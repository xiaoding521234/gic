# 势力机制总述

> 各势力机制详见本目录对应文档；本文只收拢**跨势力通用规则**，各势力篇不再重复。

## 机制本质

势力机制本质上是**技能**，分为主被动两种形式。**玩家可以混搭多势力**——携带的 8 种卡可来自不同势力，场上存在对应势力的角色/建筑即可使用该势力机制。

## 通用规则

- 通用的**战技、爆发**消耗体力（**按施法者层级**：眷属 0/伙伴 5/魔神 10——2026-09-29 操控分层拍板，真源=05 §5.1 层级表）；**移动免费**（即时制，决策九十五蓝图 §3.3）
- **势力特殊技能（号令）不消耗体力**（除非特殊说明）——即时制**配额制退役**（决策九十五）：延奏、契约等与魔神操作、打出手牌一样**即时上交即时结算**（体力=手动操作唯一节流；见 [../05-行动系统.md](../05-行动系统.md) §5.0）
- **势力技能=玩家域专属**（2026-09-29 操控分层拍板，docs/32 §4）：号令是玩家对自主军团（眷属/伙伴）的指挥通道——施法者可为眷属/伙伴/魔神（眷属技能表本无势力技能条目=天然只有伙伴/魔神能被号令），**自主单位永不自用**（伙伴评分脑已剥离势力技能候选）；号令=**即时触发施放**（即时制下无「跳过当回合自主决策」概念——号令行动即时结算，伙伴自主脑照常 0.5s 节拍运转）
- 蒙德延奏 / 璃月契约等机制的即时制语义见 [../04-战斗流程.md](../04-战斗流程.md)（决策九十五拍板 6：回合制的连携等待/契约谈判时停等时序侵入旧案**不迁移**——未实装势力实装时以即时制语境从零设计）

## 八势力一览

| 势力 | 机制 | 形式 | 一句话定位 |
|------|------|:----:|------|
| [蒙德](蒙德.md) | 延奏 / 变奏 | 主动 + 被动 | 消耗施法者元能协奏全图任意我方角色；蒙德角色被协奏时触发变奏 |
| [璃月](璃月.md) | 契约 | 主动 | 消耗摩拉签订契约，对敌使用时档位谈判 + 投票决定签订与否 |
| [稻妻](稻妻.md) | 连携 | 被动 | 达成条件获得勾玉，2 秒窗口内可点击发动，至多连发 3 次 |
| [须弥](须弥.md) | 智慧数据库 | 被动+主动 | 收集角色隐藏"智慧"，经世界树建筑花摩拉传输激活 |
| [枫丹](枫丹.md) | 芒荒形态 | 被动 | 按元能比例自动切换形态，技能效果随形态变化 |
| [纳塔](纳塔.md) | 夜魂 | 被动 | 元能与生命联动：元能流逝触发效果，生命 0 仍可行动但流逝 3 倍速 |
| [挪德](挪德.md) | 双祝福 | 被动 | 升命时二选一祝福，同角色可走出不同命座路线 |
| [待定势力](待定势力.md) | 至冬 / 坎瑞亚 | — | 待设计 |

## 衍生玩法

势力机制之外，各势力还有通过特定角色/建筑触发的**衍生玩法**子系统（炼金/再生/月矩力/机械科技等），见 [../08-势力衍生玩法.md](../08-势力衍生玩法.md)。
