# 稻妻 — 连携

> 势力机制本质上是**技能**，分为主被动两种形式。**玩家可以混搭多势力**，场上存在对应势力的角色/建筑即可使用该势力机制。

| 技能 | 类型 | 说明 |
|------|------|------|
| **连携** | 被动 | 行动阶段中达成特定条件时触发 |

## 连携流程

1. 行动阶段中，达成特定条件时 → 获得**1个勾玉**，并出现**连携按钮**
2. 玩家可点击按钮发动连携，**若超过3秒不点击则视为取消**
3. 点击后 → 消耗**1个勾玉**，发动连携效果
4. 发动后，根据**存有勾玉数量**判断是否再次出现按钮 → 可继续发动连携
5. **至多储存3个勾玉**
