# 稻妻 — 连携

> 通用规则（机制本质/混搭/体力）见 [00-总述.md](00-总述.md)。

| 技能 | 类型 | 说明 |
|------|------|------|
| **连携** | 被动 | 执行阶段中达成特定条件时触发 |

## 连携流程

1. 执行阶段中，达成特定条件时 → 获得**1个勾玉**，并出现**连携按钮**
2. **2秒内随时可点击**按钮发动连携；计时结束未点击则按钮消失，视为放弃本次发动（勾玉保留）
3. 点击后 → 消耗**1个勾玉**，发动连携效果
4. 发动后，根据**存有勾玉数量**判断是否再次出现按钮 → 可继续发动连携（新按钮重新计时2秒，**至多追加2次**——同一次触发中合计至多发动3次）
5. **至多储存3个勾玉**
6. **阶段推进等待**：进入下一行动阶段之前，流程会先等该2秒计时结束——连携计时不被阶段切换掐断，保证玩家拥有完整的反应窗口
