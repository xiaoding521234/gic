# 璃月 — 契约

> 势力机制本质上是**技能**，分为主被动两种形式。**玩家可以混搭多势力**，场上存在对应势力的角色/建筑即可使用该势力机制。

| 技能 | 类型 | 说明 |
|------|------|------|
| **契约** | 主动 | 消耗**摩拉**，选择全图任意角色与其签订特定契约 |

## 契约流程

1. **行动阶段**：施加方选择目标并支付摩拉发起契约；**对敌人使用时额外弹出档位弹窗**，选择契约数值档位（见下）
2. **执行阶段**：契约结算到签订决定时——
   - **对我方角色使用**：直接同意（**平衡档位**生效），契约生效
   - **对敌方角色使用**：进入**谈判时停**（见下）
3. **拒签**：触发对应的**惩罚**
4. **签订**：契约生效，包含四个阶段：
   - **施加时**：契约生效时的即时效果
   - **存在时**：契约存续期间的持续效果
   - **解除条件**：满足条件时契约自动解除
   - **解除时**：契约解除时的效果

## 档位（数值调整）

行动阶段对敌人使用契约时，主契者通过弹窗选择档位，共 **3 档**，**默认平衡**：

- **平衡**（默认）
- **小利**
- **大利**

- 档位**只影响契约中的数值**（对被契者的补偿），**不影响拒签惩罚**——三档拒签惩罚相同
- 用于让玩家更好谈判：初始档位越低，后续谈判加利的空间越大（见下"加利上限"）
- 示例（行秋·雨深闭门）：移速-50% 三档不变；平衡=每回合结束时获得10元能 / 小利=15元能 / 大利=20元能

## 谈判时停（执行阶段，对敌方使用时）

契约结算到签订决定时，**游戏时停3秒**，被契玩家限时决定：

- **签订** → 契约生效
- **拒签** → 触发拒签惩罚
- **超时 → 自动拒签**
- 时停期间，被契玩家可点击**谈判加利按钮** → 快速向主契者发送要求加利的消息，**决定权移交主契者**：
  - 主契者**同意** → **立即加利**（档位+1），决定权回到被契者，谈判时间**延长2秒**
  - 主契者**拒绝** → 不加利，且**直接判定拒签**
  - 主契者**超时 → 自动拒签**
- **加利上限**：至多加到**大利**档——初始为平衡最多谈判加利2次、小利最多1次、大利不可加利
- 谈判期间，其它玩家可发送**快捷消息**，但**没有决定权**

## 契约规则

- 当某角色身上**已有该施加方的契约存在时**，不可再对其施加新契约
- 1个角色可以**同时被施加多个契约**（来自不同施加方）
- 其中**任意1个契约解除时，该角色身上的所有契约同时解除**
