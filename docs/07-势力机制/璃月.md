# 璃月 — 契约

> 势力机制本质上是**技能**，分为主被动两种形式。**玩家可以混搭多势力**，场上存在对应势力的角色/建筑即可使用该势力机制。

| 技能 | 类型 | 说明 |
|------|------|------|
| **契约** | 主动 | 消耗**摩拉**，选择全图任意角色与其签订特定契约 |

## 契约流程

1. **行动阶段**：施加方选择目标并支付摩拉发起契约；**对敌人使用时额外弹出档位弹窗**，选择契约数值档位（见下）
2. **执行阶段**：契约结算到签订决定时——
   - **对我方角色使用**：直接同意（**平衡档位**生效），契约生效
   - **对敌方角色使用**：进入**谈判时停**（见下）
3. **拒签**：触发对应档位的**拒签惩罚**（见"档位"）
4. **签订**：契约生效，包含四个阶段：
   - **施加时**：契约生效时的即时效果
   - **存在时**：契约存续期间的持续效果
   - **解除条件**：满足条件时契约自动解除
   - **解除时**：契约解除时的效果

## 档位（数值调整）

行动阶段对敌人使用契约时，主契者通过弹窗选择档位，共 **3 档**，**默认平衡**：

- **平衡**（默认）
- **小利**
- **大利**

- 档位**同时影响契约中的数值**（对被契者的补偿）**与拒签惩罚**——档位越高，补偿越高，拒签惩罚也越重
- 用于让玩家更好谈判：初始档位越低，后续谈判加利的空间越大（见下"加利上限"）；初始档位越高则拒签惩罚越重——开高价既是让利也是施压
- **描述规范**：契约技能描述只写该技能特有的效果与数值（存在时效果、解除条件、拒签惩罚、消耗），缔约流程/档位选择/谈判投票等**通用契约规则不重复写入**；随档位变化的数值统一写作紧凑格式"值1/值2/值3"（按 平衡/小利/大利 顺序），不逐档展开、不逐档标注
- 示例（行秋·雨深闭门）：移速-50% 三档不变；每回合结束时获得10/15/20元能、拒签失去30/45/60元能（平衡/小利/大利）；拒签扣除元能不足时，不足部分按50%换算为摩拉，由主契者掠夺

## 谈判时停（执行阶段，对敌方使用时）

契约结算到签订决定时，**游戏时停3秒**，以**投票**决定契约签订与否：

### 票权

| 投票人 | 票数 |
|------|:---:|
| 主契者 / 被契者 | 3 |
| 双方队友（同队玩家） | 2 |
| 已淘汰玩家、非这两个队的玩家（第三方） | 1 |

### 投票规则

- 只可对**同意 / 拒绝**投票——签订/拒签轮投"契约是否签订"，加利回应轮投"是否同意加利"
- **谈判加利只能由被契者点击**发起，其余玩家（含队友）无加利发起权
- **决定权在哪一方，该方与第三方投票，另一方本轮不投票**：
  - **签订/拒签轮**：被契方（被契者+其队友）与第三方投票，主契方不投票
  - **加利回应轮**：主契方（主契者+其队友）与第三方投票，被契方不投票
- **平票 → 判定拒签**（含双方均 0 票；计时结束按已投票数统计）

### 投票流程

1. 时停开始，进入**签订/拒签轮**投票
2. 被契者可点击**谈判加利按钮**发起加利 → **决定权移交主契方**，进入**加利回应轮**：
   - 主契方**同意** → **立即加利**（档位+1），决定权回到被契方，谈判时间**延长2秒**；加利后补偿与拒签惩罚**同步按新档位生效**——要求加利后再拒签，按加后的档位惩罚执行
   - 主契方**拒绝或平票** → 不加利，且**直接判定拒签**
3. **加利上限**：至多加到**大利**档——初始为平衡最多谈判加利2次、小利最多1次、大利不可加利
4. 谈判期间，其它玩家可发送**快捷消息**（拉票/施压）

## 契约规则

- 当某角色身上**已有该施加方的契约存在时**，不可再对其施加新契约
- 1个角色可以**同时被施加多个契约**（来自不同施加方）
- 其中**任意1个契约解除时，该角色身上的所有契约同时解除**
