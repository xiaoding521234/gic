# 大地图

## 1. 概述

大地图是局外导航系统——玩家在区域间切换、查看可探索的地点、进入对应场景。它是游戏循环的枢纽：

```
大地图选择位置 → MainHall（该位置的场景背景）→ 祈愿/背包/局前准备 → 进入战场 → 结算 → 回到大地图
```

大地图与战场是两个完全独立的系统：
- **大地图**：局外导航，区域 + 锚点，选择位置传送
- **战场**：局内 20×20~50×50 网格战棋（见 03-战场与资源.md）

| Inazuma | 稻妻 | 4 | 待添加 |
| Sumeru | 须弥 | 5 | 待添加 |
| Fontaine | 枫丹 | 6 | 待添加 |

每个区域有自己的视野中心、视野高度和锚点列表（共用一张 3D 大地图平面 `all_map`，相机按区域聚焦）。大地图顶部有区域切换按钮，点击切换到对应区域视野。

## 3. 位置系统

每个区域包含若干**位置**（PositionName），位置是玩家可以传送到的具体地点。

### 3.1 位置编号规则

位置枚举按区域分段，每个区域占 1000 个编号段：

| 区域 | 编号范围 | 已有位置 |
|------|----------|---------|
| 挪德卡莱 | 1000–1999 | 星砂浅滩(1001)、纳沙镇门(1002)、纳沙镇(1003) |
| 蒙德 | 2000–2999 | 风龙废墟(2001)、摘星崖(2002)、千风神殿(2003)、风起地(2004)、低语森林(2005)、清泉镇(2006)、龙脊雪山西麓(2007) |
| 璃月 | 3000–3999 | 遥光滩(3001)、绝云间(3002)、归离原(3003)、碧水原(3004)、天衡山(3005)、璃月港(3006)、望舒客栈(3007) |
| 稻妻~坎瑞亚 | 4000–9999 | 待添加 |

### 3.2 位置数据（PositionData）

每个位置由 `PositionConfig` 中的 `PositionData` 定义：

| 字段 | 类型 | 说明 |
|------|------|------|
| position | PositionName | 位置枚举 |
| region | RegionName | 所属区域 |
| isUnlocked | bool | 是否已解锁（解锁后锚点可点击） |
| taskNames | List\<string\> | 该位置可执行的任务名（待设计） |
| audioPrefix | string | 音频文件前缀，用于自动匹配日间/夜间 BGM |
| dayAudios | AudioClipRandom | 日间背景音乐 |
| nightAudios | AudioClipRandom | 夜间背景音乐 |

位置的本地化信息（名称、区域名、描述）通过 `PositionName` 枚举扩展方法从 `TableName.PositionName` 本地化表读取。

### 3.3 解锁机制

- 位置默认锁定（`isUnlocked = false`），大地图上锚点显示为**灰色不可点击**
- 通过 `PositionManager.UnlockPosition(PositionName)` 解锁
- 解锁后锚点变为**白色可点击**状态
- 当前玩家位置存档在 `PlayerSaveData.currentPosition`，默认为纳沙镇

## 4. 锚点系统

大地图上的位置以**锚点**（Anchor）形式展示。

### 4.1 锚点坐标

锚点位置使用**归一化坐标**（0–1）存储，与地图图片尺寸无关：

- `normalizedX = 0` → 地图图片最左侧
- `normalizedX = 1` → 地图图片最右侧
- `normalizedY = 0` → 地图图片最上方
- `normalizedY = 1` → 地图图片最下方

地图图片尺寸变化时，锚点自动按比例定位，无需手动调整。

### 4.2 锚点数据（AnchorData）

| 字段 | 类型 | 说明 |
|------|------|------|
| positionName | PositionName | 对应的位置枚举 |
| normalizedX | float (0–1) | 归一化 X 坐标 |
| normalizedY | float (0–1) | 归一化 Y 坐标 |

### 4.3 锚点行为

锚点是 3D 世界空间面片（`MapAnchor`，预制体 `Assets/Art/Map/Prefabs/Anchor3D.prefab`）：

- 结构：根节点（`MapAnchor` + `BoxCollider`）+ 子物体 Icon（`SpriteRenderer` 直立面片，按相机俯角后仰使法线指向相机，缩放固定不随相机缩放变化）
- 材质：`Sprites-Default`（与 MainHall 背景同款，URP 无灯光可正常渲染）

1. `SetPositionName` — 绑定 PositionName
2. `RefreshVisual(pitch)` — 由 MapScreen 生成时调用：设置图标倾斜角与离地悬浮高度
3. `SetData(PositionData)` — 根据 `isUnlocked` 设置：
   - **已解锁**：图标白色，可点击
   - **未解锁**：图标灰色，点击时仅打印日志
4. **点击锚点** — 由 `MapCameraController` 在指针抬起且位移小于阈值时射线检测 `BoxCollider` 分发到 `HandleClick()` → 调用 `PositionManager.MoveToPosition(positionName)` → 传送

> 2026-08-16 前：锚点是 UGUI Button + Image（Anchor.prefab），用 `AnchorScaleFix` 反向补偿父级缩放；3D 化后相机缩放不改变物体尺寸，反向补偿不再需要（AnchorScaleFix.cs 与旧 Anchor.prefab 保留未删）。

## 5. 地图交互（3D 世界空间）

> 2026-08-16 重构：地图与锚点从 UGUI 画布迁移为 3D 物体（平铺 XZ 地面的 SpriteRenderer 地图平面 + 直立面片锚点），由专用透视相机渲染，交互全部改为相机运动。UI 层（标题/区域按钮条/关闭按钮）保留在 Canvas。

### 5.1 相机与缩放拖拽

大地图通过 `MapCameraController`（挂在场景 MapCamera 上）实现（2026-08-16 定稿：**正交垂直俯视，无 3D 透视效果**）：

| 功能 | 说明 |
|------|------|
| 相机 | 正交相机垂直向下（rotation 90°），固定高度 100，depth 10 高于 MainHall 相机，Clear=SolidColor |
| 拖拽平移 | 抓取地面点跟随：按下时求指针射线与地面交点，移动时平移相机使该点跟随指针（鼠标/单指） |
| 缩放 | 乘法缩放：滚轮每格 ×0.925（缩出）/×1.081（缩入），任意缩放级别下视觉变化一致，到上下限有明确停顿感；双指捏合为比例式；正交尺寸 8–15（默认 8），以指针地面点为锚，ApplyCameraSetup 另有硬 clamp 兜底 |
| 边界 | 按当前可见半宽/半高 clamp 注视点，画面四边不露出地图外（地图小于可视区时居中） |
| 入场动画 | 进场无遮罩直接显示，同步播 0.2s 缩放回落（快→慢）；期间持有 MapEntering 输入锁 |
| 点击判定 | 按下与抬起屏幕位移 < 12px 视为点击 → 射线检测锚点 BoxCollider 分发 |

输入锁：`InputLocks.IsLocked`（任意锁存在）时中断一切地图交互手势。锚点图标平铺在地图平面上方（与 MapPlane 同旋转），俯视观感等同平面图标。

### 5.2 区域切换

1. 点击顶部区域按钮 → `ShowRegion(RegionName)`
2. 如果与当前区域相同则直接返回
3. 更新标题文字
4. 从 `MapConfig` 读取该区域的 `RegionData`：
   - `viewCenter`（归一化视野中心）→ 换算为地图平面上的世界坐标
   - `viewHeight`（视野高度，0=相机默认 13）
5. 清除旧锚点（`ClearAnchors`）
6. 生成新锚点（`SpawnAnchors`）：归一化坐标转换为地面世界坐标
8. `地图相机.FocusRegion(世界坐标, 视野尺寸)`：播放入场动画（等价旧的 ResetMap+ReplayEntryAnimation）
   - `viewHeight` 语义 = 正交相机垂直半高（世界单位），0 时用默认 8

### 5.3 锚点世界坐标计算

地图平面以 SpriteRenderer 铺在 XZ 地面（sprite 顶边朝 -Z 北），中心为原点，世界尺寸取自 `地图贴图.bounds.size`（all_map @PPU100 ≈ 215×138）：

```
worldX = (normalizedX - 0.5) × mapWidth
worldZ = (normalizedY - 0.5) × mapDepth
```

归一化 Y=0（图片顶）→ -Z（北），与旧 UGUI 的 Y 翻转语义一致。

## 6. 导航流程

### 6.1 大地图 → 位置

```
玩家打开大地图 → 选择区域 → 点击锚点
→ PositionManager.MoveToPosition(PositionName)
→ 验证位置已解锁
→ 写入存档 (currentPosition)
→ 触发 OnPositionChangedEvent
→ 加载 MainHall 场景（Single，替换大地图）
```

### 6.2 场景生命周期

| 场景 | 加载模式 | 说明 |
|------|----------|------|
| MainHall | Single | 主场景（位置背景 + 功能入口） |
| MapScreen | Additive | 大地图叠加在 MainHall 上，关闭后回到 MainHall |
| BattleScreen | Additive | 战场叠加在 MainHall 上 |
| WishScreen | Additive | 祈愿叠加在 MainHall 上 |

大地图作为 Additive 场景加载，关闭时调用 `GameScene.Instance.GoBack()` 卸载自身，回到 MainHall。

### 6.3 位置背景

传送到新位置后，MainHall 会根据当前位置加载对应背景图：

- 背景路径：`PositionBack/{RegionName}/{PositionName}_{Day|Night}`
- 通过 Addressables 按需加载
- 根据当前时间段（`TimeUtility.GetCurrentTimePeriod()`）选择日间或夜间背景

## 7. 音乐系统

每个位置有日间和夜间两套 BGM（`AudioClipRandom`），通过 `audioPrefix` 自动匹配音频文件。

- 进入新位置 → `PlayCurrentPositionMusic()` 根据时间段选择 BGM
- 播放间隔：每 10 秒检查一次是否需要切换音乐（`MUSIC_INTERVAL = 10f`）
- 打开大地图时降低音乐音量（`AudioManager.PushMusicVolume`），关闭时恢复（`PopMusicVolume`）

## 8. 数据配置

### 8.1 MapConfig

`MapConfig`（ScriptableObject，`GIC/Map Config`）存储大地图布局：

```
MapConfig
└── regions: List<RegionData>
    └── RegionData
        ├── region: RegionName
        ├── viewCenter: Vector2            // 区域视野中心（归一化 0-1，0=地图左/上）
        ├── viewHeight: float              // 区域视野高度（世界单位，0=相机默认）
        └── anchors: List<AnchorData>      // 该区域所有锚点
```

> 2026-08-16 3D 化时删除了旧的 4 个 UGUI 像素字段（mapImageAnchoredPosition/mapImageSize/contentAnchoredPosition/contentSizeDelta）；7 个存量区域的 viewCenter 已按旧像素数据换算迁移，可在 Inspector 微调。

### 8.2 PositionConfig

`PositionConfig`（ScriptableObject，`Game/PositionConfig`）存储位置主数据：

```
PositionConfig
└── mapDataList: List<PositionData>
    └── PositionData
        ├── position: PositionName
        ├── region: RegionName
        ├── isUnlocked: bool
        ├── taskNames: List<string>
        ├── audioPrefix: string
        ├── dayAudios: AudioClipRandom
        └── nightAudios: AudioClipRandom
```

两个配置文件通过 `ConfigManager` 加载。新增区域/位置需要同时更新两个配置。

### 8.3 新增区域流程

1. 在 `RegionName` 枚举中添加新值（已有 9 个区域，一般不需要新增）
2. 在 `PositionName` 枚举中添加该区域的位置（使用对应编号段）
3. 在 `PositionConfig.asset` 中添加 `PositionData` 条目
4. 在 `MapConfig.asset` 中添加 `RegionData`，配置视野中心（viewCenter）和锚点归一化坐标
5. （共用 `all_map` 大图，无需单独地图资源；`Assets/Art/Map/Prefabs/{RegionName}Map.prefab` 为 3D 化前的旧区域图预制体，当前未使用）
6. 放置位置背景图（`Assets/Art/PositionBack/{RegionName}/{PositionName}_Day|Night`）
7. 放置 BGM 音频文件（`Assets/Resources/Audios/Daytime/` 和 `Night/`，按 `audioPrefix` 匹配）
8. 更新本地化表（`TableName.PositionName` 和 `TableName.UIText`）

## 9. 场景结构

大地图场景（MapScreen）层级：

> 地图贴图 `all_map.jpg`：10752×6912（0.5×源图，PPU 50，世界尺寸 215×138）+ **DXT1 无 mipmap**（Tuanjie 开 mip 即拒绝块压缩，见 docs/14 §8.2），运行时 71MB。缩放范围 8–15 内画面恒为放大显示，无 mip 无损。源图备份 `Export/all_map_source_21504.jpg`。

```
MapScreen (Additive Scene)
├── MapCamera (正交俯视 90°, depth 10, SolidColor)  // MapCameraController：拖拽/缩放/入场动画/点击射线
├── MapWorld
│   ├── MapPlane (SpriteRenderer: all_map, 平铺 XZ 地面, ≈215×138)
│   └── Anchors                             // 动态生成的 3D 锚点挂载在此
│       ├── Anchor3D (MapAnchor + BoxCollider + Icon 子物体)
│       └── ...
├── Canvas (ScreenSpaceOverlay, order 100, CanvasGroup 淡出 UI)
│   ├── Title (TextCombiner)                // 区域标题
│   ├── Scroll View                         // 区域切换按钮条（8 个区域缩略按钮）
│   ├── CloseButton
│   ├── ChooseMap
│   └── FadeOverlay (全屏黑遮罩, CanvasGroup ignoreParentGroups)  // 3D 地图淡入淡出
└── MapScreen (脚本挂载点)
```

淡入淡出双通道：UI 走根 Canvas 的 CanvasGroup；3D 地图走 FadeOverlay 全屏遮罩（入场 1→0 淡入，退场 0→1 遮黑后 GoBack）。

渲染层级：MainHall 相机(depth -1) → MapCamera(depth 10, SolidColor 覆盖) → Canvas(Overlay 最顶层)。

## 10. 设计意图

- **区域 = 卡池关联**：7 个主要区域对应 7 个祈愿卡池（风神/岩神/雷神/草神/水神/火神/月神），玩家在大地图上的位置决定可访问的卡池
- **位置 = 场景入口**：每个位置是独立的场景背景，承载祈愿、背包、联机大厅等功能入口
- **解锁驱动探索**：位置需要逐步解锁，给玩家"探索提瓦特"的进度感
- **日/夜循环**：位置有日夜两套背景和音乐，增强沉浸感
- **大地图 vs 战场分离**：大地图是局外导航（无战斗逻辑），战场是局内网格（无导航逻辑），两者通过场景加载切换，互不干扰
