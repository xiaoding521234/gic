# 大地图

## 1. 概述

大地图是局外导航系统——玩家在区域间切换、查看可探索的地点、进入对应场景。它是游戏循环的枢纽：

```
大地图选择位置 → MainHall（该位置的场景背景）→ 祈愿/背包/局前准备 → 进入战场 → 结算 → 回到大地图
```

大地图与战场是两个完全独立的系统：
- **大地图**：局外导航，区域 + 锚点，选择位置传送
- **战场**：局内 20×20~50×50 网格战棋（见 03-战场与资源.md）

每个区域包含若干**位置**（PositionName），位置是玩家可以传送到的具体地点。

### 3.2 位置数据（PositionData）

每个位置由 `PositionConfig` 中的 `PositionData` 定义：

| 字段 | 类型 | 说明 |
|------|------|------|
| position | PositionName | 位置枚举 |
| region | RegionName | 所属区域 |
| isUnlocked | bool | 是否已解锁（解锁后锚点可点击） |
| taskNames | List\<string\> | 该位置可执行的任务名（待设计） |
| audioPrefix | string | 音频文件前缀，用于自动匹配日间/夜间 BGM |
| dayAudios | AudioClipRandom | 日间背景音乐 |
| nightAudios | AudioClipRandom | 夜间背景音乐 |

位置的本地化信息（名称、区域名、描述）通过 `PositionName` 枚举扩展方法从 `TableName.PositionName` 本地化表读取。

### 3.3 解锁机制

- 位置默认锁定（`isUnlocked = false`），大地图上锚点显示为**灰色不可点击**
- 通过 `PositionManager.UnlockPosition(PositionName)` 解锁
- 解锁后锚点变为**白色可点击**状态
- 当前玩家位置存档在 `PlayerSaveData.currentPosition`，默认为纳沙镇

## 4. 锚点系统

大地图上的位置以**锚点**（Anchor）形式展示。

> 2026-08-16 改为原神式：**锚点全图常驻显示**——打开地图时一次性生成 `MapConfig` 中所有区域的锚点（`SpawnAllAnchors`），玩家可自由拖拽浏览全图，锚点不随区域切换增删；区域按钮只移动相机视野。

**区域按钮为数据驱动**：MapScreen 的 `regionButtons` 数组（`{RegionName region, Button button}` 列表）——新增区域只需数组加一条 + 场景拖入按钮，无需改代码。场景中区域按钮条在 Canvas/Scroll View/Viewport/Content 下（现有 7 个区域按钮 GameObject：Nodklai/Mondstadt/Liyue/Inazuma/Sumeru/Fontaine/Natlan）；ChooseMap 是右下角独立图标（Image，无点击绑定）。

### 4.1 锚点坐标（原神式固定世界坐标系）

> 2026-08-16 重构：坐标系统从"图片归一化坐标（0–1）"改为**固定世界坐标系**（原神标准做法）。
> 归一化坐标绑定当前图片边界，扩图后所有坐标错位；固定世界坐标系中锚点/区域数据存**绝对世界坐标**，永不需要随图调整。
> 2026-08-17 垂直画布定稿：世界坐标为 XY（**Y 向上 = 北**），地图平铺 XY 竖直平面 z=0（见 §5.3）。

- `AnchorData.world`：锚点的世界 XY 坐标（Vector2，y 即世界 Y）
- `RegionData.viewCenterWorld`：区域视野中心的世界 XY 坐标
- 地图图片通过 `MapConfig` 的两个**标定参数**摆进世界框架：
  - `mapOrigin`：图片**左上角**的世界 XY 坐标（图片顶边在世界 +Y，即屏幕上方）
  - `worldUnitsPerPixel`：每图片像素对应的世界单位数
- 当前标定（2026-08-18 新版地图 16384×13896）：`mapOrigin = (-108.59, 114.94)`，`worldUnitsPerPixel = 0.013348`（世界尺寸 ≈218.7×185.5）

**扩图/换图工作流**（只动两个参数，存量坐标零改动）：

1. 覆盖 `Assets/Art/Map/Textures/all_map.jpg`（保持路径不变；尺寸两边取 4 的倍数；关 mip，见 docs/14 §8.2）
2. 菜单 `Tools/地图/坐标取点器` → 「标定地图」模式：**下拉 A/B 必须与图上点击的两处地点一一对应** → Ctrl+点 A 地点实际位置 → 点 B（自动吸附约束线）
3. 面板看解算值（unit 应与当前 MapConfig 同量级）→「保存到磁盘」→「应用地图标定到场景」→ 目测

> 两道防呆（2026-08-18 标定事故后加入）：点击方向偏差 >3° 拒解算；解算 unit 与当前值比值超 ±3 倍拒写入。拒绝时按提示核对，勿手工硬填绕过。

新锚点坐标换算（px/py 为图片左上起的像素，py 向下增长）：

```
worldX = mapOrigin.x + px × worldUnitsPerPixel
worldY = mapOrigin.y − py × worldUnitsPerPixel
```

（坐标取点器的「新建锚点」模式点图即得世界坐标，无需手算。）

### 4.2 锚点数据（AnchorData）

| 字段 | 类型 | 说明 |
|------|------|------|
| positionName | PositionName | 对应的位置枚举 |
| world | Vector2 | 锚点位置（固定世界 XY 坐标，扩图不变） |

### 4.3 锚点行为

锚点是 3D 世界空间面片（`MapAnchor`，预制体 `Assets/Art/Map/Prefabs/Anchor3D.prefab`）：

- 结构：根节点（`MapAnchor` + `BoxCollider`）+ 子物体 Icon（`SpriteRenderer` 直立面片，按相机俯角后仰使法线指向相机，缩放固定不随相机缩放变化）
- 材质：`Sprites-Default`（与 MainHall 背景同款，URP 无灯光可正常渲染）

1. `SetPositionName` — 绑定 PositionName
2. `RefreshVisual(pitch)` — 由 MapScreen 生成时调用：设置图标倾斜角与离地悬浮高度
3. `SetData(PositionData)` — 根据 `isUnlocked` 设置：
   - **已解锁**：图标白色，可点击
   - **未解锁**：图标灰色，点击时仅打印日志
4. **点击锚点** — 由 `MapCameraController` 在指针抬起且位移小于阈值时射线检测 `BoxCollider` 分发到 `HandleClick()` → 调用 `PositionManager.MoveToPosition(positionName)` → 传送
5. **恒定视觉尺寸** — MapScreen 每帧检测相机正交尺寸变化，锚点根节点按 `相机尺寸/基准尺寸(默认8)` 比例缩放，与视野变化抵消：无论怎么缩放，锚点屏幕大小不变（点击热区同步恒定）

> 2026-08-16 前：锚点是 UGUI Button + Image（Anchor.prefab），用 `AnchorScaleFix` 反向补偿父级缩放；3D 化后相机缩放不改变物体尺寸，反向补偿不再需要。2026-08-18 旧 Anchor.prefab 及 8 个旧区域图 Prefab、8 张旧区域贴图已删除（GUID 核验零引用）；`AnchorScaleFix.cs` 仍在但全仓零引用（死代码，待删）。

## 5. 地图交互（3D 世界空间）

> 2026-08-16 重构：地图与锚点从 UGUI 画布迁移为 3D 物体（初版为 XZ 地面平铺 + 透视相机，2026-08-17 已改垂直画布正交，见 §5.3），交互全部改为相机运动。UI 层（标题/区域按钮条/关闭按钮）保留在 Canvas。

### 5.1 相机与缩放拖拽

大地图通过 `MapCameraController`（挂在场景 MapCamera 上）实现（2026-08-17 定稿：**垂直画布正交版**——地图平铺 XY 竖直平面，相机沿 -Z 看，rotation 归零）：

| 功能 | 说明 |
|------|------|
| 相机 | 正交相机 rotation identity（沿 -Z），距画布 -100，depth 10 高于 MainHall 相机，Clear=SolidColor |
| 拖拽平移 | 抓取地面点跟随：按下时求指针射线与地面交点，移动时平移相机使该点跟随指针（鼠标/单指） |
| 缩放 | 乘法缩放：滚轮每格 ×0.925（缩出）/×1.081（缩入），任意缩放级别下视觉变化一致，到上下限有明确停顿感；双指捏合为比例式；正交尺寸场景覆盖 8–15（默认 8，代码默认 5–45——上限 15 时看不全整图，待拍板），以指针地面点为锚，ApplyCameraSetup 另有硬 clamp 兜底 |
| 边界 | 按当前可见半宽/半高 clamp 注视点，画面四边不露出地图外（地图小于可视区时居中） |
| 入场动画 | 进场无遮罩直接显示，从最大上限远景快→慢落到缩放区间中点 11.5（居中视野），0.2s；期间持有 MapEntering 输入锁。区域可经 viewHeight 单独指定落点 |
| 点击判定 | 按下与抬起屏幕位移 < 12px 视为点击 → 射线检测锚点 BoxCollider 分发 |

输入锁：`InputLocks.IsLocked`（任意锁存在）时中断一切地图交互手势。锚点图标平铺在地图平面上方（与 MapPlane 同旋转），俯视观感等同平面图标。

### 5.2 区域切换

> 2026-08-16 改为原神式：**锚点全图常驻**（打开地图时 `SpawnAllAnchors` 一次性生成所有区域的锚点，可自由拖拽浏览全图），区域按钮只移动相机视野，不再按区域生成/销毁锚点。重复点击当前区域按钮 = 重新居中该区域视野。

1. 点击顶部区域按钮 → `ShowRegion(RegionName)`
2. 更新标题文字
3. 从 `MapConfig` 读取该区域的 `RegionData`：
   - `viewCenterWorld`（固定世界 XY 坐标）→ 相机直接聚焦，无需换算
   - `viewHeight`（视野高度，0=相机默认 8）
4. `地图相机.FocusRegion(世界坐标, 视野尺寸, fromMaxZoom)`：
   - 初次打开（`fromMaxZoom=true`）：从最大远景快→慢落下
   - 区域切换（默认）：从当前视野/注视点平滑滑移到目标（原神式）
   - `viewHeight` 语义 = 正交相机垂直半高（世界单位），0 时用默认 8

### 5.3 地图摆放与标定（固定世界坐标系，垂直画布）

> 2026-08-17 重构为**垂直画布**（Unity 2D 约定）：地图平铺在 XY 竖直平面（z=0），MapCamera/MapPlane rotation 全部归零（identity），相机沿 -Z 看。相比旧的"XZ 平铺 + Euler(90) 俯拍"方案，结构性消灭 Y 翻转公式、SpriteRenderer.bounds 世界 AABB 陷阱、SceneView 2D 模式冲突。MapConfig 存量坐标已同步迁移（world.y = −旧 z，即世界 Y 向上=北）。

MapPlane（SpriteRenderer，rotation identity）由 `MapScreen.ApplyMapCalibration()` 在 Start（及编辑器标定工具）按 `MapConfig` 标定参数摆放：

- 世界尺寸 = 图片像素数 × `worldUnitsPerPixel`（缩放抵消 PPU，换图后 PPU 变化无影响）
- 中心位置 = `mapOrigin` + (宽/2, −高/2)，z=0（图片左上角对齐 mapOrigin，图片顶边在世界 +Y 上方）
- 相机边界 `InitBounds(宽, 高)` 同步标定值
- 射线交互（拖拽取点/点击）统一与 z=0 平面求交

锚点/区域视野直接使用存量的世界 XY 坐标，无任何换算。

## 6. 导航流程

### 6.1 大地图 → 位置

```
玩家打开大地图 → 选择区域 → 点击锚点
→ PositionManager.MoveToPosition(PositionName)
→ 验证位置已解锁
→ 写入存档 (currentPosition)
→ 触发 OnPositionChangedEvent
→ 加载 MainHall 场景（Single，替换大地图）
```

### 6.2 场景生命周期

| 场景 | 加载模式 | 说明 |
|------|----------|------|
| MainHall | Single | 主场景（位置背景 + 功能入口） |
| MapScreen | Additive | 大地图叠加在 MainHall 上，关闭后回到 MainHall |
| BattleScreen | Additive | 战场叠加在 MainHall 上 |
| WishScreen | Additive | 祈愿叠加在 MainHall 上 |

大地图作为 Additive 场景加载，关闭时调用 `GameScene.Instance.GoBack()` 卸载自身，回到 MainHall。

### 6.3 位置背景

传送到新位置后，MainHall 会根据当前位置加载对应背景图：

- 背景路径：`PositionBack/{RegionName}/{PositionName}_{Day|Night}`
- 通过 Addressables 按需加载
- 根据当前时间段（`TimeUtility.GetCurrentTimePeriod()`）选择日间或夜间背景

## 7. 音乐系统

每个位置有日间和夜间两套 BGM（`AudioClipRandom`），通过 `audioPrefix` 自动匹配音频文件。

- 进入新位置 → `PlayCurrentPositionMusic()` 根据时间段选择 BGM
- 播放间隔：每 10 秒检查一次是否需要切换音乐（`MUSIC_INTERVAL = 10f`）
- 打开大地图时降低音乐音量（`AudioManager.PushMusicVolume`），关闭时恢复（`PopMusicVolume`）

## 8. 数据配置

### 8.1 MapConfig

`MapConfig`（ScriptableObject，`GIC/Map Config`）存储大地图布局：

```
MapConfig
├── mapOrigin: Vector2                    // 图片左上角的世界 XY 坐标（标定参数）
├── worldUnitsPerPixel: float             // 每像素世界单位数（标定参数）
└── regions: List<RegionData>
    └── RegionData
        ├── region: RegionName
        ├── viewCenterWorld: Vector2      // 区域视野中心（固定世界 XY 坐标）
        ├── viewHeight: float             // 区域视野高度（世界单位，0=相机默认）
        └── anchors: List<AnchorData>     // 该区域所有锚点
```

> 2026-08-16 3D 化时删除了旧的 4 个 UGUI 像素字段（mapImageAnchoredPosition/mapImageSize/contentAnchoredPosition/contentSizeDelta）；7 个存量区域的 viewCenterWorld 已按旧像素数据换算迁移，可用取点器微调。

### 8.2 PositionConfig

`PositionConfig`（ScriptableObject，`Game/PositionConfig`）存储位置主数据：

```
PositionConfig
└── mapDataList: List<PositionData>
    └── PositionData
        ├── position: PositionName
        ├── region: RegionName
        ├── isUnlocked: bool
        ├── taskNames: List<string>
        ├── audioPrefix: string
        ├── dayAudios: AudioClipRandom
        └── nightAudios: AudioClipRandom
```

两个配置文件通过 `ConfigManager` 加载。新增区域/位置需要同时更新两个配置。

### 8.3 新增区域流程

以 2026-08-18 待加的**至冬（Snezhnaya）**为例：

1. `RegionName` 枚举已有至冬（=8），无需改动；若新增区域值再改枚举
2. 在 `PositionName` 枚举中添加该区域的位置（使用对应编号段，至冬用 8000–8999）
3. 在 `PositionConfig.asset` 中添加 `PositionData` 条目
4. 用 `Tools/地图/坐标取点器`：「区域视野中心」模式点一下创建 `RegionData`（viewCenterWorld）；「新建锚点」模式点图建锚点（world 坐标自动写入）
5. 场景 MapScreen 的 Canvas/Scroll View/Viewport/Content 下复制一个区域按钮 GameObject（Image 用 `Assets/Art/Map/UI/{region}_map_button.png`）+ `MapScreen.regionButtons` 数组加一条（共用 `all_map` 大图，无需单独地图资源；旧区域图 Prefab 已删除）
6. 放置位置背景图（`Assets/Art/PositionBack/{RegionName}/{PositionName}_Day|Night`）
7. 放置 BGM 音频文件（`Assets/Resources/Audios/Daytime/` 和 `Night/`，按 `audioPrefix` 匹配）
8. 更新本地化表（`TableName.PositionName` 和 `TableName.UIText`）

## 9. 场景结构

大地图场景（MapScreen）层级：

> **瓦片化已落地（2026-08-18）**：源图 `all_map.jpg` 16384×13896 不再直接上屏（未压缩 RGBA32 显存 868MB + 首帧上传卡顿）。改为「低清预览底图 + 瓦片动态加载」：场景 MapPlane 只挂 2048×1736 预览图（DXT1 ≈1.8MB，即时可见），全分辨率按 2048px 网格切成 8×7=56 片（含 4px 重叠边防双线性接缝），每片 DXT1 ≈2MB，由 MapTileLayer 按相机可视范围经 AssetCache 动态加载/释放（滞回 1 格）。运行时常驻显存从 868MB 降到 ~20MB（可视瓦片集）。16384 全图**不进构建**（不进 Addressables 组、场景不引用），仅编辑器工具按路径使用。瓦片生成：`Tools/地图/生成地图瓦片`（幂等，换图后重跑）。旧版源图备份 `Export/all_map_source_21504.jpg`。

```
├── MapWorld
│   ├── MapPlane (SpriteRenderer: all_map_preview 2048 预览, XY 垂直画布 z=0, ≈218.7×185.5)
│   ├── TileRoot (MapTileLayer)             // 瓦片层 z=-0.02：可视范围动态加载/释放 56 片 DXT1 瓦片
│   └── Anchors                             // 动态生成的 3D 锚点挂载在此（z=-0.7，渲染在瓦片之上）
│       ├── Anchor3D (MapAnchor + BoxCollider + Icon 子物体)
│       └── ...
├── Canvas (ScreenSpaceOverlay, order 100, CanvasGroup 淡出 UI)
│   ├── Title (TextCombiner)                // 区域标题
│   ├── Scroll View → Viewport → Content    // 区域按钮条（7 个区域按钮，挂 MapScreen.regionButtons）
│   ├── CloseButton
│   ├── ChooseMap                           // 右下角图标（Image，无点击绑定）
│   └── FadeOverlay (全屏黑遮罩, CanvasGroup ignoreParentGroups)  // 3D 地图淡入淡出
└── MapScreen (脚本挂载点)
```

淡入淡出双通道：UI 走根 Canvas 的 CanvasGroup；3D 地图走 FadeOverlay 全屏遮罩（入场 1→0 淡入，退场 0→1 遮黑后 GoBack）。

渲染层级：MainHall 相机(depth -1) → MapCamera(depth 10, SolidColor 覆盖) → Canvas(Overlay 最顶层)。地图内容自下而上：MapPlane 预览图(z=0) → 瓦片(z=-0.02) → 锚点(z≈-0.7)，全 sortingOrder=0 靠深度排序。

### 9.1 瓦片化（MapTileLayer）

- **数据源**：`MapConfig` 瓦片字段（sourcePixelWidth/Height、tileColumns/Rows、tilePixelSize=2048、tileOverlapPx=4、tileAddressPrefix）由 `Tools/地图/生成地图瓦片` 自动写入；世界尺寸换算用源图像素数（MapScreen.ApplyMapCalibration 不再读 sprite.rect——MapPlane 显示的是 1/8 预览图）
- **地址**：`MapAssets/Tiles/tile_{x}_{y}`（Addressables 组 MapAssets；全图条目已移除）
- **动态加载**：每帧按相机可视矩形计算需要集（外扩 1 格预载），缺失瓦片经 AssetCache.LoadAsync 加载（离视野中心近者优先）；超出 可视+2 格（滞回）才 Release，避免边缘反复装卸
- **重叠边**：瓦片含 4px 邻域重叠（地图边缘钳制），相邻瓦片的双线性采样在重叠带内容一致，无接缝；重叠带渲染同内容两遍，视觉无差异
- **标定不变**：瓦片落位直接用 MapConfig 标定参数换算（图片左上=MapOrigin、Y 向下），换图/标定流程与瓦片无关；换图后只需重跑生成工具
- **编辑器全图预览**：取点器打开时 MapPlane 临时换 16384 全图便于取点/标定目测（MapEditorFullRes）；sceneSaving 守卫保证场景 YAML 永远只含预览图引用（全图不进构建）

## 10. 设计意图

- **区域 = 卡池关联**：7 个主要区域对应 7 个祈愿卡池（风神/岩神/雷神/草神/水神/火神/月神），玩家在大地图上的位置决定可访问的卡池
- **位置 = 场景入口**：每个位置是独立的场景背景，承载祈愿、背包、联机大厅等功能入口
- **解锁驱动探索**：位置需要逐步解锁，给玩家"探索提瓦特"的进度感
- **日/夜循环**：位置有日夜两套背景和音乐，增强沉浸感
- **大地图 vs 战场分离**：大地图是局外导航（无战斗逻辑），战场是局内网格（无导航逻辑），两者通过场景加载切换，互不干扰
