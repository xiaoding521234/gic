## 0. 设计输入与总原则

### 0.1 v1 已拍板输入（决策五十九，全量继承）

1. **未提及不改动**：地形仍一格格拼（tile 掩码）、眷属/伙伴仍 AI 自主、势力技能仍手动
2. 瞄准不再受方向限制（对齐王者荣耀）：任意角度、范围=真圆、站位自由（不锁格心），单位有体积=1/4 格，碰撞规则语义不变
3. 移速真实化：100 移速=1 格/秒，全员统一 100，1 格=1 米
4. 持续回合数→秒：1 回合=1 秒（冰冻 2 回合→2 秒）
5. 战技 CD 统一 3 秒、爆发 CD 6 秒；移动不消耗体力、不获取元能
6. 安柏射程 8 格（箭矢同）、攻击视野 8 格；芭芭拉战技 4 格；箭矢/水球命中伤害范围 0.5 格；凯亚战技 1.5 格
7. 攻速=技能释放速度（相对 0，每 +10 攻速快 10%）；武器不影响攻速；攻速默认 0
8. 距离直接数字：100=1 格=1 米（凯亚战技射程=150）

二轮补拍：昼夜时钟每秒 +1 分钟、回合数显示退役；体力/摩拉回复 +1/秒；点击式移动=不限距离走点（参考英雄联盟）、拖拽式=王者荣耀一致；**点击式技能全参考英雄联盟、拖拽式全参考王者荣耀**；**本游戏战技=MOBA 普攻地位**（无独立普攻，战技 CD 3 秒即攻击节奏）；势力技能仍 0 体力；战技体力张力拍板 A=维持层级表现状（体力产出建筑配套）。

## 2. 时间模型：回合机 → tick 机（v1 继承+业界标准件）

### 2.1 tick 底座

- 模拟步进=固定 tick，**1 tick=1/20 秒（20Hz，业界 RTS 区间 20~30Hz）**；定点整数：位置 1 单位=1cm、1 格=100、时间全 tick 计数——确定性（BattleSimState.RollChance 种子单出口保留、模拟核心禁 UnityEngine.Random）+回放（同 seed+同命令序=同战局）+与「100=1 格」自洽
- 驱动：单机 Host=BattleSession 本地 Update 累加器推 tick；命令经 LocalBattleTransport（JSON wire）即发即收；客户端渲染 60fps 对 tick 位置插值

### 2.2 确定性护栏四件套（v2 新增，业界标准件，P1 一并落地）

1. **accumulator 累加器模式**（Gaffer《Fix Your Timestep!》标准）：`accumulator += frameTime`（frameTime clamp 0.25s）→ `while (accumulator >= dt) { tick; accumulator -= dt; }`
2. **spiral of death 防护**：每帧最大 tick 步数 clamp——模拟跟不上时整体慢放，不雪崩欠债
3. **双缓冲状态插值**：UnitView 插值=prev/current 两份 tick 状态 + `alpha=accumulator/dt` 混合（比「追最近 tick 位置」观感好，Gaffer "final touch"）
4. **desync hash 钩子**：每 N tick（建议 20）计算战场 state hash 落 BattleRecorder 行——单机阶段即上（成本一行）；后置 LAN 联机直接可用（王者荣耀同款定位手段，其不同步率从 2% 做到 0.03% 依赖此链）

**tick 输入聚合**（护栏第 5 件，P2 随移动命令落地）：拖拽摇杆/点击输入进 tick 输入队列——防单帧多 tick 重复应用、防无 tick 帧输入丢失（业界固定步长输入处理标准做法）。

### 2.3 「1 回合=1 秒」直译表（v1 继承）

| 项 | 现状 | 新值 |
|---|---|---|
| Buff 持续 | RemainingTurns，回合末结算 | 秒制：字段改名换义，到期=施加 tick+时长 |
| Burn/歌声之环/寒冰之棱 tick | 回合末 | **每秒整拍**（tick%20==0，错峰语义简化版） |
| 体力/摩拉回复 | +10/回合（回合末） | **+1/秒**（每秒整拍；初始 60/200 与编入卡增量不变） |
| 昼夜时钟 | 初始 6:00、每回合 +20 分钟 | **每秒 +1 分钟**（时段边界 8:00-20:00 与音乐选池不变） |
| 回合数显示 | HUD 顶部 | **退役**（顶部只留战斗时钟） |
| AI 决策 | 每回合 1 次 | **每 0.5 秒 1 次**（三脑同频） |
| 快照 | 每选择阶段头 | **每秒 1 次**全量（对账/自愈） |

### 2.4 回合机退役清单（新仓/改造段内拆，勿再当 bug 修）

五阶段回合循环、选择倒计时（GetSelectLimitSeconds）、玩家每回合 1 配额、Pass 按钮、完成选择按钮、执行预览（BattleExecutionPreview+preview 布局键）、攻速分桶与片头等待公式、Segment+ack 门控（15s 超时快进）、_playbackSpeed 表现层倍率、LayerBeatSeconds 逐层错峰、升命超时自动确认（保留手动确认/取消）。

### 2.5 新 RTSFlowController

取代 TurnFlowController：职责=开局装配（AssembleRoutine 分帧保留）/accumulator 推 tick 循环/胜负判定（核心摧毁唯一判据不变，同 tick 双灭=平局语义保留）/战斗时钟/退出收口。回合阶段事件驱动的音乐自愈链改为时钟驱动。

## 3. 空间模型：格 → 连续（v1 继承）

### 3.1 坐标与度量

- 单位位置：`int x, z`（厘米；1 格=100=1 米=1 世界单位）。格坐标保留为**地形掩码**（tile 可走性查询）与寻路网格
- **距离度量：切比雪夫→欧氏**全链迁移（ChebyshevTo 全部消费方逐一改：光环半径/视野/部署半径（含星级部署链+部署锚点并集，决策八十八）/溢出转移最近/威胁图/AI 排序/建筑效果半径）

### 3.2 体积与碰撞

- **碰撞圆=受击圆柱统一，直径 0.5 格**（1 格 2×2 容 4 个单位；与旧受击圆柱 0.42 观感最连续）；per-unit 受击圆柱覆写保留（UnitData→UnitState.cylinderDiameter 链沿用），协议核心 0.8 不变
- 碰撞规则语义不变：敌/尸体=硬挡；互不阻挡友军=可穿不可停；地形按 ForceType 分派（Walk/Fly/Amphibious/Knockback/Pull/Jump/Teleport 全保留）。旧「单格体积上限 3（MaxTileVolume/PassesVolumeLimit）」退役——密度由碰撞圆自然限制
- **尸体=死亡位置静态碰撞圆**：占位/阻挡/可被命中/可点选语义全保留

### 3.3 移动与寻路（+业界选型论证）

- 移动命令两形态：**目标点**（点击式：int cm，不限距离走点）/ **方向持续**（拖拽式摇杆：按住期间朝向移动，松手停）
- 移速 stat=厘米/秒（全员 100=1 格/s）；Buff ±10/层直译=±10% 速度；**移速数值域扩展**（旧 -100~100 装不下 100 基线+叠层）
- 寻路=tile A*（静态地形+尸体圆阻塞）+直线段 steering+圆碰撞分离；被敌圆阻挡=停于接触前+短冷却重寻路；移动免费（0 体力 0 元能）
- **选型论证（2026-11-03 调研）**：flow field（SupCom2/行星歼灭）适合数百单位共享目标，gic 一局十几~几十单位远低于回本门槛；且业界实践复盘（jdxdev）证实群体观感问题（蚂蚁线）靠寻路层解决不了、最终都回到 A*+boids 局部力——**tile A*+steering+圆分离=业界对位方案，维持 v1 拍板**
- 移动循环片=移动期间循环播放（决策四十四 loop 机件复用）；「移动 0.18s/格」回放常量退役

### 3.4 部署与站位

- 部署=拖卡出牌区→**自由落点瞄准**（欧氏 ≤200 于协议核心+可走 tile+无圆重叠）→**即时生成**（「部署段先结算」退役）；部署前置=星级链（决策八十八追记二）+锚点并集（决策八十八）——均欧氏迁移不改语义
- 站位合法=可走 tile 内+不与任何碰撞圆重叠；「选择阶段散开/执行阶段收拢」两态退役→重叠自动散开表现保留

## 4. 技能/瞄准/弹道（v1 继承）

### 4.1 自由角瞄准（输入双参照）

- **Direction2D 十字归一退役**（SkillHitResolver.DirectionToDelta/预判十字/CrossDirections 方向域）→瞄准向量（协议千分定点 int 向量）；技能/弹道/移动不再锁 4/8 方向
- **点击式全对齐英雄联盟**：移动=点地走点不限距；技能=点目标点/目标单位即放（射程外钳到圆边）；保留预览指示器
- **拖拽式全对齐王者荣耀**：按住技能键拖轮盘→方向+距离→松手即放、超圆钳边、拖回取消；现有拖拽轮盘结构保留，落点从格→连续点
- 瞄准贴片格高亮（AimHighlight_{x}_{y}）退役→**真圆/线段/落点指示器**（射程圆+AOE 圆预览+命中敌高亮复用推荐分色）；WorldToCell 拾取改射线/点拾取
- 指定单位型（IsUnitTargeted）：点击式=点选目标单位；拖拽式=头像盘（既有）

### 4.2 范围=真圆

- **AOE 真圆半径字段**取代「同格成员聚合」：安柏箭矢/芭芭拉水球命中伤害范围=**半径 50**（0.5 格）
- 线形技能（霜袭/箭矢）=线段×受击圆求交（ProjectileResolver 线段-圆数学现成复用）；LineBurst 整线语义=线段全长达人
- 光环/治疗/视野等一切半径=欧氏（歌声之环/冰棱半径 1 格→100 直译；冰棱薄冰冻面/BuffConfig.作用半径同链）

### 4.3 CD 与释放速度（战技=MOBA 普攻地位）

- **攻击 CD=3 秒**：战技+AI 普攻条目（Normal）同享——Normal 无 CD 会被 AI 每 0.5 秒连放；per-skill 覆写后续按需；CD 从施放起算，常量收口 BattleMetrics
- **爆发 CD=6 秒+元能门槛双 gate**（costs 条目全保留：安柏 30/凯亚 40/芭芭拉 100；能量条/溢出转移/命座加成链不动）
- **释放速度=1+攻速/100**：时轮 clip 发射/命中时刻与动作片播放速率同乘该倍率；**攻速全员 0**（资产迁移 40→0；武器攻速词条未接线天然失效）
- 元能获取：移动 +10 来源删除；战技命中 +10（同技去重）/延奏/协奏/光环来源保留

### 4.4 弹道

- 弹速默认 8 格/s=**800cm/s**；射程上限=clip.maxRange（安柏箭矢/箭雨=800）；虚空消散/命中点千分定点协议保留
- 投射物编译序=命中时刻序（两遍法 hitT 排序保留）；LineBurst 先于投射物的旧例外随时刻序收口自然消解

## 5. 经济与操作（v1 继承+基线漂移）

- 配额制退役——行动即时上交即时结算；**体力=手动操作唯一节流**（层级表不变：眷属 0/伙伴 5/魔神 10；AI 伙伴自主行动仍耗玩家共享池=「伙伴轮休」机制延续）
- 回复 +1/秒；初始体力 60/摩拉 200 与编入卡增量照旧
- **势力技能仍 0 体力无 CD**；号令链（玩家触发伙伴/魔神施放）保留；被号令伙伴免除行动体力语义保留
- **购买=即时通道天然兼容**（BuyCardExecutor 不占配额、即时校验即时入账——零改动）；回合末建筑效果→每秒整拍（§9）
- 手牌无抽牌/卡不消耗不变；升命=EnterUpgradePending 待确认态保留（超时自动确认退役）
- **装备系统（决策八十/八十一，v2 新增适配）**：数据驱动+耐久/堆叠双方案+死亡掠夺+采集恢复钩子全保留——纯单位级数据链，天然兼容连续空间，接口级适配（采集钩子挂 §9 资源点秒化后的采集事件）
