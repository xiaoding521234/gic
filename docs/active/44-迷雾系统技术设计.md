# 44 - 迷雾系统技术设计（迷雾批 2026-10-17）

> 拍板=docs/18 决策七十七；玩法设计背景=docs/03 §3.6。本文=实现真源。
> 需求原话：①对战迷雾——完整看见地形格子、半透明标记未探索（开房间对战时不用记忆地图）；
> ②任务迷雾——未探索格替换为统一混沌地形、不知道格子是什么地形（游玩任务时的探索感）；
> ③迷雾视野改名探索视野。

## 1. 架构定位

**纯表现层系统**：客户端本地计算本方阵营探索集，Host 模拟核心、协议、快照**零感知零改动**
（docs/18 决策一「迷雾=渲染层最后补」的既定归属）。LAN 各端独立计算=天然各自视角；
改内存可作弊=已知边界，随 N1 信息隐藏批（per-player 快照过滤+visibilityScope 命令过滤）收口。

## 2. 数据位与开局链

- `BattleFogMode { None, Skirmish(对战), Mission(任务) }`（GIC.Data，`Data/Battle/Protocol/BattleFogMode.cs`）。
- `BattleLaunchConfig.FogMode`（默认 None）：**BuildFromRoster 置 Skirmish**（房间对战恒开，拍板 D2=A 无开关）；
  沙盒/调试直开/观察局=None；任务系统（后续批）置 Mission。
- `StartBattleEvent.FogMode`（int 载荷）：host 广播/OnStartBattleReceived 重建两路透传，LAN 各端同模式。
- `BattleScreen.AssembleRoutine → _player.ConfigureFog(mode, 本端玩家解析器, 队伍解析器)`
  （解析器 lambda 惰性求值——ConfigureFog 早于 session 创建；本端口径=BattleHud.ResolveLocalPlayerId 同款
  SelfPlayerID→Offline/P1 回落，队伍=session.GetTeamOf 门面，LAN 客户端无 Sim 也成立）。

## 3. 探索集（BattleFog.cs，View/ 层控制器）

- 挂 BattlePlayer（`Fog` 属性，EnsureFog 建件；模式 None 不建件零开销）。
- **揭雾**：以本方阵营**存活单位**（含协议核心等建筑；尸体不探索）的**当前视觉位置**为心、
  **探索视野**（UnitData.探索视野，切比雪夫，**Unspecified 回落 1**——2026-10-17 追拍一默认 2→1；
  安柏/协议核心=2 资产值，开局核心周界 5×5）逐帧画圈标记；
  移动播放途中按视觉位置即时揭雾（走一路揭一路）。
- **单调有进无出**（docs/03 §3.6「探索过永久可见」）；队友单位共享揭雾（TeamType 聚合）。
- 探索视野真源=**快照 exploreVision**（追拍六「1命视野真源化」：Host BuildUnitState 从
  UnitStats.VisionRange 终值填充=config 基值+1命 StatBoost——升命中途生效随快照到达；客户端首选
  直读，0=未填回落旧链 unitName→UnitConfig 基值；视野缓存随快照换代失效）。Host 账本 RevealFog
  同读 stats 终值——两侧统一升档。开局诊断日志 `[迷雾] 揭雾视野: ...`（配置值≠实际半径分歧锚点）。
- 身份未解析（容器暂不可达）不评估——防默认队 A 短暂误判（LAN 客户端防线）。
- 消费方 API：`IsExplored(cell)` / `IsUnitVisible(UnitState)`（我方/队友恒真；敌方=所在格已探索）/
  `IsEnemyActor(unitId)`（归属方判定，数字门控用）。

## 4. 两种迷雾渲染（BattleBoard）

| | 对战 Skirmish | 任务 Mission |
|---|---|---|
| 形态 | 半透明暗雾面（合并单 Mesh，每格按**视觉表面高度**+抬升——水/沼/薄冰含波峰带） | 不透明混沌盖（顶+四侧箱盖合并单 Mesh，y 0→0.505，边界外扩 5mm） |
| 地形可见性 | 完整可见（RA2 式，雾只作「没去过」标记） | 零泄露（真地块全部暴露面被罩住；贴图=AI 生成深渊暗纹 Resources/UI/Battle/ChaosFog 1024） |
| 虚空格 | **不盖**（虚空豁口正常可见，拍板 D6） | **同罩**（整片未知区域浑然一体不泄露地图轮廓，拍板 D6） |
| 草簇 | **同过滤**（追拍四：草簇是立牌式竖直面，穿出贴地雾面在未探索格漏亮——「只有地形变暗了草簇还是亮的」报障修复） | 同过滤（草尖穿盖漏地形） |
| sortingOrder | -2（新常量 FogOverlaySortingOrder） | 不透明+深度写=与透明件排序体系正交 |
| Inspector | 对战迷雾色/迷雾面抬升（代码默认值免场景手术） | 混沌盖高/混沌盖外扩/混沌盖材质（null=Resources 自建） |

两模式草簇过滤同款（ApplyFogChanges 统一 RebuildGrassDecor 探索谓词）；固定种子+rng 恒消耗=
已探索格草簇布局跨重建逐位稳定。

层序变更：水面/薄冰 **-2→-3**（WaterSurfaceSortingOrder 常量）——雾面（-2）恒罩水面/冰面、
恒在底座盘（-1，仅出现在已探索格）之下；盘与雾面同格互斥（单位所在格恒已探索）不同格屏幕不叠。

## 5. 单位与特效隐藏（拍板 D1=docs/03 §3.6 定案「看不见单位/建筑」+追拍二）

- 敌方单位所在格（视觉位置）未探索=隐藏：`UnitView.SetFogHidden` ——立牌 sprite/视频 quad/
  底座盘/描边环四渲染件 **MeshRenderer.enabled 意图态覆盖层**（部署过渡先例；**勿动 GameObject
  激活态**防 VideoPlayer 停摆）。隐藏期间视频/动画照常播（只是不画），走进已探索区无感现身。
- 意图态三层结构（UnitView.ApplyRenderables 单出口）：`_spriteVisible/_videoVisible` 意图位由
  建件/首帧落地/解码失败回落三路径维护，落地=`意图 && !IsFogHidden`——盲开全部会错
  （视频路径下 sprite 本应禁）。
- 头顶条：BattleOverheadBars Update 按 `view.IsFogHidden` 整簇 SetActive 自隐。
- 选中弧光：敌方单位被选中后走进迷雾——BattleHud.UpdateSelectMarkerFog 每帧巡检随隐
  （重新可见不强推重显，重新选中自然恢复）；描边走 avatar 材质=渲染器禁用自动隐。
- **敌方特效逐格门控（追拍二「敌方安柏射出的箭矢应当只有飞到已探索格才显示」）**：
  CreateProjectileVisual 全箭矢工厂（飞行/消散/天降/落地滞留）单点注册
  `BattleFog.RegisterProjectileVisual(go, 施法者队伍)`——**我方特效不注册恒显**；敌方特效逐帧按
  当前位置所在格探索态显隐（渲染器缓存+幂等开关）；注册表按 Unity null 探测自动剪除。
- 我方/队友恒可见；开局看不见敌核心（靠出生点石路地形特征推断对手方位=docs/03 设计意图）。

## 5b. AI 雾限（追拍三拍板「需要 AI 也受雾限」+「他们自带透视协议核心的位置，否则无法自主攻城」）

- **Host 迷雾账本**（BattleSimState 迷雾账本节）：按队伍记探索集——`FogMode`（BattleScreen 装配期
  注入，None=AI 不受限：调试直开/沙盒/观察局零回归）+ `RevealFog()` **全量幂等揭雾**
  （BeginSelectPhase AI 决策前单钩——WEGO 全行动先提交后结算=回合边界同步即覆盖决策时态，
  无需逐命令挂钩；半径=RawData.GetEffectiveExploreVision 与客户端同源）。
- **AI 可见性单出口** `sim.IsUnitVisibleTo(队伍, 敌方)`：同队恒真；**敌方核心（Core tag）恒真**
  （自带核心透视——眷属 v7 核心锚定/J-4 伙伴推核心/终局判据/战力核心 HP 全零回归）；
  其余敌方=所在格已被该队探索。快照态重载 `IsEnemyStateVisibleTo`。
- **消费方收口（两中心+七散点）**：`BattleHeuristics.FindEnemiesByDistance`（眷属目标序/伙伴敌锚/
  FindNearestEnemy）+ `PreviewLineTargets`（眷属开火方向/伙伴评分/威胁图预测——WouldHit 预检为
  超集无碍：雾内敌不产开火方向）；CompanionBrain 五循环（自施放爆发敌计数/自保/光环敌/视野敌集/
  最近敌距）+AIStrategist 战力比（雾内敌不入比值；核心 HP 恒计）+OpponentThreatModel.Build
  （雾内敌不产威胁）。PlayerQuotaBrain 全我方域零改动。
- **结算真值永不消费**（EffectCompiler/执行器照旧全量结算——雾限 AI 决策输入，不改变命中/移动）；
  观察类情报层（OpponentProfiler 命令流记账）=已发生行为的观察，与玩家可见的投射物/数字同口径，
  v1 不滤。
- 预测递归自洽：威胁图 PredictAction 预测敌决策时，敌视角目标经同一收口按**敌队**探索集过滤。

## 6. 泄露口径（拍板 D4：地形类允许泄露、单位类零泄露；**追拍二区分规划期/执行期**）

规划期（一切「因隐藏单位存在与否而不同」的表现按「不存在」处理）；地形类信息（移动路径绕行、
部署落点合法性、箭矢插地/沉水形态）如实显示。**执行期反馈按归属方**（追拍二）：我方特效
（箭矢全程、命中伤害数字——即便目标在迷雾内）恒显；敌方特效/数字迷雾内隐藏。

| 消费点 | 实现 |
|---|---|
| 瞄准候选（点格轮换/同格列表/拖动头像盘） | CollectAimTargets（契约敌队分支）+ FindUnitAt + UnitsAtCellOrdered 按 FogVisible 滤 |
| 预判描边/命中竖线/**方向推荐色**（拍板原话案例「安柏战技变推荐色=泄露这个方向有敌人」） | UpdateAimHitPreview 对 PredictDirectionHits 结果后滤 |
| 方向推荐/移动推荐/部署红格（占用判定泄露隐藏敌人占位） | ComputeAimCells/部署预览吃 **FogFilteredSnapshot**（迷雾内敌方按不存在的滤后快照） |
| 执行预览行（敌方行动预告=意图泄露） | BattleExecutionPreview.Build 跳过迷雾内敌方条目 |
| 敌方投射物/箭雨/落地箭 | RegisterProjectileVisual 逐格门控（追拍二；我方不注册） |
| 伤害数字 | **归属方口径（追拍二修订）**：我方命中恒显；敌方施放且目标隐藏（自奶/自增益）才抑制——PlayDamageCoroutine 带 actorUnitId+IsEnemyActor 判定；元能数字维持目标隐藏侧抑制 |
| 命令流照播不滤 | 敌在雾内移动=看不见的位移（快照权威自愈）；箭矢从雾中飞出=RA2 式戏剧感保留 |

## 10. 追拍九（2026-10-23 实战报障「AI 无视近处敌直奔核心」——§5b 账本口径勘正：战术视距）

§5b 首版「AI 可见性单出口=所在格已探索」把**战术感知**也一并压到探索账本（探索视野仅 1~2 格）
——低于决策三十一攻击视野（5）的既定语义（v7「攻击视野内才追」/J-4「自身攻击视野内无普通敌
才推核心」），雾局下 2~5 格未探索近敌对 AI 完全不存在（实战：敌方凯亚无视更近的我方凯亚直奔
协议核心；观察局实锤 d=3 敌不在锚集）。**勘正=决策感知双层口径**：

- **战术层（决策单位视角，新）**：`BattleHeuristics.PerceivesEnemy(sim, self, enemy)`——雾账本
  可见（IsUnitVisibleTo 原口径）**或**自身攻击视野内（`IsEnemyInTacticalSight`：切比雪夫 ≤
  GetEffectiveAttackVision，视距源=决策单位本体——**勿做团队共享视距**：安柏攻击视野 24，共享
  =团视距溢出杀死迷雾）。消费=FindEnemiesByDistance（眷属 v7/伙伴敌锚/FindNearestEnemy）+
  CompanionBrain 战术五循环（光环敌计数/最近敌距/自保/光环覆盖/先锋视野敌集——视距源=决策
  单位/先锋）。
- **战略层（团队视角，原样）**：威胁图（OpponentThreatModel）/AIStrategist 战力比/
  OpponentProfiler/PreviewLineTargets（开火方向/评分目标）仍走 IsUnitVisibleTo 账本口径——雾限
  战略情报的牙齿保留。已知边界：攻击视野内近敌「锚/评分看得见，但威胁图不设防、技能开火目标
  仍账本限」——单位贴身 1 格后账本揭开除雾自愈。
- **配套修复（同批）**：CompanionBrain.RememberMoveAnchor 排除 IsCore——核心不入 E-3 锚锁
  （锁核心=新出现的近敌被永久无视；J-4 每回合重插即续位、无需锁；观察局 S2 实锤）。
- **验证**：观察局三相位（d=3 接战 / d=6 恢复推核心=视野外不关心边界 / 回 d=3 重接战）+
  12 回合部署升命回合推进零回归。
