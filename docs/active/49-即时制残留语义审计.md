# 49-即时制残留语义审计（P6 收尾 gate）

> **审计日期**：2026-11-05
> **审计基线**：`3e3504d6`（P6 批追记，即时制 P0~P6 代码项全部落地）
> **审计对象**：`Assets/_Scripts` 全部 `.cs`（战斗 132 文件）+ 配置资产 + 协议层
> **方法**：静态检索 + 调用链人工核验（Mac 侧无 Tuanjie 编译环境，**未做运行时验证**；定级依据=代码路径可达性 × 语义偏差幅度）
> **背景**：决策九十五选择案 A「本仓就地改造、改即时不改灵魂」（docs/active/48 §0.3/§13）。本审计=对「保留面」与「新骨架」接缝处的系统性排查，不针对已明确的 P6 待办（docs 改版/调参批）。

## 0. 结论摘要

**就地改造的整体判断成立**：空间度量主链已干净（`ChebyshevTo` 全仓 0 命中、非 View 层 `WorldToCell/CellToWorld` 0 命中），时间轴/移动/技能主链已切新轨，回放 harness v2 覆盖模拟层。

**但接缝处确有系统性残留**，共登记 **26 项**：

| 定级 | 数量 | 说明 |
|---|---|---|
| 🔴 高（行为已偏离设计） | 6 | 会改变玩法数值/节奏或造成可见 UX 回归，建议 P6 收尾前修 |
| 🟡 中（规则不一致/双轨） | 11 | 同一规则两套判定、客户端预测与 Host 不一致、命名误导 |
| ⚪ 低（死代码/命名） | 9 | 不影响当前行为，但会误导后续修改 |

**最高危的根因不是"旧代码没删"，而是三处"语义被悄悄拓宽/单位被悄悄换掉"**：
1. `Selecting` 相位被当作 Running 常驻 → 所有"选择阶段专属"逻辑变成常开；
2. `turnNumber`/`CurrentTurn` 变成逻辑秒 → 所有"每回合/第 N 回合"判断变成"每秒/第 N 秒"；
3. 客户端 `_flow` 恒 null → 仍走 LAN 客户端派生路径，其中时钟公式还是"回合 ×20 分钟"。

## 5. 高危项详述（建议优先处理）

### 🔴 C4 / D1：客户端建筑窗灯昼夜 20 倍速

```
BattlePlayer.cs:405-407
int battleMinutes = _flow != null ? _flow.BattleTimeMinutes
    : TurnFlowController.BattleClockStartMinutes
      + TurnFlowController.BattleClockMinutesPerTurn * Mathf.Max(0, (LatestSnapshot?.turnNumber ?? 1) - 1);
```

`BindFlow` 已无调用方（`BattleSession.cs:178-179` 注释确认 `_flow` 恒 null），所以**单机也走 fallback**；`turnNumber` 已是逻辑秒，`BattleClockMinutesPerTurn=20`。结果：战斗 10 秒 = 窗灯 9:00（Host 权威时钟 6:10）。修法：fallback 改用 `BattleMetrics.BattleClockMinutesPerSecond`，或让 HUD 直接从 session 门面取 `BattleTimeMinutes`（`BattleHud.cs:900` 已这么取，BattlePlayer 这一处是漏网）。

### 🔴 C1：Buff 计时与效果拍不同频

`ResolveSecondBeat` 每秒 `RemainingTurns--`（`:486`），但 `OnTurnEnd()` 只在 `effectBeat`（tick%40）执行（`:485`）。3 秒 Burn = 1 次伤害而非 3 次；2 秒光环 = 1 次。两条修法二选一：
- 计时也按效果拍递减（时长语义变 2 秒/拍，需重定数值）；
- 或效果拍恢复每秒（放弃 2026-11-04"时间翻倍"追拍）。
无论选哪条，**当前是"计时按秒、效果按 2 秒"的混合态，与任一设计口径都不自洽**。

### 🔴 C2 / C3：AI 与建筑周期按"秒"解读"回合"配置

`AIStrategist.发育期回合数=3`、`OpponentProfiler` 首回合观察、建筑 `效果周期=5` 均为回合制标定值，现在直接按秒生效。建议在配置层显式改名（`发育期秒数`/`效果周期秒`）并重标数值，避免"改了名字但没改值"的第二轮漂移。

### 🔴 A1：HUD 每 0.5 秒执行一次"新选择阶段"副作用

`RTSFlowController.RunAiBeat()` 每 0.5 秒 `OnPhaseChanged(Selecting, second)`（`:156`），HUD 的 else 分支没有幂等保护。建议：HUD 只在 `second` 变化或相位真变化时做"新回合"副作用，或把 AI 节拍事件拆成专用事件（`OnAiBeat`），不再复用相位事件。

### 🔴 B1：AI 部署仍走旧格判定

玩家自由落点（圆碰撞）vs AI `deployCell`（格体积≤3）。建议 AI 部署也生成 `deployX/deployZ`（格心 cm 即可），统一走 `IsDeployPointValid`；`MaxTileVolume` 与 `IsDeployCellValid` 一并退场。
