# 光环位置价值与支援形态切换技术设计（G 批次）

> 2026-10-03 立项。用户设计输入两条：①「芭芭拉的光环可以给周围敌人挂水，而且不需要体力，因此她也适合去前线战斗，配合凯亚打出冻结或安柏打出蒸发」；②「芭芭拉的大招还可以复活队友，如果她在前线先死，那么就没人复活队友了。芭芭拉既可以在前线战斗，也可以在后方稳定提供复活。我们该怎么办」。
> **机制事实基座（先厘清）**：①闪耀奇迹=**发放**光环非转移（2026-10-03 用户勘正——施加只给目标挂新实例，施法者持有不消失；芭芭拉 OnDeploy 命座自带光环恒在）；②歌声之环 tick=半径内敌 20% 攻**水伤**（经 CompileElementalDamage 统一出口→命中敌**附着水**）+半径内我方治疗 5% 施加者 maxHp+理智（含持有者自己）；③**复苏=无限程**（单位指向型无距离域）——「稳定提供复活」是**生存问题**不是站位问题；④光环半径 1（2命 2）与治疗半径同源——「顶敌前」与「贴身奶前排」位置重合。
> **方案拍板（2026-10-03 用户拍板「开工」按推荐）**：光环位置价值维度+**血线/威胁预警双门控形态切换**——满血=前线形态（光环贴敌+反应链联动），血线 <60% 或威胁图预警预期承伤 ≥50% hp=保险形态（贴敌分归零+自保×3 后撤）。复活保险由「她活着」+形态切换保命承担，被一回合集火秒杀=合理战术代价（敌方优先拆奶妈的战术深度）。
> 关联：docs/active/33 §4（E-3 反应预期分——队友脑自发追打挂水目标=联动闭环零新机制）、docs/active/34（F 批站位评分器/自保维度——G 批是其维度扩展）、docs/18 决策三十三。

## 1. 体系闭环图

```
芭芭拉（OnDeploy 自带光环）满血顶敌前 ←—— 光环敌覆盖分（G-1 驱动）
→ 回合末光环 tick：半径内敌挂水（水伤附着）+ 半径内我方奶（前排队友受益）
→ 凯亚/安柏的 E-3 反应预期分已自动生效：挂水敌=冻结/蒸发候选加价（队友脑自发，零新机制）
→ 凯亚挂冰后她的光环 tick 水伤吃冰=反向冻结（双向联动）
血线 <60% 或 威胁图预警 → 保险形态（G-2）：贴敌分归零+自保×3 → 后撤到远离敌仍奶程内
→ 光环 tick 含持有者自奶 → 奶回安全线 → 自动重返前线
复苏（有尸体=100 分最高档）无限程随时可放——形态切换保她活着=保复活保险
```

## 2. 改动清单

### G-1 光环位置价值
- `BattleHeuristics.AuraRadiusOf(unit)` 新原语：遍历当前 Buff 找半径型 tick 光环（现役白名单=SongOfLifeBuff/IcicleBuff——is-pattern 显式扩展点，新光环类落地时补一行；返回实例真值半径含命座加成；无光环=0 天然不消费）。
- `ScoreSupportCell` 新增第 5 维：**光环敌覆盖分**=`光环半径内敌数 × SupportAuraPerEnemy(6) × 档案「光环贴敌权重」`——仅 auraRadius>0 且权重>0 时计。
- 档案新字段「光环贴敌权重」float 默认 0（全单位零迁移；输出型不进支援评分器零影响）。

### G-2 形态切换（双门控）
- `SupportStanceOf(sim, unit, team, threat)` 新私有方法：**血线门** hp% < `SupportStanceRetreatHpPercent`(60) 或 **预警门**（threat 非 null 时）`ExpectedDamageOnAlly[我] ≥ hp × SupportStanceRetreatThreatPercent(50)%` → 保险形态；返回因子 `SupportStanceSafeFactor`(3) 或 1（前线）。
- 三处消费：①光环敌覆盖分×（前线 1/保险 0）②SelfPreservePenalty 返回值×因子（保险形态贴敌格扣 45——自然选出远离敌仍在奶程的格；四个落点档一致）③threat=null（配额脑路径）时仅血线门。
- 确定性：两门均为纯函数判据，零 roll。

### G-3 发放语义修正（用户勘正落地）
- `ScoreUnitTargetBurst` 排除条件「已持有」→「**已满层**」（活体 `Buffs.Find(Type)?.IsAtStackCap()`——快照 BuffState 无层数/上限字段）：3命 C3StackLimit=2 时给 1 层持有者施加=叠层=有增益，旧逻辑漏此候选；注释同步勘正（发放语义：发放不改施法者持有）。

### G-4 资产+收口
- 芭芭拉档案：光环贴敌权重=1、自保权重 1→0.3（前线定位轻自保）、支援贴近距离 0（自动）。
- 文档：决策三十四（docs/18）+docs/17 指针+docs/11+gic-new-unit skill 档案字段（八→九）+记忆。

### G-5 验证局三轮返修+探针定位（2026-10-03 深夜，docs/14 §115 harness+反射探针法）
- **第一轮**（前瞻梯度/保险后撤模式）：同 seed 战局逐位重放=零差异假象——**全员幸运 0 时 roll 从不消费→seed 对战局无效**（战局纯由确定性评分决定）；显式注入 Environment.TickCount 也不变=确定性系统的实证。
- **探针定位**（反射调 private 评分方法 dump 逐格明细——比纸上推演高效一个量级）：①档案/原语/签名全生效排除「代码没编译」假设；②逐格同分=「伤员=自己 → 旧位奶程锁 → 永久驻位」（修：**woundedIsSelf 时 distToWounded 恒 0**——治疗半径随施法者走）；③**回合 2 Left×3 之谜破解**：地形图 dump 实证环湖地图（A 西 B 东南、中央大湖）——**B 芭（镜像敌奶妈）恰为 A 芭最近敌**（切比雪夫 8<凯亚 9）→ E-3 锁延续 → 绕湖南岸 BFS 首步=Left → **「BFS 首步×直线推力」越过路径拐点**=纯西行滑边 (0,3)——**docs/14 §114 同族**（眷属修了直线前缀、伙伴锚循环漏修）。
- **三修终版**：①**锚循环直线前缀化**——新原语 `BattleHeuristics.ApproachStraightPrefix`（BFS 首步方向上「到目标距离严格递减」逐格截断=路径开头连续直线段，§114 同判据）替换步长钳；②**前瞻公式勘误** `(Base−dist)×PerStep`（旧斜率式 Base−dist×PerStep 在 5 格外恒 0）；③**站位评分器三态接管**——伤员锚/光环贴敌（无伤员+有光环+权重>0：自体假锚+光环前瞻主导——治「无伤员阶段走锚循环、光环驱动不参与决策」的接管错位）/保险后撤。
- **终验局全绿**（28 回合 **A 方首次获胜**、A 核存活）：A 芭完整行为弧线=开局理性驻奶（VitalityBurst 群奶引擎）→ 回合 12 伤员驱动上前线 → 回合 13~16 **主动推进距敌 8→1 顶到敌前**（不再缩角）→ 贴敌水球+光环挂水 → hp 破 60% **后撤 1→9 格**（不再站桩挨打）→ 自奶回血 → 全队推掉 B 核获胜。B 芭对照=全程保守驻奶（AI 玩家侧另有温迪护航）——双方支援性格分化。

## 3. 验收（复测清单）

1. **前线形态**：满血芭芭拉（带光环）站位倾向敌旁（光环半径内敌越多越优），配合凯亚/安柏触发冻结/蒸发链。
2. **形态切换**：她血线跌破 60%（或威胁图预警大额集火）→ 下回合后撤远离敌；被奶回安全线 → 重返前线。
3. **发放语义**：闪耀奇迹施放后**她的光环仍在**（继续贴敌挂水）；给已持有未满层者（3命）施加不再被排除。
4. **复活保险**：有我方尸体时复苏仍恒最高优先（保险形态不影响技能档）。
5. 输出型/凯亚零回归（自保 0+光环权重 0——凯亚寒冰之棱本批不配贴敌权重，观察后再配）。
6. 同 seed 一致。

## 4. 遗留

- 凯亚（寒冰之棱）贴敌权重配置=观察后拍板（本批只芭芭拉）。
- 多支援型并存的角色分工（谁前谁后）=场上真出现双支援再议（Halo 式分配，v2）。
- 光环敌覆盖分的反应联动价值未显式建模（队友 E-3 反应分自发消费已闭环——显式建模=重复，不做）。
