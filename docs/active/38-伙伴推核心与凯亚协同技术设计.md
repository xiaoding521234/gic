# 伙伴推核心与凯亚协同（J 批次）技术设计

> **拍板（2026-10-04 用户原话）**：①「先提交当前的」（伤员锚退役+H-3b 已提交 f3c8b86）；
> ②「伙伴应当去推核心，攻击视野内没有其它敌人时」；③冻结协同分/④凛冽轮舞语境评分/⑤爆发态
> 贴脸驻位=按推荐做；⑥输出型存活门控=不做（先锋吃伤+奶位体系的存在意义，撤了战线崩）。

## 1. 现状核验（2026-10-04 代码实读）

- 凯亚=输出型近战先锋：CR-Move 驻位基准=`AttackRangeOf`（霜袭线 2 格）→ 恒距敌 2 开火；
- 反应预览分只给增伤反应（蒸发/融化 `effPerTarget/2`）——**冻结控制反应恒 0 分**；
- 凛冽轮舞=`SelfCastBurstBuffScore` 45 平分×爆发优先权重，仅 `IsAtStackCap` 防重放——零语境感知；
- 寒冰之棱半径=1（3命 C3 才 2）——距敌 2 驻位=光环 tick 够不到敌、冰附着链空转。

## 2. J-1 冻结协同分

- 反应预览增伤分支旁补冻结分支：`reaction.ReactionType == BattleCommand.ReactionKindFreeze → +FreezeControlScore(25)`。
- 意义：芭芭拉光环挂水后，凯亚霜袭打水附着目标=冻结（目标跳 2 回合行动）——双芭凯联动主链接通；25 低于斩杀 80、高于集火每档 3——只影响同分域目标选择、不压斩杀。
- 通用性：对称作用于一切单位（芭芭拉水球打冰附着敌同样加分）。

## 3. J-2 凛冽轮舞语境评分

- `ScoreSelfCastBurst` 加 sim 参数：即将施加的光环半径（新原语 `BattleHeuristics.AuraRadiusOfBuffType(BuffType)`——施放前 Buff 未上身，`AuraRadiusOf` 查不到；白名单同源）内每存活敌 +`SelfCastBurstPerEnemyScore`(15)。
- **语义修正（较原提案）**：空场施放≠浪费——寒冰之棱永久（碎裂才消失），赶路期施放=预载、到前线即满层生效，故保留基础分 45 照常放；加成的真实作用=贴敌群时（45+15×N）优先于常规攻击（霜袭双目标≈82）**先放爆发**——tick 从接战首回合末就吃满。
- 满层 `IsAtStackCap` 防重放照旧；配额脑操魔神档共享骨架同享受。

## 4. J-3 爆发态贴脸驻位

- 锚循环敌锚驻位距离：持有半径型 tick 光环（`AuraRadiusOf` 单源）且半径<攻击射程 → 收紧到光环半径（凯亚：爆发后 2→1）。
- 配额保障（H-3b 同族）：收紧就位移动 Offer 托底 `SupportAuraTakePositionScore`=95 压攻击档——一次性就位成本（移动一回合），就位后攻击+光环 tick 双通道；斩杀 +80×激进度恒赢。
- 联动闭环：冰棱 tick 走 `CompileElementalDamage` 统一出口（决策二十三）=半径内敌逐层冰伤+无反应命中附着冰——贴脸后芭芭拉挂水的敌=每回合末**冻结链**。
- 附带作用面：歌声之环持有者（芭芭拉支援 fallback 路径）同样收紧（半径 1<水球 5）——与光环贴敌语义一致，属预期泛化。

## 5. J-4 伙伴推核心

- 实现（锚序构建段，E-3 lock 插队之后）：自身攻击视野内（`GetEffectiveAttackVision` 回落 5，眷属 v7 同口径）无普通敌单位（`IsBuilding` 不算「其它敌人」）→ 敌协议核心（现役唯一建筑=双方核心，眷属 v7 同识别）插队锚序首直奔推进；视野内有普通敌=原最近敌锚序零变化。
- 与眷属 v7 的差异（刻意）：眷属=核心永恒目标+视野内且严格更近才追；伙伴=视野内有敌照常最近敌锚序（伙伴是战术层，E-2/E-3 协调全套保留），仅「无可见敌」时切换推核心。
- 核心插在 lock 之后：无视野敌时推核心优先于上回合锁定（锁定防两敌间震荡，无可见敌时无震荡可言）。

## 6. 复测清单

1. **冻结联动**：芭芭拉光环挂水的敌，凯亚霜袭优先打它（vs 打未挂水敌）并出冻结；
2. **凛冽轮舞时机**：接战期（敌贴身）先放爆发再攻击；赶路期照常预载不囤积；
3. **爆发态贴脸**：凛冽轮舞激活后凯亚从距敌 2 收紧到距敌 1（一次移动后就位），光环 tick 开始命中+冰附着；
4. **推核心**：清完视野内敌后伙伴直奔敌方协议核心；核心附近有敌进入视野时回最近敌锚序；
5. **回归**：无光环单位（安柏/丽莎）驻位与锚序零变化；斩杀仍恒赢就位托底；配额脑/眷属脑零变化。

## 7. 遗留

- J-1 冻结分对已冻结目标的重复冻结（刷新时长）未降档——v1 不区分，观察后再评。
- J-2 常量 15/敌为估值起点，手感不对调常量勿改结构。
- J-4 伙伴推核心未含眷属式「比核心更近才追」约束（伙伴视野内有敌=照常最近序）——实机若出现「绕开核心旁守军」观感问题再议。

**四刀返修（全在 CompanionBrain，编译 0 CS 错）**：
1. **J-3 托底带限制**：贴脸 95 托底只在「锚距 ≤ 原攻击射程」（射程内收紧带）生效——射程外=接近阶段走常规评分（有攻击候选时攻击赢）；旧版任意锚距托 95=凯亚弃战奔锚（T6 探针实锤 attack52 vs move95）。
2. **保险形态血线门补近敌判定（W1）**：`SupportStanceOf` threat=null 路径——hp<60% 且近敌 ≤`InsuranceDangerRadius`(5) 才保险；无近敌+低血=安全区随军（观察局实证她在 7+ 格无敌区因 49% 血驻场 15 回合、先锋前排单打至死）。配额脑威胁图路径原样。
3. **追赶托底 60（评分器路径补齐）**：T15 探针实锤尸体线自奶 42 > 追赶裸分 40（水球打尸 OnHit 自治疗=拍板 A 合法战术）——先锋/伤员追赶期（锚=真实单位、超伴随半径）的评分器移动 Offer 与 BFS 兜底同享 `VanguardChaseFloorScore`(60)：压常规单体技能（含尸体线自奶）、低于群奶/救命奶（75-90）与就位托底 95。
4. **穿占虚 Offer 修复（G 批「占据格跳过续评」保守近似勘正）**：评分器射线遇占据格——敌/尸体/未开互不阻挡的友军=**硬阻断 break**（执行层停格前，越格落点=虚假目标；实证：芭芭拉被 U11 尸体挡 (3,13)、Right 3 连续多回合零位移白走+元能+10）；仅移动者开互不阻挡且占据者=友军才跳过续评（CanEnter 同判）。
