## 2. 部署前置（2026-10-23 追拍：星级链，梯度制/科技等级整体作废）

- 原 `BuildingTech` 枚举（低科/中科/高科+`BuildingTechHelper.FromStars` 换算）**已全量退役删除**（2026-10-23 拍板「不再划分科技等级」）。
- **星级链前置**（`DeployUnitExecutor.PassesBuildingStarGate` 建筑分支校验）：
  - 部署 1★ → 自己有 **Core tag 建筑在场**（存活；协议核心开局在场、被打掉即判负，故恒满足，仍显式校验）；
  - 部署 N★（N≥2）→ 自己有 **N-1★ 建筑在场 ≥1**（存活、任意同名——2★ 要 1★、3★ 要 2★、以此类推）；
  - **高星不抵低星**（旗帜全灭后 2★ 也不可部署，须先重铺 1★）；
  - **不共享队友**（2v2 各算各——判定一律按 OwnerPlayerID 过滤，不走 TeamType）。
- **协议核心 5★**：开局在场、不受部署前置约束；5★ 恒≠N-1(≤4) 天然不占链位（部署 4★ 要 3★ 在场，核心帮不上）。
- **每种建筑上限 3**（拍板 #4 勘正 2026-10-22：原「存活建筑总数 3」作废）：部署时校验=自己存活的**同种**（同名）建筑数（非 Core tag）<3——3 座旗帜+3 座餐馆同场合法；含尸体问题不存在（消散不留尸体）；拆掉立即释放名额。
- 客户端镜像：`CanDeployEnterPreview` 加同口径检查（星级链/上限不满足=红格）；拖出拦截 toast（PopupText.Battle_TechRequired——**键名 Tech=内部标识符沿用**，2026-10-23 文案勘正为「需先部署上一星级的存活建筑」，§7）。

## 3. 建筑部署分支（复用 DeployUnit 行动）

- **复用 DeployUnit**（ActionType=3）+`DeployUnitExecutor` 内 `unitType==Building` 分支；**DeployBuilding 枚举（=4）维持预留不启用**（部署段/配额/AI 候选/回放全链零另起）。
- 建筑分支校验链（替换升命分支——建筑**永不升命**）：
  1. 配置存在 → 2. 手牌成员（既有 Host 权威）→ 3. **梯度前置**（§2）→ 4. **建筑上限** → 5. 落点合法（**半径 3**：新常量 `DeployRadiusFromCoreBuilding=3`；地形+体积+碰撞原语照旧——建筑互不阻挡后 PassesBlockingRules 天然放行，体积层 2+1=3 仍容许同格一站位；**2026-10-23 决策八十八勘正：核心单锚已改建筑锚并集——核心 tag 锚=建筑 3/角色 2、其它自己建筑锚=建筑 2/角色 1**，`DeployRadiusOf`/`CollectDeployAnchors` 单源）→ 6. 摩拉够 → 7. 生成登场（UnitFactory+RegisterUnit+Summon 命令+摩拉 StatChange，既有链）。
- 部署段归属不变（B6c 部署段先于攻速片）；升命分支在建筑类型前置分流（勿让 3★ 总部/教堂走升命）。
- AI 配额脑（**2026-10-23 决策八十八落案，取代原「天然不触发」表述**）：AI 卡组含建筑卡三张（餐馆/总部/大教堂）+旗帜走购买——部署三桶（1★ 建筑首铺→角色→其余建筑）+TryPurchase 购买档详见 docs/18 决策八十八；§9 同步勘正。

## 4. 消散机制（新死亡分支，拍板 #5）

**适用对象**：`UnitType.Building` 全部（含协议核心——核心摧毁由胜负判据接管，表现按通则）+ `UnitTier.Familiar` 的 Character（1~2★：丘丘人、西风骑士）。

**Host 流程**（HP≤0 死亡点，装备掠夺段之后）：
1. 装备掠夺先行（既有同段最近 Damage 攻击者归属——掠夺发生在移除之前，顺序保证）；
2. 该单位全部 Buff 注销（ActiveBuffs 清理——"死亡不清理"通则对**尸体**维持，对消散单位=随移除清理）+附着清除；
3. `_sim.Units` 移除 + GameObject 销毁；
4. Death 命令照发、payload 携带**消散标志**（客户端区分表现：尸体=压扁灰化〔既有〕/消散=立牌淡出〔新，特效随素材批〕）。

**波及面清理清单**（实施时逐项核对，多为"天然自洽、只需验证"）：
- FindOwnUnitByName（升命/同名判定）→ 消散后天然只命中存活；
- 尸体碰撞/体积（MovementResolver/部署 occupants 含尸体）→ 消散单位已移除不占格；
- 鞭尸 tick（Burn/Icicle/SongOfLife 对尸体）→ Buff 已随消散注销，天然停；
- 复苏（Revive 目标=尸体）→ 眷属/建筑无尸体不可复苏=语义自动成立（复苏=3★+ 单位既有先例口径）；
- 水之浅唱 OnHit 判定/预判描边/集火等"含尸体"域 → 消散单位自然缺席；
- 客户端尸体表现（尸血条/灰染/命座徽章残留）→ 消散走 RefreshFromSnapshot"单位从快照消失"既有清理路径；
- 迷雾隐藏单位死亡 → 同路径；
- 全库扫描项：死亡单位引用持有点（执行器/AI 追踪器/头顶条条目）——实施批 rg `IsDead` 全消费点核对一遍，消散单位 IsDead 判定不达（已移除），确认无 NRE 悬挂。

**勿当 bug 修登记**：丘丘人死亡从"压扁尸体"改为"消散"=拍板预期；建筑拆掉不留残骸/尸体不挡路=拍板预期。

## 5. 元能与治疗通则（拍板 #8/#9，全局规则）

- **加元能**：`UnitType.Building` 目标一律无效（TurnResolver 能量应用段统一过滤——覆盖战技/移动/光环 tick/溢出转移/旗帜等一切来源；**安柏 1命溢出转移的候选域排除建筑**，切比雪夫最近未满"我方"=非建筑单位）；倒下角色照常加（既有 tick 含尸体先例维持——眷属/建筑无尸体，倒下角色=伙伴/魔神尸体）。**2026-10-24 追记四修订**：加元能对「**有元能上限**的建筑」（骑士团总部 baseEnergy=120）**照常生效**——`ApplyEnergy` 过滤改判 `Max<=0`（元能引擎外部充能接入：歌声之环 tick 喂总部；旗帜目标域=非建筑系自身设计不充能总部；溢出转移候选域维持排除）。
- **治疗**：对一切存活单位生效（角色/造物/建筑；2v2 含队友）；特别强调例外既有保留：复苏（尸体）、协议核心治疗减半（50% 治疗效率）。大教堂按此通则（**含建筑目标**——旗帜/餐馆/核心血量不满也奶）。
- 实施锚：TurnResolver 元能应用处 + 溢出转移选目标处 + 教堂效果；歌声之环"我方存活"已是同口径零改动。

## 6. 建筑效果结算（BuildingEffectsSystem，效果拍每 2 秒）

- **配置位**：UnitData 新增建筑段字段（[Header("建筑效果")]）：`建筑效果 BuildingEffectKind`（enum：None=0/EnergyAura=1/MoraIncome=2/PeriodicSummon=3/HealWounded=4/**EnergySummon=5〔2026-10-24 追记四：元能引擎召唤〕**）+ 效果参数（效果半径/效果数值/效果周期 int + **效果阈值 int〔2026-10-22 实施扩展补录：教堂 50% 阈值参数位，默认 50；EnergySummon 复用=触发线兼消耗额（总部 100）〕**）+ 召唤单位 UnitName + **初始元能 int〔2026-10-24 追记四：EnergySummon 消费（总部=80）——UnitStats 初始化直读，默认 0=全员空蓝零变化〕** + 可购买卡片 `List<CardId>`（§1.2）。**不走技能原子**（建筑无技能——效果枚举+参数直白承载，未来建筑种类增长再评估原子化）。
- **结算段位置**：`TurnResolver.ResolveSecondBeat` 的**效果拍**（每 2 秒，`CurrentTick % BattleMetrics.EffectBeatTicks == 0`）经 `BuildingEffectsSystem.CollectTurnEndEffects` 与 buff OnTurnEnd 同拍结算（秒拍族=资源发放/泡湿/采集/快照仍每秒）。**EnergySummon 例外（2026-10-24 追记四用户拍板「建筑的效果不一定是在回合末才生效」）**：过阈即召=能量落地同拍判定（ApplyEffects 加能循环钩）——外部充能（歌声之环 tick）与自充同拍同权，召唤命令经 EmitSliceCommands 尾 DrainPendingBuildingSummons 发射（含 -阈值 消费命令）。
- **命令发射**（全走既有命令层）：
  - 旗帜：EnergyEffect **新类别 CategoryBuildingGain=8**；**合并键必须区分来源建筑**（键含来源建筑 unitId——否则两座旗帜对同一目标会按 (target,category) 合并吞成 +1；拍板语义=每座旗帜各 +1）。客户端元能条跳变+可选弹字（元能弹数字开关既有，默认不弹）。**目标域=我方非建筑（自身设计，追记四后仍不充能总部）**。
  - 餐馆：StatChange(StatKindMora,+5) 直产命令（回合发放先例——不走 MoraSpendEffect 技能链）。
  - 教堂：HealEffect → 治疗命令（治疗数字绿色 +N 既有曲线）；目标筛选=我方存活单位 ∣ HP<50%×MaxHp；治疗量=FloorToInt(10%×教堂攻击)（末点截断通则）。
  - 总部（**追记四前=旧版**）：Summon 命令（UnitFactory+RegisterUnit 既有链）；落点=总部自己格 → 体积/碰撞不合法 → **最近可部署格顺延**（BFS 距离场最近合法格，确定性序）；召唤的西风骑士带 exploreVision 缓存预热（部署当帧揭雾既有链）。**追记四后=元能引擎**：自充 EnergyEffect（BuildingGain 类别、目标=自身）+过阈召唤同上一段——部署即召与 5 回合周期退役。
- **总部周期计数**（**追记四后已退役**，保留为 PeriodicSummon 类型的通用记载）：以部署回合为 0，`turn % 5 == 0` 触发（T+5/T+10/…；回合数真源=BattleSimState 当前回合）；**部署当回合在部署段内立刻召唤 1 个**（部署分支尾部直呼召唤，不等回合末）。周期计数器挂 UnitData 实例字段（Unit 组件侧，随消散销毁）。
- 建筑效果段只结算**存活**建筑（消散即移除，天然）；多座同种建筑独立结算（两座餐馆=+10）。

## 7. 购买系统（BuyCard，拍板 #10/#11/#17）

### 7.1 协议与行动
- **ActionType.BuyCard=6 启用**；ActionData 新增字段 `buyCardType`（CardType 枚举值）+ `buyCardValue`（UnitName/ItemName 枚举值）——单位卡/物品卡统一承载。
- **即时执行、不占配额、不进执行段**：选择阶段客户端即时上交 → TurnFlowController SubmitAction 通道 BuyCard 分支**直通 Host**（不参与"收齐开演"判定——与配额行动分流）；Host 校验→结算→命令广播即完。
- **Host 校验链**：①该玩家存在**存活建筑**其可购买列表含此卡（来源建筑不指定=等价校验，防凭空购买）→ ②（角色卡）玩家**已解锁**该角色 → ③摩拉够 → GainCard 入手牌+扣摩拉。
- **命令**：新 `BattleCommand.CardGain`（cardType+value+count——角色/建筑卡入手牌；物品卡核对现有 ItemGain 命令语义是否即"物品入手牌"，同则物品复用 ItemGain、单位卡用 CardGain）+ `StatChange(StatKindMora,-购买价)`。客户端：CardGain→GainCard 镜像+RefreshHandCards；StatChange→资源刷新链（既有）。
- **回放**：BattleRecorder 录 BuyCard 行（全行动录制通则）。
- **LAN**：客户端经既有行动上交通道发 BuyCard（MirrorBattleTransport），Host 权威结算广播（B7 双保险通则）；对手视角零信息泄露（手牌隐藏既有 N2 现状）。

### 7.2 价格单源
- `PurchaseCostOf(cardId)`（BattleMetrics 或 CardId 扩展单源）：
  - **角色/建筑卡 = GetEffectiveDeployCost() / 2**（拍板 #11：部署价一半；骑士团总部/大教堂 3★出战 60→购买 30 ✓〔2026-10-23 默认表分档后值〕；安柏/凯亚/琴/芭芭拉 3★出战 50→购买 25）；
  - **物品卡 = 摩拉价值星级表**（拍板原需求）：1★=5 / 2★=15 / 3★=30 / 4★=80 / 5★=200（`MoraValueOfStar(starLevel)` 单源；生肉/萝卜/蛋全 1★→5 摩拉/张）。

### 7.3 解锁判定（角色卡购买前置，拍板 #11）
- 判定源=**存档卡牌收藏**（与祈愿解锁同源——抽到/初始解锁的角色才可买；实施时核实 SaveData 角色解锁的确切字段与查询入口，以"祈愿抽到后可买"为验收口径）。
- 未解锁=购买面板**灰显+不可拖**；建筑卡/物品卡无解锁门槛（默认可购买）。

### 7.4 UI（购买面板）
- **入口**：选择阶段点击**我方存活建筑**（含协议核心）=选中（描边/弧光照旧）+购买面板弹出；**敌方建筑/执行阶段点击=纯查看不弹**（既有建筑查看态语义维持）。
- **面板结构**：可购买卡横排列表（复用 Card.prefab 实例）+ 每卡**购买价角标**（DeployCostBadge 组件复用、填 PurchaseCostOf 而非部署价）+未解锁/摩拉不足灰显；摆位/滑入参考技能详情面板自适应惯例。
- **交互**：把可购买卡**拖入手牌区（下方）=购买**（复用手牌拖拽手感件 HoverTiltEffect.Suspend 让位协议+出牌区白蒙层方向反转提示，"拖入下方"拍板原文）；点击可购买卡=开卡牌详情面板（复用 CardDetailPanel 既有链，含建筑效果描述查看）；购买成功=卡入手牌+摩拉即时扣+面板就地刷新。
- **收口**：点外/点其它单位/进瞄准/阶段流转/拖起手牌统一收口（对齐技能详情面板收口惯例）；面板开着计入 `BrowseUiOpen` 聚合=单人局浏览自动暂停（N0 同口径）。
- **建筑选中态**：无技能盘（协议核心纯查看先例推广到全部建筑）；购买面板=建筑选中态的专属面板（角色选中=技能盘、建筑选中=购买面板）。
