# 一、局前准备

## 1.1 卡组构筑

- 每局开始前，玩家从自己的收藏中**自由选择携带8种卡**作为**初始牌库**
- 卡牌类型包括：
  - **角色卡**：安柏、钟离等（用摩拉出战）
  - **建筑卡**：西风大教堂等（用摩拉出战）
  - **物品卡**：原粹树脂、小麦、狼的末路等（消耗品/装备）
- 玩家**初始拥有200摩拉、2体力**

## 1.2 卡牌性质

**局外收藏是"解锁"制，带入对局不消耗收藏。** 角色卡和建筑卡打出均不消耗（留在手牌），物品卡使用/装备后消耗。

### 三种单位卡

| | 角色卡 | 建筑卡 | 造物卡 |
|---|---|---|---|
| **可编入卡组** | ✅ | ✅ | ❌ |
| **卡组上限** | 1张 | 1张 | — |
| **打出消耗** | 不消耗（留在手牌） | 不消耗（留在手牌） | — |
| **局内来源** | 手牌打出 | 手牌打出 | 角色技能召唤 |
| **重复打出** | 3星+提升命座；1-2星加一个 | 加一个（无命座） | — |
| **命座** | 有（0-3） | 无 | 无 |
| **背包可见** | ✅ | ✅ | ✅（图鉴查看） |
| **单位属性** | 完整（HP/攻速/防御等） | 完整 | 完整（与角色一致） |
| **技能系统** | 主动技能（弧形排列）+ 被动技能 | 主动技能（战技=科技面板）+ 被动技能 | 主动技能 + 被动技能 |
| **操控方式** | 3星+玩家操控；1-2星AI | 被动效果 | 被动效果 |

> **核心统一**：角色、建筑、造物都是 Unit，点击后出现技能按钮，UI 逻辑完全复用。建筑的区别只是"战技按钮打开科技面板"而非"造成伤害"。

### 角色卡

- 每种角色卡在牌库中**只有1张**
- 带入对局**不消耗局外收藏**（收藏是"解锁"关系）
- 出战不消耗卡牌 — **卡始终留在手牌**
- **重复出战同一角色 = 提升命座**（每次消耗摩拉）
- 对局结束后，掠夺来的角色卡**不会带出**
- 局内可通过掠夺获得对方的角色卡并使用

### 建筑卡

- 出战时**卡牌不消耗**（与角色卡一致，留在手牌）
- 建筑在场上提供**功能效果**（如西风大教堂提供大范围治疗）
- **无命座**，重复打出 = 在场上增加一个同类建筑
- 场上的建筑可作为**科技树节点**：点击建筑 → 战技按钮 → 科技面板
  - 花费摩拉在该建筑上购买新的角色卡或建筑卡
  - **购买费用 = 出战费用的一半**
  - 例：西风大教堂 → 花摩拉购买芭芭拉角色卡 / 风神雕像建筑卡
  - 例：出战风神雕像后 → 花摩拉购买巴巴托斯角色卡
  - 通过建筑购买的卡加入**局内牌库**，对局结束后不带出

- **物品卡**（使用/装备即消耗）：
  - **消耗品**（食物/饮品）：使用后消失
  - **武器**：装备后消失，加攻击力等战斗属性
  - **配件**：装备后消失，提供特殊效果（加属性词条 / 触发被动 / 存储资源等）
    - 例：冰风迷途的勇士 → 加暴击/冰伤
    - 例：兔兔伯爵 → 受伤时抵挡伤害（有耐久）
    - 例：勾玉 → 稻妻连携产出，存储在角色身上

- **造物卡**（不可编入卡组）：
  - 背包中可见（图鉴查看），但**无法编入卡组**
  - 局内永远不会出现在手牌里
  - 只能通过对应角色的技能**直接召唤**到场上
  - 造物是完整的 Unit，拥有与角色一致的属性（HP/移速/防御等）

## 1.3 局内牌库扩张

- 初始8种卡是**开局资源**，不固定整局的卡池
- 通过建筑科技树，牌库在局内**不断扩张**：
  - 建筑A → 解锁角色X / 建筑B
  - 建筑B → 解锁角色Y / 建筑C
  - 形成局内成长路线和科技树分支
- 不同建筑解锁不同角色/建筑，玩家的科技路线选择决定中后期走向

## 1.4 势力选择

- 玩家**不是只能选一种势力，可以混搭**
- 携带的8种卡可以来自不同势力（例如：蒙德的安柏 + 璃月的钟离 + 稻妻的雷电将军）
- 每个势力拥有**独特机制**，当场上存在该势力的角色/建筑时可触发对应机制
- 混搭可以获得多个势力的机制，但每种机制的触发条件/强度可能与纯势力阵容不同（具体规则待设计）
