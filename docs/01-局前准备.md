# 局前准备

> 局前流程与卡牌性质：选 8 卡构筑、三种单位卡、装备槽位、局内牌库扩张。关联：局内四资源见 03 §3.2；出战/购买/升命行动见 05 §5.2；命座两层定义见 09。

## 1.1 卡组构筑

- 每局开始前，玩家从自己的收藏中**自由选择携带8种卡**作为**初始牌库**
- 卡牌类型包括：
  - **角色卡**：安柏、钟离等（用摩拉出战）
  - **建筑卡**：西风大教堂等（用摩拉出战）
  - **物品卡**：原粹树脂、小麦、狼的末路等（消耗品/装备）
- 玩家**初始拥有200摩拉、60体力**

## 1.2 卡牌性质

**局外收藏是"解锁"制，带入对局不消耗收藏。** 角色卡和建筑卡打出均不消耗（留在手牌），物品卡使用/装备后消耗。

### 三种单位卡

| | 角色卡 | 建筑卡 | 造物卡 |
|---|---|---|---|
| **可编入卡组** | ✅ | ✅ | ❌ |
| **卡组上限** | 1张 | 1张 | — |
| **打出消耗** | 不消耗（留在手牌） | 不消耗（留在手牌） | — |
| **局内来源** | 手牌打出 | 手牌打出 | 角色技能召唤 |
| **重复打出** | 3星+提升命座；1-2星加一个 | 加一个（无命座） | — |
| **命座** | 有（0-3） | 无 | 无 |
| **背包可见** | ✅ | ✅ | ✅（图鉴查看） |
| **单位属性** | 完整（HP/攻速/防御等） | 完整 | 完整（与角色一致） |
| **技能系统** | 主动技能（弧形排列）+ 被动技能 | 主动技能（战技=科技面板）+ 被动技能 | 主动技能 + 被动技能 |
| **操控方式** | 5星魔神玩家全手操；3-4星伙伴 AI 自主（评分制脑，可被势力技能号令）；1-2星眷属自主行动（启发式脑，如 MOBA 小兵）——2026-09-29 操控分层拍板=docs/active/32 | 被动效果 | 被动效果 |

> **核心统一**：角色、建筑、造物都是 Unit，点击后出现技能按钮，UI 逻辑完全复用。建筑的区别只是"战技按钮打开科技面板"而非"造成伤害"。

### 补充说明

- **角色卡**：带入对局不消耗局外收藏（"解锁"关系）；掠夺来的角色卡对局结束后**不会带出**（未通过祈愿解锁的无法带回局外）
- **建筑卡**：科技树节点——点击建筑 → 战技按钮 → 科技面板，花费摩拉购买新卡（费用=出战费用的一半），购买的卡加入局内牌库（对局结束不带出）
- **物品卡**：使用/装备即**消耗**（与角色卡/建筑卡的"不消耗"相对）——消耗品（食物/饮品）使用后消失；武器装备后消失加属性；配件装备后消失提供特殊效果（如兔兔伯爵抵挡伤害）
- **造物卡**：局内永远不会出现在手牌里，只能通过角色技能直接召唤到场上

## 1.3 局内牌库扩张

- 初始8种卡是**开局资源**，不固定整局的卡池
- 通过建筑科技树，牌库在局内**不断扩张**：
  - 建筑A → 解锁角色X / 建筑B
  - 建筑B → 解锁角色Y / 建筑C
  - 形成局内成长路线和科技树分支
- 不同建筑解锁不同角色/建筑，玩家的科技路线选择决定中后期走向

## 1.4 势力选择

- 玩家**不是只能选一种势力，可以混搭**
- 携带的8种卡可以来自不同势力（例如：蒙德的安柏 + 璃月的钟离 + 稻妻的雷电将军）
- 每个势力拥有**独特机制**，当场上存在该势力的角色/建筑时可触发对应机制
- 混搭可以获得多个势力的机制，但每种机制的触发条件/强度可能与纯势力阵容不同（具体规则待设计）
