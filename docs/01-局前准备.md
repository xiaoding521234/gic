# 一、局前准备

## 1.1 卡组构筑

- 每局开始前，玩家从自己的收藏中**自由选择携带8种卡**作为**初始牌库**
- 卡牌类型包括：
  - **角色卡**：安柏、钟离等（用摩拉出战）
  - **建筑卡**：西风大教堂等（用摩拉出战）
  - **物品卡**：原粹树脂、小麦、狼的末路等（消耗品/装备）
- 玩家**初始拥有200摩拉、2体力**

## 1.2 卡牌性质

**局外收藏是"解锁"制，带入对局不消耗收藏。** 局内使用时，只有角色卡不消耗。

- **角色卡**（不消耗）：
  - 每种角色卡在牌库中**只有1张**
  - 带入对局**不消耗局外收藏**（收藏是"解锁"关系，带上场只是表示"这局我能用"）
  - 出战不消耗卡牌 — **卡始终留在手牌**
  - **重复出战同一角色 = 提升命座**（每次消耗摩拉）
  - 对局结束后，掠夺来的角色卡**不会带出**（未通过祈愿解锁的角色无法带回局外）
  - 局内可通过掠夺获得对方的角色卡并使用

- **建筑卡**（出战即消耗）：
  - 出战时卡牌**从手牌消耗**，建筑实体部署到场上
  - 建筑在场上提供**功能效果**（如西风大教堂提供大范围治疗）
  - 场上的建筑可作为**科技树节点**：花费摩拉在该建筑上购买新的角色卡或建筑卡
    - **购买费用 = 出战费用的一半**
    - 例：西风大教堂 → 花摩拉购买芭芭拉角色卡 / 风神雕像建筑卡
    - 例：出战风神雕像后 → 花摩拉购买巴巴托斯角色卡
  - 通过建筑购买的卡加入**局内牌库**，对局结束后不带出

- **物品卡**（使用即消耗）：
  - 消耗品使用后消失
  - 装备卡装备后消失

## 1.3 局内牌库扩张

- 初始8种卡是**开局资源**，不固定整局的卡池
- 通过建筑科技树，牌库在局内**不断扩张**：
  - 建筑A → 解锁角色X / 建筑B
  - 建筑B → 解锁角色Y / 建筑C
  - 形成局内成长路线和科技树分支
- 不同建筑解锁不同角色/建筑，玩家的科技路线选择决定中后期走向

## 1.4 势力选择

- 玩家**不是只能选一种势力，可以混搭**
- 携带的8种卡可以来自不同势力（例如：蒙德的安柏 + 璃月的钟离 + 稻妻的雷电将军）
- 每个势力拥有**独特机制**，当场上存在该势力的角色/建筑时可触发对应机制
- 混搭可以获得多个势力的机制，但每种机制的触发条件/强度可能与纯势力阵容不同（具体规则待设计）
