# 安柏即时制重设计：通用采集、移动快速采集与分支命座

> 状态：已确认施工方案（2026-11-10）。工作分支：master。
> 范围：通用读条采集、采集效率、安柏移动快速采集、通用命座二选一、安柏六个命座选项、箭雨自由角表现修复。
> 非目标：不修改安柏战技/爆发的伤害、弹道、段数和基础时轮；不修改延奏/变奏本体；不重做兔兔伯爵物品规则。

## 1. 通用采集

### 1.1 普通采集

- 单位位于资源点中心 50cm 欧氏半径内、资源点有余量，且未主动行动、未受硬控时，自动开始读条。
- 资源点新增采集时间配置，默认 3 秒；读条以整数 tick 结算。
- 完成后采集一次；若仍满足条件，自动开始下一次读条。
- 读条绑定 `(unitId, resourceNodeId)`，切换节点重新计时。
- 资源点在完成前被采空或消散，本次失败且无收益。

### 1.2 中断语义

中断并清空读条：成功主动移动、成功主动施放战技/爆发/势力技能、硬控、离开 50cm、节点失效。

不打断：普通受击和伤害、非硬控减益、被动技能/光环/装备触发、被动推挤/击退/牵引、选中或查看单位、操作其他单位。被动位移导致离开范围时仍按离范围中断。

“保持不动”指无主动行动，不要求权威坐标绝对不变。无效或被资源/CD 门拦截的主动指令不制造假中断。

### 1.3 采集效率

- `UnitConfig.UnitData` 新增 `baseHarvestEfficiency`，缺省回落 100。
- `StatType` 追加 `HarvestEfficiency`，`UnitStats` 支持修改器，详情面板显示百分比。
- 公式：`实际读条时间 = 资源点采集时间 × 100 / 采集效率`，结果转整数 tick。
- 50=两倍时间，100=标准，200=一半时间；防止除零。
- 只影响普通读条，不影响安柏快速采集次数与冷却。

### 1.4 表现

单位头顶显示资源图标、进度和剩余时间；中断立即消失，不播放成功反馈。普通受击不显示中断提示。

## 2. 安柏飞行冠军

- 安柏实际移动时，若自身 50cm 内有资源点且该点快速采集冷却结束，立即快速采集 1 次。
- 每次成功采集给正常资源收益，并额外 +5 体力/+5 元能，触发既有采集装备钩子。
- 冷却为 6 秒，以 `(unitId, resourceNodeId)` 独立记录；不同单位不共享。
- Host 按实际移动状态和逐 tick 位置检测，重复移动命令本身不触发。
- 持续移动且仍在范围内时，冷却结束可再次触发；停下后转为普通读条。
- 快速采集与普通读条共用资源余量，余量不足只结算实际成功次数。
- 移除旧“移动结束后按 PathCells 补算、单堆一次移动连采三次”逻辑。

## 3. 通用分支命座

### 3.1 选择与数据

- 0 命与上限 3 命不变；每次升命展示当前级两个选项，确认其一后才正式升层。
- 同级互斥且当局不可更改，不同级可自由组合；未选择不自动生效、不继续升下一级、不超时自动选。
- 多个待选请求排队处理。
- 每级配置严格两个选项；每项复用 Talent 技能的名称、图标、SkillTag、参数和效果原子，并带 AI 评分。
- 保留旧 Talent 作为 0 命和未迁移角色兼容路径，不改变单位技能索引。
- `Unit`/`UnitState` 记录各级已选稳定技能 ID；`ActionData` 增加选项 ID；升命命令回传同一 ID。
- Host 校验当前等级、合法选项和未重复选择，失败零副作用；选择进入快照、hash 和既有回放行动流。

### 3.2 卡片与 Tag

命座卡显示等级、A/B、名称、图标、Tag、描述及选择状态；不是手牌或物品卡。

复用 SkillTag：采集、视野、伤害；追加：生存、冷却。新枚举只追加不重排，本地化五语言同步。

AI 必须提交同一升命行动与选项 ID，不得本地直接改属性；同分按稳定技能 ID 决胜。

## 4. 安柏命座选项

| 等级 | 选项 | Tag | 名称 | 效果 |
|---|---|---|---|---|
| 1 | 1A | 采集 | 一飞双采集！ | 快速采集 1→2 次；移速 +10。 |
| 1 | 1B | 视野 | 敏锐感知 | 探索视野 +100cm；100cm 内敌人获得视野暴露 3 秒。 |
| 2 | 2A | 视野 | 迷雾侦查 | 箭雨线域破雾；命中敌人获得视野暴露 6 秒。 |
| 2 | 2B | 生存 | 是兔兔伯爵！ | 获得兔兔伯爵，沿用优先直接装备规则。 |
| 3 | 3A | 伤害 | 弱点侦查 | 我方单位对处于视野暴露的敌人增伤 50%。 |
| 3 | 3B | 冷却 | 压制射击 | 战技/爆发 CD -50%；释放速度 +100%。 |

### 4.1 细则

- 1A：一次触发连续结算最多两次，每次独立给正常收益及 +5/+5；余量不足按实际次数；6 秒冷却不变；移速 60→70。
- 1B：安柏存活时持续扫描，进入范围施加既有视野暴露，范围内刷新，离开后 3 秒倒数。
- 2A：破雾写队伍探索账本；多段只刷新暴露不累计；删除旧按破雾格数回能。
- 2B：优先直接装备，已装备补耐久，槽满或满耐久入手牌；物品本体不改。
- 3A：读取任意来源的既有视野暴露，+50 进入增伤乘区；安柏倒下后按尸体规则停效；同名不叠。
- 3B：战技 3→1.5 秒、爆发 5→2.5 秒；动作、前摇、发射间隔和箭雨波次速度 ×2；弹速、伤害、元能消耗不变。

## 5. 箭雨自由角表现修复

静态核查：HUD 已提交任意角千分向量，Host 已按向量做线段×圆判定；`BattlePlayer.PlayArrowRainCoroutine` 仍用 `DirectionToDelta(command.direction)` 计算落点和斜落方向，且把 `maxRange=800cm` 当 800 格循环。

修复边界：

1. 表现改用 SkillCast 的 aim 向量与连续 cm 口径，不再读旧 direction。
2. 落点格集与 Host 共用同一线域采样原语。
3. 落箭倾斜方向、破雾表现与实际自由角一致。
4. 不改箭雨数值、判定和基础时轮。
5. 验收角度：0°、17°、45°、90°、137°、180°、269°、359°，瞄准线、伤害、落箭、破雾一致。

## 7. 验收清单

- 普通采集只在范围内无主动行动时推进；主动行动/硬控/离范围中断，普通受伤和非硬控效果不断。
- 默认 3 秒，效率 50/100/200 对应 6/3/1.5 秒；快照与回放一致。
- 安柏快速采集逐 tick 发生，不再等移动结束；每点 6 秒限频，1A 一次最多两份且受余量限制。
- 命座未选不升层；同级不可双选；六项效果及组合在 Host、快照、HUD、AI、回放一致。
- 3B 只改 CD 和释放速度，不改伤害、弹速、段数、消耗。
- 箭雨任意角的指示、判定、落箭与破雾一致，无 cm/格混用。
