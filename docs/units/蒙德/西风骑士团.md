# 西风骑士团（KnightsOfFavonius）

## 基础属性

| 字段 | 值 |
|------|-----|
| UnitName | KnightsOfFavonius = 3015 |
| 类型/星级 | 建筑（蒙德）/ 3★（中科——需自己有低科建筑在场才可部署） |
| 部署费 | 100 摩拉（购买价=50） |
| 生命/攻击 | 200（3★档）/ 40（臂铠档） |
| 武器/元素 | 臂铠 / 物理 |

| 碰撞 | 敌我双向互不阻挡全开 |
| 元能 | 0（无元能条） |

## 建筑效果

- **周期召唤（拍板 #10）**：部署当回合立刻召唤 1 名[西风骑士](../蒙德/西风骑士.md)（部署段内直呼，不等回合末）；此后每过 5 个回合（以部署回合为 0 相对计数）回合末再召唤 1 名。
- 召唤落点：骑士团自己格优先；体积/碰撞不合法时**最近可部署格顺延**（BFS 距离场、固定方向序确定性）。
- 可购买列表：安柏、凯亚、琴（3★角色出战 50→购买 25；**需玩家已解锁**，未解锁灰显）。

## 获取方式

战斗内通过西风旗帜购买获得；亦可直接编入卡组（每建筑 1 张）。

## AI 行为

建筑无自主行为（AI 玩家本期不购买、AI 卡组无建筑——拍板 #14）。

## 历史演进

- 2026-10-22 决策八十六批A~G 实装：首批可部署建筑（召唤型——部署即召+周期召唤）。
