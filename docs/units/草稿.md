## 行秋 (Xingqiu)

- UnitName: `Xingqiu` (枚举值 3008)
- 势力: Liyue
- 星级: 3
- 武器: Sword
- 元素: Hydro
- 移动方式: Amphibious
- 出战摩拉: auto (→50)
- 生命值: auto (→200)
- 攻击力: auto (→40)
- 攻速: auto (→40)
- 防御力: 0
- 移速: 3
- 幸运: 0
- 韧性: 0
- 精通: 0
- 理智: 50
- 吸血: 0
- 治疗效率: 100
- 元能: 3
- 视野: 1
- 碰撞: 阻挡友方/敌方/被敌方阻挡 = true/true/true
- 标签: DifficultyEasy, CoordinatedAttack, BurstDamage

**移动 — 两栖**
- 向直线两栖移动

**战技 — 画雨笼山**
- 对前方2格直线敌人造成100%攻击力水伤
- 获得1柄雨帘剑

**爆发 — 飞云商会
- 获得2柄雨帘剑
- 每有1柄雨帘剑，获得10%理智的摩拉
- 元能消耗 3

**契约 — 雨深闭门
- 契约存在时：被契者移速减少50%，但每个回合结束时获得1元能
- 被契者累计使用2次移动后，解除契约
- 拒签惩罚：被契者失去3元能
- 消耗20摩拉

**命座**
- 【1命】雨帘剑上限提升3柄，每次协同攻击还会为行秋与被协者都加1元能
- 【2命】任意我方击倒敌人后，行秋获得6柄雨帘剑。任何情况溢出的雨帘剑会立即攻击半径5内生命最低敌人
- 【3命】雨帘剑每次协同攻击还会为行秋与被协者都加2韧性

### 雨帘剑 (Buff)

- 上限3柄
- 我方角色造成战技伤害时，消耗1把雨帘剑：对目标造成40%攻击力水伤（协同伤害）
- 持有者倒下时清除
