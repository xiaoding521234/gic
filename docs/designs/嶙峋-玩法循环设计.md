## 0. 这份文档要回答什么

立项书定义了"谁能怎么赢"，这份文档定义"**一局游戏从头到尾，玩家每一分钟在做什么、为什么做、做完拿到什么反馈、下一分钟被推向哪里**"。

先设计循环、再设计技术与关卡。任何一条循环断掉（做完没有反馈、反馈不改变下一步、下一步不产生冲突），系统再精致也是空转。

## 1. 循环层级

| 层级 | 周期 | 玩家心里的问题 | 主要动作 | 产出 |
|------|------|----------------|----------|------|
| 生涯循环 | 数小时~数十小时 | 我为什么再开一局 | 选队、组队、结算、熟练度、外观 | 身份偏好与"下次我要试另一种打法" |
| 单局循环 | 30 分钟 | 这局我怎么赢 | 三方目标竞速 | 胜负、结算面板、可讲述的故事 |
| 阶段循环 | 4~8 分钟 | 现在该抢什么 | 阶段目标切换（潜行→对抗→收束） | 地图状态改变、计划改写 |
| 战术循环 | 60~180 秒 | 下一步去哪、值不值得冒险 | 侦察→决策→执行→暴露→响应 | 价值、证据、防线、位置 |
| 交战循环 | 10~30 秒 | 打还是跑 | 定位→交火/回避→脱离/倒地 | 击倒、被捕、逃脱、掉货 |
| 交互循环 | 2~10 秒 | 这个读条值得吗 | 接近→读条→暴露窗口→兑现/失败 | 一件财物、一条证据、一次撤离 |

**设计原则：上一层的目标必须由下一层的动作实现；下一层的每次成功必须改变上一层的局势。** 例如：读条拿到一件油画（交互）→ 团队窃取值跨过 3000（战术）→ 全场公告、撤离点开启（阶段）→ 庄主被迫分兵守点（单局）。

## 2. 循环总图

```
┌─────────────────── 生涯循环（跨局）───────────────────┐
│  选队/组队 → 单局 → 结算 → 熟练度/外观 → 再开一局      │
└──────────────────────────┬────────────────────────────┘
                           ↓
┌─────────────────── 单局循环（30 min）──────────────────┐
│  布置 → 渗透 → 对抗 → 收束 → 终局 → 结算               │
└──────────────────────────┬────────────────────────────┘
                           ↓
┌────────────── 战术循环（60~180 s）────────────────────┐
│  侦察 → 决策 → 执行 → 暴露 → 响应 → 回到侦察           │
└──────────────────────────┬────────────────────────────┘
                           ↓
┌────────────── 交战循环（10~30 s）─────────────────────┐
│  发现 → 定位（声音/轮廓）→ 交火或回避 → 结果           │
└──────────────────────────┬────────────────────────────┘
                           ↓
┌────────────── 交互循环（2~10 s）──────────────────────┐
│  接近 → 读条（降速/噪音/可打断）→ 兑现或失败           │
└───────────────────────────────────────────────────────┘
```

所有循环共享同一个"燃料"：**噪音与信息**。破坏、读条、开枪、警报都会把私密行动变成公共事件，公共事件再驱动其他玩家进入下一轮战术循环。

## 3. 单局状态机

```
Lobby（大厅/组队）
  → TeamSelect（选队：庄主 2 / 盗贼 4 / 调查 3，可组队锁定）
  → Briefing（30 s：地图、撤离点、队伍目标、队友标记）
  → Prep（2 min：庄主布置；其他队在外围出生点准备）
  → Infiltration（10 min：潜行期，撤离点关闭）
  → Escalation（8 min：公告已触发，撤离点开启，强对抗）
  → Endgame（7 min：调查解锁、庄主收缩、盗贼押送）
  → Final（3 min：撤离窗口最后冲刺）
  → Settlement（结算：价值明细、证据明细、逮捕/淘汰、最佳镜头）
  → Lobby
```

时间点用"硬时钟"驱动（服务器时间），不因某队进度快而提前结束；只有"胜利达成"能提前终止。

## 4. 分钟级时间轴

> 下表是"设计上希望发生什么"，不是保证。每局会漂移，但**如果某一段连续多局都不发生，说明该系统没有驱动力**。

| 时间 | 场上默认状态 | 期望首发事件 | 各队此时该做什么 | 张力 |
|------|--------------|--------------|------------------|:----:|
| 0:00–2:00 | 庄园封闭，撤离点关闭，庄主可布置 | 庄主布锁/陷阱；盗贼与调查从不同外围入口落地 | 庄主：分配守卫区、上锁、设 1–2 个陷阱；盗贼：分头踩点；调查：找第一处血迹 | 2 |
| 2:00–6:00 | 安静，偶发脚步声 | 第一扇门被撬/第一面墙被砸 | 盗贼：确认高价值区与撤离路线；调查：第一件证据扫描；庄主：听到第一声噪音并判断方位 | 4 |
| 6:00–10:00 | 局部破坏，局部交火 | 第一件财物入袋、第一次击倒 | 盗贼：背包开始有货，考虑"再拿一件"；庄主：第一次追击；调查：发现证据被烧的痕迹 | 5 |
| 10:00–14:00 | 位置互相暴露，巡逻被打断 | 第一次真正的三方混战 | 盗贼：分头跑，制造假方向；庄主：选一个目标追到底；调查：趁乱扫描/救人 | 7 |
| 14:00–18:00 | 窃取值接近 3000 | **全场公告 + 撤离点开启** | 盗贼：第一次撤离尝试（通常失败或只走 1 人）；庄主：立刻分兵守点；调查：意识到"再不抓就来不及" | 8 |
| 18:00–22:00 | 撤离点被守，庄园被拆出多条通路 | 第一名盗贼成功撤离 / 第一件核心证据被销毁 | 盗贼：改换撤离点、用破坏开路；庄主：修补 + 设伏；调查：开始用证据进度换时间 | 8 |
| 22:00–26:00 | **调查队解锁强化（全场公告）** | 透视上线，第一次逮捕 | 调查：从"收集"转为"收网"；盗贼：负重撤离，不敢恋战；庄主：被迫同时防撤离点和防逮捕 | 9 |
| 26:00–30:00 | 终局，地图多处破损 | 最后的撤离读条 / 最后的逮捕 | 三方都在赌：盗贼赌读条能读完，庄主赌能打断，调查赌能先铐住 | 10 |
| 30:00 | 硬结算 | 无人达成 → 庄主胜 | — | — |

### 节奏保证机制

- **每 8 分钟一次"全场播报"**：只播报"已发生的事实"（谁撤离成功、谁被逮捕、证据进度档位），不播报位置。作用是让三方都知道"时间在走、有人在得分"，防止中段空转。
- **破坏必须有回声**：任何结构性破坏触发一次 3 秒的环境音（木头断裂、砖石掉落），半径 20 米内可听。安静期因此不会真的安静。

## 5. 三方完整闭环

### 5.1 庄主队

```
巡逻/听声（侦察）
  → 判断哪队在做什么（决策：追 / 守 / 修 / 设伏）
  → 执行（追击、上锁、修补、放陷阱、炸楼梯）
  → 回收（补陷阱、锁门、看尸体/掉货）
  → 回到巡逻
```

| 环节 | 具体行为 | 反馈 | 风险 |
|------|----------|------|------|
| 侦察 | 巡逻固定路线、听破坏声、看警报器 | 噪音方向波纹、警报区域高亮 | 巡逻路线被摸清 |
| 决策 | 三选一：追人 / 守撤离点 / 修墙 | 警觉点余额、各区域状态 | 选错=另一处被偷 |
| 执行 | 近战压制、关门、修补、布陷阱 | 击倒提示、墙体恢复、陷阱触发 | 离开岗位、暴露位置 |
| 回收 | 补陷阱、收走掉落的财物（可藏起来） | 警觉点回复、财物入库 | 花时间=别处失守 |

**核心决策点**：*"我现在离开这个房间，会损失什么？"*
**失败循环**：被击倒 → 重生时间递增（90→120→150 秒）→ 防线被迫收缩 → 更守不住 → 更依赖陷阱。这是设计上的"越打越弱"，让 2 人队不会无限续命。
**胜利闭环**：不需要主动进攻，只需要让三条计时器都不归零。

### 5.2 盗贼队

```
踩点（找入口/锁/墙/高价值物）
  → 破坏或开锁（噪音）
  → 拿货（背包容量与负重）
  → 选择：继续拿 / 藏货 / 撤离
  → 撤离（读条 8 秒）或 被抓（掉货 + 30 秒重生）
  → 再进（若撤离点仍开）
```

| 环节 | 具体行为 | 反馈 | 风险 |
|------|----------|------|------|
| 踩点 | 观察巡逻规律、找可破坏的墙/地板 | 体素断面预览、锁的硬度提示 | 被庄主看见 |
| 破坏 | 砸墙、撬地板、炸保险箱 | 断面、噪音波纹、队友可见 | 噪音吸引庄主与调查 |
| 拿货 | 拾取、装袋 | 背包条、团队窃取值进度 | 负重降速、暴露更久 |
| 决策 | 继续 / 藏货 / 撤 | 撤离点状态、队友位置 | 贪一件可能全丢 |
| 撤离 | 读条 8 秒 | 全场公告"有人在撤离" | 被打断、被守点 |

**核心决策点**：*"再拿一件的期望收益，是否大于被抓住全部掉货的风险？"*
**队内循环**：4 人天然分工（撬锁、爆破、搬运、放风），但系统不强制。队友可拾取死者掉落的财物，也可"见死不救"——这是盗贼队的社交张力，不额外加惩罚。
**失败循环**：被抓 → 掉货 → 重生 → 队友可能已经撤走 → 独自面对更严的防守。
**胜利闭环**：窃取 3000 → 公告 → 撤离 → 累计 10000。只要有一人卡在"差 500"，全队就得再赌一次。

### 5.3 调查队

```
扫描现场（找证据）
  → 取证（3 秒读条，光束暴露）
  → 累积证据（团队进度）
  → 跨过 10000（全场公告：猎人上线）
  → 透视定位 → 击倒 → 上铐 → 收网
```

| 环节 | 具体行为 | 反馈 | 风险 |
|------|----------|------|------|
| 扫描 | 对着可疑区域扫描 | 线索音、进度条、文字提示 | 光束与噪音暴露 |
| 取证 | 3 秒读条 | 证据入档、团队进度上涨 | 读条被打断、证据被销毁 |
| 累积 | 在庄园里找下一处 | 进度条、庄主开始烧证据 | 时间压力 |
| 解锁 | 10000 达成 | 全场公告、装备与透视到手 | 成为全场目标 |
| 收网 | 透视 → 击倒 → 上铐 | 逮捕计数、囚禁点 | 被捕者队友来救 |

**核心决策点**：*"先攒证据还是先抓人？"* 抓人会让对方减员，但会拖慢证据进度；攒证据会被庄主烧，但解锁后才能抓人。
**前期补偿**：调查队开局最弱，因此给"扫描就有反馈"（每次扫描都有线索文本与音效），让前 10 分钟也有事可做、有进展感。
**失败循环**：证据被烧 → 进度倒退 → 解锁延后 → 盗贼已经撤够 → 只能靠逮捕翻盘。
**胜利闭环**：解锁 → 透视 → 逐个击倒上铐；每铐住一个，场上"存活目标"就少一个，剩下的人更容易被围。

## 6. 循环之间的咬合

三方不是各玩各的，而是**互相生产对方的目标**。这是整个设计最重要的部分。

| 事件 | 对庄主 | 对盗贼 | 对调查 |
|------|--------|--------|--------|
| 盗贼砸墙 | 获得噪音方向，可追击 | 打开新通路，但也留下入口 | 可对"破坏痕迹"取证（新增证据来源） |
| 庄主修补 | 恢复防线，消耗警觉点 | 捷径被封，需重新开路 | 修补痕迹本身可取证（"他在掩盖什么"） |
| 调查扫描 | 看到光束，知道调查位置 | 知道调查在哪，可绕开或利用 | 获得证据 |
| 庄主烧证据 | 阻止调查解锁 | 无直接影响，但调查被拖住=庄主更闲 | 进度倒退，被迫改计划 |
| 盗贼撤离成功 | 少一个可击杀目标，只能靠拖时间 | 团队分数上涨，场上少一人 | 少一个可逮捕目标，但盗贼更接近胜利 |
| 调查解锁 | 成为被猎对象，必须反击 | 不敢再慢慢搬，必须尽快撤 | 获得武器/装备/透视/逮捕权 |
| 有人被抓 | 少一个对手，但调查更强了 | 少一个同伙，少一个搬运工 | 逮捕计数 +1 |

### 关键咬合点（必须实现）

1. **破坏痕迹 = 可取证证据**：调查队可以扫描盗贼砸开的墙洞，获得"外力入侵"类证据（价值 300~500）。这让调查队天然跟随盗贼，而不是各走各的。
2. **修补痕迹 = 可取证证据**：同理，庄主修补过的地方也是线索。这让"庄主偷偷补墙"变成可被读出来的行为。
3. **撤离公告 = 庄主的防守指令**：每次撤离读条开始，全场播报"某撤离点有动静"，庄主获得一次定向信息。这给 2 人队一个明确的"该去哪"的指引。
4. **调查解锁 = 盗贼的撤退信号**：解锁公告后，盗贼的"慢慢搬"策略失效，必须进入押送模式。

## 7. 信息循环

不对称的核心不是数值，是**谁知道什么**。

| 信息 | 谁知道 | 持续 | 反制 |
|------|--------|------|------|
| 噪音波纹（方向） | 半径 15 米内所有玩家 | 2 秒 | 蹲走、慢速破坏、用雨声掩护 |
| 破坏声（材质音色） | 半径 20 米 | 瞬时 | 换材质、远距离爆破 |
| 警报器触发 | 庄主全图 + 触发区域所有人 | 5 秒 | 提前拆掉警报器 |
| 撤离读条 | 全场播报（位置粗粒度） | 读条期间 | 假撤离（佯攻） |
| 调查扫描光束 | 视线内所有玩家 | 3 秒 | 背后扫描、利用墙体遮挡 |
| 调查透视 | 调查队 | 3 秒 / 12 秒冷却 | 卡冷却、分散站位 |
| 已窃取总值 | 盗贼队内可见；跨过阈值后全场知道"已报警" | 常驻 | 无法反制，只能接受 |
| 已带出总值 | 盗贼队内可见；结算公开 | 常驻 | 无法反制 |
| 证据进度 | 调查队内可见；销毁时全场播报 | 常驻 | 无法反制 |

**设计原则：每个"强信息"都必须有反制手段或代价。** 透视无代价会毁掉潜行，因此它有限时与冷却；撤离公告无代价会让庄主无法守点，因此它给庄主定向提示，而不是精确位置。

## 8. 价值循环

### 8.1 财物（地图总额 21800）

| 物件 | 单价 | 数量 | 小计 | 位置 |
|------|-----:|-----:|-----:|------|
| 保险箱 | 3000 | 1 | 3000 | 地下金库（需撬锁 8 s 或爆破） |
| 油画 | 1200 | 3 | 3600 | 画廊 |
| 珠宝 | 800 | 6 | 4800 | 主卧、首饰盒 |
| 首饰 | 600 | 4 | 2400 | 主卧、阁楼 |
| 现金 | 500 | 6 | 3000 | 书房、主卧 |
| 银器 | 300 | 10 | 3000 | 宴会厅 |
| 杂物 | 100 | 20 | 2000 | 全图 |
| **合计** | | | **21800** | |

- 理论可带出率约 60%（破坏/交火/时间损耗）→ 约 13000。
- 胜利线 10000 = 可带出量的 ~77%——**必须高效、必须少死、必须至少成功撤离 3 人次**。
- 单人背包 3000（可换大麻袋 5000），负重惩罚 -5%~-20%。4 人满载也只有 12000，一次全撤理论上刚好够，但撤离点冷却（120 秒/点/人）使"一次全撤"几乎不可能，逼迫分批。

### 8.2 证据（地图总额 13600）

| 证据 | 单价 | 数量 | 小计 | 位置 |
|------|-----:|-----:|-----:|------|
| 核心文件 | 1500 | 3 | 4500 | 书房（夹墙 1 件） |
| 隐藏尸体 | 2000 | 1 | 2000 | 酒窖夹墙（必须破坏） |
| 录音带 | 1000 | 2 | 2000 | 主卧 |
| 血迹样本 | 500 | 6 | 3000 | 多区域 |
| 账本 | 800 | 2 | 1600 | 画廊、书房 |
| 日记 | 500 | 1 | 500 | 阁楼 |
| **合计** | | | **13600** | |

- 解锁线 10000 = 73% 的证据量，意味着**调查队必须拿到大部分高价值证据**，不能只捡血迹。
- 庄主销毁一件 10 秒，理论上能销毁 4~6 件。若庄主全程专注销毁，调查队会被卡死在 8000 左右——因此销毁行为必须暴露（火光/烟/声音），让调查队有机会抓现行。

### 8.3 通胀与枯竭控制

- 地图价值固定，不随人数/时间增长；每局从 3 套布局中随机一套（价值物分布不同）。
- 财物被带出即永久离开本局；被销毁的证据同理。
- 不做"补货"机制（避免无限刷分），枯竭本身就是压力来源：越到后期，剩下的东西越难拿、越危险。

## 9. 张力曲线

| 分钟 | 目标张力(1–10) | 驱动因素 | 设计手段 |
|:----:|:----:|----------|----------|
| 0–2 | 2 | 未知与布置 | 只给环境音，不给敌人信息 |
| 2–6 | 4 | 第一声噪音 | 第一个破坏/撬锁事件 |
| 6–10 | 5 | 第一次接触 | 首次击倒或首次照面 |
| 10–14 | 7 | 位置暴露 | 巡逻被打断、混战 |
| 14–18 | 8 | 公告与撤离点 | 全场播报，庄主分兵 |
| 18–22 | 8 | 第一次成功撤离 | 分数可见，压力具象化 |
| 22–26 | 9 | 调查解锁 | 猎人上线，攻守易位 |
| 26–30 | 10 | 终局读条 | 最后 4 分钟只保留一个高潮 |
| 30:00 | — | 结算 | 立刻切断，不拖尾 |

**反模式（必须避免）**：在 10–20 分钟之间出现"三方都在等"的空窗。对策是每 8 分钟的全场事实播报 + 破坏回声 + 撤离点公告，确保任意时刻至少有一方在推进。

## 10. 失败、学习与观战循环

| 状态 | 玩家体验 | 必须给的信息 | 设计目的 |
|------|----------|--------------|----------|
| 被击倒 | 15 秒倒地窗口，可呼救 | 击杀者方向（不是精确位置） | 给队友救援窗口，给本人"下次别走这条路"的线索 |
| 被淘汰 | 进入观战 | 自由视角、队友视角、事件时间线 | 不让玩家无聊到退出 |
| 被逮捕 | 囚禁视角，可被救 | 拆铐进度、救援者接近提示 | 保留翻盘希望 |
| 撤离成功 | 观战 + 结算预览 | 自己带出的明细 | 正反馈：我的选择值钱 |
| 队伍失败 | 结算面板 | 三条胜利路径各自差多少 | 明确"下次差在哪"，而不是"被碾压" |

### 观战设计（防止 20 分钟空转）

- 可切换任意存活玩家视角（不显示其 HUD 私有信息）。
- 可查看"事件时间线"：谁在何时破坏了什么、谁撤离、谁被抓。
- **不允许**向存活队友发送任何信息（无幽灵 ping、无语音）。观战是"看"，不是"帮"。
- 终局后自动剪辑 30 秒"最佳镜头"（破坏、撤离、逮捕各一段）。

### 结算面板（学习闭环）

按队伍分栏，逐项列出：
1. 我的得分来源（偷了什么/拿到什么证据/逮捕了谁）
2. 我损失了什么（掉货、被烧的证据、被抓次数）
3. 三条胜利路径的最终进度（例如：盗贼 8700/10000、调查 6200/10000、庄主 存活到 27:41）
4. 一个"关键失误/关键操作"回放片段

## 11. 局外循环

| 项 | 内容 | 是否影响数值 |
|----|------|:----:|
| 队伍熟练度 | 每队 1–10 级，按"达成目标的行为"给经验（不是按击杀） | 否 |
| 解锁 | 每队 2 个备用外观、3 个工具皮肤、1 个备用角色 | 否 |
| 组队 | 好友组队锁定同队；不足 9 人由 AI 补位 | — |
| 挑战 | 每周 3 个"行为挑战"（例：不破坏任何墙体完成一次撤离） | 否 |
| 自定义房间 | 可调局时长、目标值、破坏强度 | — |

**不做**数值成长、不做开箱、不做装备属性。PvP 公平是这款游戏能否有长期对局的前提。

## 12. 边界情况与循环断裂

这些是循环设计里最容易漏、也最容易毁掉一局的地方，逐条给处理方案。

| 情况 | 风险 | 处理 |
|------|------|------|
| 盗贼全部撤离但总分 < 10000 | 盗贼队永久失去达成路径，4 人提前观战 | 盗贼队判负；游戏继续（庄主 vs 调查）；结算如实显示"差 X 分" |
| 盗贼全部被淘汰 | 同上 | 同上；庄主"击杀所有"成立则直接获胜 |
| 庄主 2 人全灭 | 庄园陷落，另两队无人干扰 | 不判负：撤离读条减半、调查透视冷却减半；庄主队实际出局但保留"拖满 30 分钟"的名义胜利可能（需拍板，见 C4） |
| 调查队 3 人全灭 | 无人能逮捕，无人能解锁 | 调查队判负；游戏继续，庄主与盗贼竞速 |
| 证据被烧到 < 10000 | 调查队无法解锁 | 保留"逮捕"作为唯一路径不可行 → 调查队判负，如实显示 |
| 地图被拆到无法通行 | 有人被埋/无路可走 | 承重结构塌方后强制保留一条连通路径；服务器每 30 秒校验关键连通性 |
| 有人卡进体素 | 卡死 | 客户端"卡住"按钮 5 秒后传送到最近可站立格（服务器校验，30 秒冷却） |
| 全员都在蹲点不推进 | 空转 | 8 分钟事实播报 + 撤离点开启后的公告压力；不做强制驱赶 |
| 玩家中途退出 | 队伍人数不齐 | 3 分钟内可重连；超时由 AI 接管该角色的基础行为（仅巡逻/搬运，不做高级决策） |

## 13. 循环验证指标（M1 / M2）

不做主观验收，用"行为是否发生"判断循环是否成立。

| 循环环节 | 验证指标 | 通过线 |
|----------|----------|--------|
| 交互循环 | 每局每名玩家主动发起读条交互次数 | ≥ 5 次 |
| 战术循环 | 每局至少一次"因噪音而改变路线"的行为 | 观察局中 ≥ 3 次 |
| 破坏咬合 | 每局被破坏的体素数 / 可破坏体素总数 | 8%~25%（太少=没动力，太多=地图被夷平） |
| 盗贼闭环 | 首次公告时间 / 首次撤离尝试时间 | 公告 8~16 分钟；撤离尝试在公告后 4 分钟内 |
| 调查闭环 | 解锁时间分布 | 20~27 分钟（早于 20 分=太容易，晚于 27 分=来不及收网） |
| 庄主闭环 | 庄主主动离开岗位去追击的次数 | 每局 3~8 次（0 次=在挂机，>12 次=防线必失） |
| 三方胜率 | 各队胜率 | 各 25%~40%（庄主略低可接受） |
| 观战体验 | 淘汰后玩家留存到本局结束的比例 | ≥ 70% |

## 14. 待拍板（循环层）

| 编号 | 问题 | 建议默认 | 影响 |
|:----:|------|----------|------|
| C1 | 撤离者是否允许重新入场？ | 不建议（保持"撤离=安全"的语义），用"盗贼判负但游戏继续"兜底 | 影响盗贼队 4 人的观战时长 |
| C2 | 调查队在盗贼全撤后只需抓庄主 2 人会不会太便宜？ | 建议加"最低收网数"：至少 3 人（含庄主）才算收网完成 | 影响调查队胜利难度 |
| C3 | 破坏痕迹/修补痕迹是否作为可取证证据？ | 建议做（300~500/处），这是三方咬合最便宜的实现 | 影响调查队的信息优势 |
| C4 | 庄主全灭后是否直接判负？ | 建议不直接判负，改为"庄园陷落"（撤离读条减半、透视冷却减半） | 影响 2 人队的容错 |
| C5 | 是否加"藏货点"（盗贼可中途存货，被抓不掉已藏部分）？ | 建议 M2 后评估；首版不加，避免循环过复杂 | 影响盗贼的风险曲线 |
| C6 | 中段是否需要"进度播报"？ | 建议每 8 分钟一次事实播报 | 影响空转 |
| C7 | 局时长默认 30 分钟还是 15 分钟快速版？ | 建议匹配默认 15 分钟（目标值减半），30 分钟进自定义 | 影响组局难度 |
| C8 | 淘汰后观战是否允许"事后解说"给队友？ | 不允许（破坏公平），只保留自由视角与时间线 | 影响观战乐趣与公平 |
