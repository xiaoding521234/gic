# 战场与资源

> 战场规格与地形、局内四资源、核心宝箱、动态战场、战争迷雾。关联：移动/阻挡/体积判定见 05 §5.3；资源发放时机见 04 §4.3；经济全链路见 10。

## 3.1 核心宝箱（**未实装**，数据位已留）

- 开局时，每个玩家的协议核心周围**随机刷出3个核心宝箱**
- **只有敌人可以开启**（己方无法开自己的箱子）
- 敌人开启宝箱获得：
  - **升变**：提升1个命座
  - **传送**：传送回自己的协议核心
  - **资源**：摩拉、物品

> **实装状态**：代码仅有 `ActionType.OpenChest` 枚举声明，无执行器实装（2026-10-08 全库扫描确认）；升命/传送/资源三效果均未接线。实装前本表为设计目标，非现状。

### 3.2.1 资源点（2026-10-27 实装，决策九十三）

- **资源点=非地形非单位的独立实体**：不占格体积、不参与阻挡——单位可正常站上/穿过（与单位同格共存是常态）。
- **首个资源点=摩拉堆**：可采 **10 次**，每次采集获得 **5 摩拉**；第 10 次采完从地图消失。
- **采集路径两条（2026-11-10 重定义）**：①**普通读条采集（通用）**——单位在资源点中心 **50cm 半径内**且无主动行动时自动读条，默认 **3 秒**完成一次（资源点可配采集时间）；主动移动/施放技能、硬控或离开范围会中断，**普通受击、非硬控减益、被动效果和被动位移本身不打断**（被动位移出范围仍中断）。完成后仍满足条件则自动开始下一次。单位配置新增 **采集效率**（默认 100）：实际时间=资源点时间×100÷效率，50/100/200 对应默认 6/3/1.5 秒；②**安柏移动快速采集**——实际移动时进入移动技能 `CollectRadius` 真圆且该点独立 `CollectCooldown` 冷却结束，按 `CollectCount` 采集并额外获得技能配置的体力/元能；冷却按 `(unitId, resourceNodeId)` 记录，1A「一飞双采集！」用自身 `CollectCount` 覆盖基础次数。两条路径共用资源余量，均逐 tick 由 Host 结算，不再于移动结束或秒拍末补算。普通读条显示进度与剩余秒数。
- **采集型角色 AI**（拍板⑦）：有采集 tag 或移动技能 CollectCount>0 的角色，AI 相比攻击敌人更主动采集资源点（距离衰减保证够得着才优先；资源点耗尽后回归战斗行为）；**采集角色对资源点自带透视**（迷雾内的堆照去——核心透视同构，2026-10-28 返拍）。
- **地图配置**：布局字符 '$'=摩拉堆（地形回落草地）；`BattleMapConfig.resourceNodeHarvestOverrides` 按格覆写普通采集秒数，缺省或值≤0回落 3 秒。星落湖现摆 4 堆（(3,5)/(11,5)/(3,9)/(11,9)——环湖四角、交战必经），未配置覆写。
- **表现（2026-10-27 追拍「直接用摩拉素材+数量随采集变少」；2026-10-28 返修=55° 平面内堆叠+迷雾隐藏）**：摩拉堆=官方摩拉图标立式小片堆，**件数=剩余可采次数**（满堆 10 件金字塔，采集逐次从顶减件、第 10 次采完堆消失）；金字塔沿 55° 斜面盘升（面内堆叠——平移视角不浮空）；**迷雾中隐藏**（未探索格堆件不可见，探索过后永久可见）。

## 3.3 战场基本规格

- 战场为**平铺网格**，无高低差概念
- 初始尺寸：**15×15**（2026-09-30 由 20×20 两轮缩小：砍外围草地两圈+缩小湖，中央 3×3 岛不变；BattleMap_FirstMap 即此规格）
- 上限尺寸：**50×50**
- 没有地形的格子用**虚空**填充（不可通行、不可放置）
- **格子距离采用切比雪夫（Chebyshev）度量**：两格距离 = max(|横坐标差|, |纵坐标差|)——对角偏移与正交偏移同距（八方向等价）；**"半径 N 的范围"** = 以中心格为基准、切比雪夫距离 ≤ N 的全部格子（**正方形区域**：半径 1 = 9 格、半径 3 = 49 格）。**注意：切比雪夫度量只用于距离与范围声明；单步移动方向限十字四向（见 05 §5.3）**——斜向格计距为 1，但不可作为移动落点

## 3.4 地形类型

每个格子有**地形属性**。已落地七类（2026-09-27 地形批次）：**草地/石路/水/沼泽/虚空/土地/圆石**（TileType：Grassland=2 / StonePath=6 / Water=101 / Swamp=102 / Dirt=7 / Cobblestone=8；BattleMapConfig 字符行 G/P/W/S/D/C/.）；岩浆等其余设计地形待后续地图批。

### 出生点

- 每个玩家的出生点固定为**3×3的石路地形**
- 出生点位置在战场上对所有人可见（通过迷雾也能看到地形）

## 3.5 战场动态变化

- 战场**不是固定的**，玩家可以通过技能改变地形：
  - **扩大战场**：将虚空格子变为有地形格子
    - 例：北斗可以把周围虚空变为**水**，使该格变为可通行的水域
  - **摧毁格子**：将有地形的格子变为虚空
    - 例：雷神的元素爆发可以**摧毁格子为虚空**
- 这意味着战场会随着对局推进**不断变化**——前期小战场空间紧张，后期战场扩大但关键格子可能被摧毁

## 3.6 战争迷雾

- 2026-10-17 迷雾批落地（docs/active/44）：**纯表现层系统**（客户端本地计算本方探索集，Host 模拟零感知），提供两种模式
- **对战迷雾（Skirmish，房间对战默认）**：类似红色警戒2——未探索区域被**半透明迷雾**覆盖，可以
  看见地形但**看不见单位、建筑、宝箱**；虚空格不盖（豁口正常可见）。用于玩家开房间对战时
  不用记忆地图（雾=「没去过」标记）+前期侦察博弈
- **任务迷雾（Mission，任务系统用）**：未探索格替换为**统一混沌地形**（不透明盖，虚空格同罩）
  ——玩家无法知道这个格子是什么地形，探索感；测试入口=指令 `fog mission`
- 一旦探索过该区域，**永久可见**（不再有迷雾）
- 探索范围=**探索视野**（原「迷雾视野」，2026-10-17 改名）：本方阵营存活单位（含建筑）以自身
  为心的切比雪夫范围（**默认 1**——2026-10-17 追拍改值；安柏/协议核心=2，开局核心周界 5×5）
  逐帧揭雾，移动途中即时揭雾；队友共享视野
- 由于出生点为固定3×3石路地形，对战迷雾下玩家可以通过雾中的地形特征推断对手的大致方位
- **泄露口径（用户拍板；2026-10-17 追拍二区分规划期/执行期）**：规划期单位类零泄露（瞄准候选/
  预判描边/推荐色/执行预览对迷雾内敌方按不存在）；地形类允许（移动路径绕行/部署合法性）；
  **执行期按归属方**——我方特效恒显（箭矢全程+命中伤害数字，即便目标在迷雾内）、敌方特效
  （箭矢/箭雨等）只有飞到已探索格才显示
- **AI 也受雾限（2026-10-17 追拍三）**：AI 三脑/威胁图/战略层只见自己队伍探索过的敌方（Host 侧
  探索账本，与玩家同规则）——但**自带透视协议核心的位置**（否则无法自主攻城）：敌方核心对 AI
  恒可见（位置/血量），眷属攻城锚与终局判据零回归；结算不受雾限（打进迷雾照样命中）
- 安柏侦察（破雾+暴露敌人）/2命（爆发破雾得元能）/1命（视野+2）三条休眠机制待 Host 侧
  探索账本批激活（docs/active/44 §9）

## 3.7 设计意图

- 地形本身提供策略深度（不同地形影响移动/战斗）
- 战场扩展=领土争夺（谁先把虚空变成自己的地形，谁就获得更多空间）
- 格子摧毁=战术断路（摧毁关键通道可以切断敌方进攻路线或保护己方核心）
- 角色的地形相关技能（如北斗造水、雷神毁格）让地形变化成为角色特色的一部分
- 战争迷雾=前期侦察博弈（探索敌方核心位置/宝箱位置/建筑布局）
- 半透明迷雾让玩家能通过地形特征（如3×3石路出生点）推断对手方位，减少纯随机摸索，保留信息博弈深度
