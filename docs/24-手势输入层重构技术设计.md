## 2. 调研基线：业界框架 ↔ 本项目组件对照

| 业界组件 | 出处 | GIC 对应 |
|---|---|---|
| GestureBinding（指针路由+hitTest 门） | Flutter | `PointerInputPump`（legacy Input 唯一轮询点，鼠标/触摸归一）+ UI 命中门（收编三份 IsPointerOverUI） |
| GestureArenaManager | Flutter | `GestureHub` 简化仲裁（first-accept-wins，见 §7 决策 3） |
| GestureRecognizer 基类 + kTouchSlop/kPressTimeout 常量 | Flutter | `GestureRecognizer` 抽象基类 + `GestureMetrics` 常量表 |
| UIGestureRecognizer 状态机（possible/began/changed/ended/cancelled/failed） | Apple | `GestureState` 8 态（含"被其它识别器挤掉"的 Failed 出口） |
| delegate 四问（shouldReceiveTouch/shouldBegin/simultaneous/requireFailure） | Apple/TouchScript | surface 的 `ShouldReceivePointer` 过滤（其余三问按需再加） |
| MinPointers/MaxPointers 指针数阈值 | TouchScript | 识别器构造参数（Pinch=2、其余=1） |
| ViewConfiguration 常量（8dp slop/100ms/400ms/300ms） | Android AOSP | `GestureMetrics` 取值基准 |
| 长按=按下挂定时器+三取消源+触发后独占 | libGDX/Flutter 同构 | `LongPressGestureRecognizer`（P1 实现、暂无消费者，B6/卡牌长按预留） |
| 捏合起手取消单指+一指抬起无缝转拖 | libGDX | `PinchGestureRecognizer` + hub 单指取消规则（Pet/Map 现有语义同构） |
| VelocityTracker/末速 EMA | Android/libGDX/Map 现有 | 末速跟踪留 `DragGestureRecognizer` 通知、EMA 留消费者（Map 0.04s 常数已调优） |

**明确不抄**：完整 Flutter Arena（嵌套竞争由 Unity 命中层天然解决）、Input System 迁移（与收敛解耦）、TouchScript 的 per-object MonoBehaviour 手势件（GIC surface 少，纯 C# + DI 更合项目风格）。

## 3. 目标架构总览

```
Legacy Input.*（唯一轮询点）
  └─ PointerInputPump（Wargame managers 管线驱动，InputManager 之后）
       ├─ 鼠标 → 指针 id=0，Kind=Precise
       └─ 触摸 → 指针 id=1..N，Kind=Touch（fingerId↔pointerId 映射；两指模拟右键陷阱见 InputManager L211 既有补丁）
            ↓ PointerEvent{ id, kind, position, phase(Began/Moved/Stationary/Ended/Cancelled), time=Time.unscaledTime }
  GestureHub（[Component] 纯 C# Manager）
       ├─ 门1 输入锁：InputLocks.IsLocked → 新事件不分发 + 进行中识别器 ForceCancel
       ├─ 门2 UI 命中：EventSystem id 式（鼠标）/位置式（触摸 Began 帧，Map L470 实证教训）→ UI 指针不进世界 surface
       ├─ 门3 surface 过滤：ShouldReceivePointer（如游戏内桌宠"命中模型才收"）
       └─ 仲裁：同 surface 第一个宣胜（Recognized/Began）→ 其余识别器 Failed；Pinch 起手 → 单指识别器 Cancelled
            ↓
  识别器（纯 C#，不依赖 UnityEngine.Time/单例，时间戳由 PointerEvent/Tick 注入——可用合成事件流离线断言）
       TapRecognizer（chain 模式含连击窗口=Flutter hold 语义） / LongPressRecognizer / DragRecognizer / PinchRecognizer
            ↓ 消费者回调
  MapCameraController / BattleCameraController / PetInGameHostController / WaitForAnyTap 订阅方
```

- **驱动点**：与 InputManager 同列注册进 `Wargame` managers 列表（GameScene.Update→Wargame.Update 管线），顺序 InputManager → GestureHub。
- **桌面宠物进程**：跳过 Wargame 组合根（GameScene L77）→ PetWindowController 无 hub 可用，**独立 Win32 轮询是其架构必然**，仅共享 GestureMetrics 语义注释。

## 4. 核心抽象（Assets/_Scripts/Framework/Input/Gestures/）

### 4.1 指针事件流

```csharp
public enum PointerKind { Precise, Touch }                       // Flutter: precise pointer 单独 slop 档
public enum PointerPhase { Began, Moved, Stationary, Ended, Cancelled }
public struct PointerEvent { int Id; PointerKind Kind; Vector2 Position; PointerPhase Phase; double Time; }
```

- Pump 每帧 diff 上一帧指针集：新按下→Began、位移→Moved、静止(触摸)→Stationary、抬起→Ended、触摸系统取消/超窗→Cancelled。
- 触摸→鼠标模拟保持全局开启（游戏内桌宠拖拽依赖它，InputManager L213 注释），Pump 按指针 id 去重（同一物理触摸只产一路事件，鼠标 id=0 与触摸 id≥1 并存时桌面语义=鼠标）。

### 4.2 状态机（Apple/TouchScript 8 态）

```csharp
public enum GestureState { Idle, Possible, Began, Changed, Recognized, Ended, Cancelled, Failed }
```
- `Recognized`=离散手势完成（Apple discrete ended；TouchScript `Recognized=Ended` 同义分立）；`Ended`=连续手势正常收尾；`Failed` 含"**被同 surface 其它识别器宣胜挤掉**"（TouchScript 原注释语义）；`Cancelled`=外部打断（输入锁/第二指针仲裁/UI 门）。

### 4.3 识别器基类与四件套

```csharp
public abstract class GestureRecognizer
{
    public GestureState State { get; }            // 迁移只经内部 Set* 方法
    public int MinPointers { get; }               // TouchScript 指针数阈值
    public int MaxPointers { get; }
    public void HandlePointerEvent(PointerEvent e); // hub 唯一入口
    public void Tick(double now);                  // hub 每帧喂（长按/超时 deadline 自查，无协程）
    public void ForceCancel();                     // 锁/UI 门/仲裁调用 → Cancelled
    // 识别器内部宣胜出口：SetRecognized / SetBegan / SetChanged / SetEnded / SetFailed / SetCancelled
    // hub 仲裁钩子：宣胜瞬间回调 hub → 同 surface 其余识别器 ForceFail
}
```

**TapRecognizer**（离散）：
- 判定=抬起时落点位移 < slop（**业界共识：tap 不因超时失效，只因移动失效**——Android TAP_TIMEOUT 不用于此，Flutter 同）。
- `ChainMode`（桌宠用）：累计 count 命中 `dispatchAtCounts` 档位（如桌宠 {2,3}）立即派发该 count，其余档位持有窗口（GestureMetrics.TapChainWindow）等下一次 down 升级、窗口空档按累计 count 派发——即 Flutter hold/release 的"双击等待"机制化 + 桌宠"双击退出立即响应"语义。参数：MaxTapCount、窗口内落点连续性（libGDX tap 矩形语义，TapChainSlop）。
- **Immediate 拖拽面的"短位移点击"不挂竞争型 TapRecognizer**——复合进 DragRecognizer 的 `ShortTap` 发射（抬起时总位移 < slop 即伴发点击，libGDX/Android GestureDetector 的 tap+pan 同体模式）；宣胜竞争仲裁只存在于升级式拖拽面（Pet 式）。

**LongPressRecognizer**（连续，Apple 语义）：按下挂 deadline=450ms（Android 400/Flutter 500 取中）；三取消源=位移出 slop/提前抬起/第二指针起手仲裁；deadline 到 → `Began` 宣胜独占，此后按住移动 → `Changed`（消费方可只取 Began 当离散事件用），抬起 → `Ended`。

**DragRecognizer**（连续）：
- `BeginMode = Immediate | OnSlop | OnSlopOrHold`：Map/Battle 相机=Immediate（抓住即拖零延迟，手感已验证）；Pet=OnSlopOrHold（0.15s 或 8px 升级，用户拍板值）；纯 UI 拖放（B6 若需）=OnSlop。
- 回调带逐帧 delta 与末速（EMA 常数沿用各消费者已调优值——速度数学留在识别器通知、衰减/滑行决策留消费者）。

**PinchRecognizer**（连续）：MinPointers=2；起手即 hub 取消同 surface 单指识别器；比例式（Map 现语义 `pinchStartSize * startDist/dist`）；一指抬起→Ended（消费者自行决定转拖，libGDX 无缝转拖语义）。

### 4.4 GestureHub 与 Surface

```csharp
public interface IGestureSurface
{
    bool Enabled { get; }                          // Map 入场动画/面板打开时自行关
    bool ShouldReceivePointer(PointerEvent e);    // Apple shouldReceiveTouch 等价（桌宠"命中模型"）
    IReadOnlyList<GestureRecognizer> Recognizers { get; }
}
```
- Hub 持 `List<IGestureSurface>`（注册/注销，Screen/Controller 在 Start/OnDestroy 管理）。
- UI 命中门在 hub 层实现一次（收编三份 IsPointerOverUI）：鼠标走 `EventSystem.IsPointerOverGameObject`，触摸走位置式（GraphicsRaycaster 结果缓存——移植 Map 现有 `_uiRaycastBuffer` 静态缓存，避免每帧分配）。
- 输入门：hub Update 开头 `InputLocks.IsLocked` → Freeze（新事件丢弃+活跃识别器 ForceCancel）——与今天 Map/Battle 冻结语义一致。

### 4.5 GestureMetrics 常量表

```csharp
public static class GestureMetrics
{
    // —— 位移档（物理像素；Flutter 实证：8 太紧投诉后升 18；精确指针单独 1px 档）——
    public const float TouchTapSlop = 24f;    // Android 8dp@3x 物理等效
    public const float PreciseTapSlop = 4f;  // 鼠标档（业界 1px 太极端，取 4）
    public const float ChainSlop = 100f;     // 连击落点连续性（Android DOUBLE_TAP_SLOP）
    // —— 时间档（ms；Android/Flutter 基准）——
    public const float HoldToDragTimeout = 150f;  // Pet 桌宠拍板值 0.15s 入表为默认
    public const float LongPressTimeout = 450f;   // 新手势基准（400/500 取中）
    public const float TapChainWindow = 300f;     // DOUBLE_TAP_TIMEOUT
}
```
- **全局统一（2026-09-13 用户拍板，推翻此前"保留覆写"推荐）**：手势语义阈值一律取 GestureMetrics——Map `clickMoveThreshold=12`/Pet `8px` 序列化字段删除，点击判定统一走双档 slop；Pet `0.15s` 升级为 `HoldToDragTimeout=150ms` 全局默认（拍板值直接入表，零迁移损失）；连击窗口统一 300ms（原桌宠 0.4s 随之收敛）。**域参数不属手势语义**（滚轮步进/滑行衰减/EMA 常数/缩放平滑），仍留各控制器序列化字段——那是相机手感域，不是点击/拖拽判别。手感回归风险由各阶段目检清单兜底（§6）。

### 4.6 可测性设计约束（铁律）

识别器**纯 C#、零 UnityEngine 依赖**（仅 Vector2 数学），时间戳由 PointerEvent/Tick 注入 → 可用合成事件流在 exec_editor_script 内直接断言状态迁移，不需要 Play Mode/测试框架。P1 验收即以此法跑 12+ 组断言（§6）。

## 7. 决策记录

1. **2026-09-13 用户拍板**：采用业界最优方案大重构，趁项目小；调研先行（webrefs/gesture-input 全套源码级信源）。
2. **状态机**取 Apple/TouchScript 8 态：Recognized 与 Ended 分立（离散/连续语义清晰），Failed 含被挤掉出口。
3. **仲裁取简化 first-accept-wins**：Flutter 完整 arena 服务于"同一命中链多 GestureDetector 嵌套竞争"，GIC 嵌套消歧由 Unity 命中层天然完成，引入=过度设计；保留 arena 的两关键语义——宣胜独占（其 Failed）与连击 hold 窗口。
4. **tap 不因超时失效**（业界三源共识），Pet 的 0.15s 是拖拽升级阈值而非 tap 时限，模型化为 DragRecognizer.OnSlopOrHold。
5. **常量双档**（Precise/Touch）入 GestureMetrics；**2026-09-13 用户拍板全局统一**：手势阈值不做 per-surface 覆写（推翻"保留覆写"推荐）——Map 12px/桌宠 8px 由统一双档取代、0.15s 入表为 HoldToDragTimeout、连击窗口统一 300ms；域参数（滚轮步进/滑行衰减/EMA）不属手势语义仍留控制器。手感回归风险由各阶段目检清单兜底。
6. **长按**默认 450ms，识别器 P1 落地、暂无消费者（B6 选格/卡牌长按详情预留）；取 Apple **连续语义**（deadline 到 Began、按住移动 Changed、抬起 Ended），消费方可只取 Began 当离散用。
7. **滚轮/键盘不进指针流**：滚轮=轴输入留轮询；键盘走 InputManager 原路（含触屏忽略鼠标键位补丁，InputManager L211 保留）。
8. **不迁 Input System**（与收敛解耦）；**DeckRow/uGUI IPointer 路线不动**；**Win32 桌宠独立**（桌面进程无 Wargame，架构必然）。
9. **识别器纯 C#+时间注入**：合成事件流可离线断言，不依赖 Play Mode/测试框架。
10. **同轮拍板（2026-09-13）**：Immediate 拖拽面的点击=DragRecognizer 的 ShortTap 复合发射（libGDX/Android tap+pan 同体模式），不挂竞争型 TapRecognizer——宣胜仲裁只存在于升级式拖拽面。
