# 八、势力衍生玩法

势力机制之外，每个势力还拥有**衍生玩法** — 通过特定角色或建筑触发的子系统，进一步丰富势力特色。

## 8.1 蒙德 — 炼金

- **核心角色/建筑**：阿贝多、炼金台建筑等
- **机制**：
  - 可以把**任意物品**分解为**元素结晶**
  - 元素结晶可以**合成为任意物品**
- **设计意图**：
  - 物品回收+再造系统，让多余的物品卡不浪费
  - 玩家可以把不需要的物品转化为需要的物品，增加局内灵活性

## 8.2 璃月 — 再生

- **核心建筑**：水车建筑
- **机制**：
  - 将**食物或材料物品**放入水车
  - 水车会**持续稳定地产出**对应的物品
- **设计意图**：
  - 物品量产系统，投入一个小麦 → 持续产出小麦
  - 让消耗品不再是一次性的，建立"生产线"概念

## 8.3 挪德 — 月矩力

- **核心机制**：红矩力与蓝矩力
- **规则**：
  - 红矩力与蓝矩力**相互吸引**（异色相吸）
  - 同色矩力**相互排斥**（同色相斥）
  - 通过特定方式可以让**单位附着上矩力**
- **设计意图**：
  - 物理推拉系统 — 通过矩力的吸引/排斥来控制单位位置
  - 可以用来拉近敌人、推开友方、改变战场格局
  - 是七势力衍生玩法中唯一的**空间操控**手段

## 8.4 枫丹 — 机械科技

- **核心概念**：用多个建筑组件（活塞、齿轮等）组装**机械战舰**
- **机制**：
  - 玩家在网格上放置多个机械建筑组件（活塞、齿轮、炮台、底盘等）
  - 相邻的机械组件自动**连接组装**为一个整体——机械战舰
  - 组装完成的机械战舰可以**移动、转向**
  - 战舰上的炮台等组件可以**攻击**
  - 不同组件组合产生不同效果（如：活塞提供推进力、齿轮提供转向、炮台提供火力）
- **设计意图**：
  - 枫丹衍生玩法的核心是**打造属于自己的巨型战争机器**
  - 不是自动化生产线，而是**可移动的组装战斗单位**
  - 组件越多战舰越大越强，但也被攻击面越大
  - 组件被摧毁则战舰功能受损（炮台被打掉就不能开火，活塞被打掉就不能移动）
  - 与枫丹芒荒形态呼应：战舰整体也可能有芒/荒两种运转模式
