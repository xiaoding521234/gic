## 4.1 时间模型：20Hz tick 状态机

- 模拟步进=**固定 tick，1 tick=1/20 秒**（RTSFlowController accumulator 累加器+每帧步数 clamp——模拟跟不上时整体慢放不欠债；巨帧钳 0.25s 防切后台快进）
- **定点整数纪律**：位置 1 单位=1cm、1 格=100、时间全 tick 计数——同 seed+同命令流=同战局（确定性=回放回归安全网〔ReplayRunner v2〕与后置实时联机的共同地基）
- **无选择阶段/无执行排序/无配额**：行动上交即校验即结算（体力=手动操作唯一节流）；每拍窗口序与 RTSFlowController.TickAdvance 同构——①移动推进（mover 每 tick 步进、到达/被挡收尾）→②AI 节拍窗（%10）→③秒拍（%20）→submit 窗（本拍内上交的行动依次结算）

| 拍 | 频率 | 内容 |
|---|---|---|
| **AI 节拍** | 每 0.5 秒（%10 tick） | 探索账本同步（RevealFog——决策时态）→眷属脑（启发式）+伙伴脑（评分制）批演算；配额脑（场景件）沿 Selecting 事件驱动同频决策；伙伴脑感知窗口=本窗口内玩家已上交行动 |
| **秒拍** | 每 1 秒（%20 tick） | 体力/摩拉发放（+1/+1）、Buff 计时递减、泡湿、灵魂衰减、资源点站立采集、建筑效果、全量快照广播（对账/自愈）、战斗时钟 +1 分钟、desync hash |
| **效果拍** | 每 2 秒（%40 tick） | Buff tick 效果（燃烧/光环/DoT）+建筑效果单次结算——2026-11-04 拍板「时间翻倍」拆两档：秒拍族恒每秒、效果族每 2 秒（单次数值不动=拍板字面；倍率调参见 docs/18 决策九十五 P5 挂账①待拍板） |

- **胜负判定**：协议核心摧毁=唯一败北判据（**队伍口径**——队败=该队全部玩家核心被摧毁；同拍互灭=平局语义保留）——每行动结算后+每秒拍后检查
- **单人局浏览暂停（N0，决策六十七）**：打开任意浏览界面（布局编辑/手牌卡详情/数据面板/技能详情/退出确认弹窗）=**tick 暂停**（BattleSession 门控 IsSoloHumanGame——多人局不冻全场；表现层照常播放；2026-11-05 P6 批修复 P1 重写时的断链）

## 4.2 操作与节流（配额制退役）

- **体力层级表不变**（眷属 0/伙伴 5/魔神 10；玩家操控伙伴减免 5、可减免为负=获得体力）；体力/CD/元能为行动自然节流，**无每回合行动配额**
- **技能 CD**：战技 **3 秒**（=MOBA 普攻地位，无独立普攻——战技 CD 即攻击节奏）+爆发 **5 秒**+元能门槛双 gate；技能键 CD 转圈+剩余秒数+未就绪拦截（快捷面板爆发键同款转圈）；势力技能 0 体力无 CD
- **释放速度**=1+攻速/100：时轮发射/命中时刻与动作片播放速率同乘该倍率；**攻速全员 0**（旧攻速排序/片序公式随回合机退役）
- **移动双形态**（免费：0 体力 0 元能；全员移速 100cm/s=1 格/秒；碰撞圆 0.5 格——敌/尸体/建筑硬挡、友军可穿不可停）：
  - **点击式**：点地走点**不限距**（LoL 式；A* 寻路 Host 权威、射程外钳边）
  - **拖拽式=真摇杆**（王者荣耀式）：**按住=朝盘方向持续行进、拖回盘心=停、松手=停**；变向超 ~15° 才重提交（持稳不刷命令）；移动循环片=移动期间循环播放
- **购买/部署/升命/物品/装备**：即时通道——即时校验即时结算即时生效（不占任何节流）；部署=**自由落点**（欧氏半径+锚点并集+星级链前置）
- **AI 施放节流**：同单位同技能最短 **2 秒**重施（治无 CD 技能 0.5s 刷屏死水）；AI 候选域过 CD/元能/体力门槛

## 4.3 体力与摩拉发放

- 玩家初始 **200 摩拉 + 60 体力**；编入备战卡组的货币物品牌=开局增量（卡位换开局经济=真实构筑选择，照旧）
- **每秒发放 +1 摩拉 +1 体力**（秒拍——旧「每回合 +10」按 1 回合=1 秒直译）
- 建筑与角色技能可产出体力/摩拉（餐馆 +5 摩拉/效果拍、旗帜元能光环、教堂治疗等=docs/08）

## 4.4 时序模型与 Buff 计时

- **全程即时演算**——无「选择阶段软暂停」概念；唯一暂停位=N0 单人局浏览暂停
- Buff 计时=**秒制直读**（旧「N 回合」语义=N 秒：冻结 2 回合→2 秒、燃烧 3 回合→3 秒；施加当拍即开始递减）；tick 效果=效果拍每 2 秒结算一次
- 控制效果**即时生效**；移动中被控/被击杀=mover 自然终止+位置校正落位
- **战斗时钟**：每秒 +1 分钟（06:00 起）——昼 8:00~20:00（现实 12 分钟一循环）；音乐选池/建筑窗灯按此时段；**回合数显示退役**（顶部仅战斗时钟）
- **表现层**：命令流带 startTick 按绝对时刻播；移动补间按实际移速逐段推进+快照位置自愈（非移动中漂移 >15cm 拉回）；伤害/附着/弹数字按命令错峰（0.05s/条）
- **回放**：`replay on` 开录制（JSONL：AI 批/上交/购买/Segment/tick hash），Tools/TG/回放回归=演算层改动后的回归安全网（同 seed 同命令流必须逐命令逐 hash 一致）

> **稻妻连携窗/璃月契约时停（未实装势力）**：回合制旧案（连携 2 秒等待/时停 3 秒投票）**不迁移**——决策九十五拍板 6：实装时以即时制语境从零设计。
