# 胜负条件

## 2.1 协议核心

- 每个玩家拥有一个**协议核心**，位于己方阵地
- 协议核心具有血量，可被攻击

## 2.2 战败条件

- 玩家自己的**协议核心**被摧毁时，该玩家**战败**
- 战败玩家的所有单位（含尸体）被**消散**（从游戏中真正删除）
- 战败玩家进入**观战模式**

> **注意**：单位被击杀后变为尸体留在场上（见 docs/05-行动系统.md §5.4），不触发消散。消散仅在玩家战败时发生，清除该玩家所有存活单位和尸体。**消散**是真正意义上的从游戏中删除；**放逐**是转移到另一个维度，该单位仍然存在（可被特定技能召回，如丽莎的蔷薇的雷光）。

## 2.3 掠夺机制

- 摧毁敌方协议核心后，**获得对方的全部手牌**（加入己方局内牌库）
- 获得的卡牌可在**本局内使用**（包括角色卡可出战/升命座）
- 对局结束后，掠夺来的卡牌**不会带出**（未通过祈愿解锁的无法带回局外）
- 胜利者可以**带出自己通过祈愿解锁的卡牌**（即初始携带的8种中自己已拥有的）

## 2.4 原石结算

- 对敌人造成伤害会**爆出原石**
- 摧毁敌方协议核心爆出**大量原石**
- 胜利者的原石还会乘上**额外倍率**
- 原石用于局外的**祈愿抽卡**系统
