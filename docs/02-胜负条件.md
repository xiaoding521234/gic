# 胜负条件

> 胜负判定与结算：协议核心、战败消散/放逐、掠夺手牌、原石结算。关联：消散/放逐术语区分见 20 §4；尸体系统见 05 §5.4；核心宝箱见 03 §3.1。

## 2.1 协议核心

- 每个玩家拥有一个**协议核心**，位于己方阵地（出生区 3×3 石路的中心格，对局装配期放置）
- 协议核心具有血量，可被攻击

### 本体属性（2026-09-29 拍板 Unit 化，docs/18 决策十七）

- **形态**：单位化的建筑（unitType=Building）——**5★ 单位、HP 600**（5★ 血量回落表同值）；无技能、无移动、无命座、无元能；体积 2、**受击圆柱直径 0.8**（近乎占满格，大目标易命中=攻城手感）
- **阻挡**：**对双方都是墙**——核心格不可进驻、不可部署、敌我皆绕行；免疫强制位移（docs/05 §5.3 建筑既有规则）
- **受击与治疗**：可被攻击/附着/打反应/冻结（控制对无行动的核心为纯视觉）；**可被治疗但治疗效率 50%**（目标侧结算——防不死流）
- **行动域**：不参与任何行动——三脑分拣、玩家上交、执行预览全排除（单一判据 unitType，与星级无关）
- **显示与归属**：不做顶栏额外显示——血量读场上头顶条（与普通单位一致）；不可入卡组（不可获得、不进背包）；核心每玩家一枚（非每队一枚），队伍败北=该队全部玩家的核心被摧毁

## 2.2 战败条件

- 玩家自己的**协议核心**被摧毁时，该玩家**战败**
- 战败玩家的所有单位（含尸体）被**消散**（从游戏中真正删除）
- 战败玩家进入**观战模式**

> **注意**：单位被击杀后变为尸体留在场上（见 docs/05-行动系统.md §5.4），不触发消散。消散仅在玩家战败时发生，清除该玩家所有存活单位和尸体。**消散**是真正意义上的从游戏中删除；**放逐**是转移到另一个维度，该单位仍然存在（可被特定技能召回，如丽莎的蔷薇的雷光）。

## 2.3 掠夺机制

- 摧毁敌方协议核心后，**获得对方的全部手牌**（加入己方局内牌库）
- 获得的卡牌可在**本局内使用**（包括角色卡可出战/升命座）
- 对局结束后，掠夺来的卡牌**不会带出**（未通过祈愿解锁的无法带回局外）
- 胜利者可以**带出自己通过祈愿解锁的卡牌**（即初始携带的8种中自己已拥有的）

## 2.4 原石结算

- 对敌人造成伤害会**爆出原石**
- 摧毁敌方协议核心爆出**大量原石**
- 胜利者的原石还会乘上**额外倍率**
- 原石用于局外的**祈愿抽卡**系统
