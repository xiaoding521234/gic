# 四、回合流程

## 4.1 同时选择阶段

- 每回合，所有玩家**同时选择1个行动**
- 选择阶段结束后，进入执行阶段

### 选择时限

| 阶段 | 时限 |
|------|------|
| 第1回合 | 30秒（方便玩家商量战术） |
| 第2回合起 | 20秒 |
| 每发放一次体力后（每6回合） | 缩短4秒 |
| 最低时限 | 8秒 |

## 4.2 攻速排序执行

- 所有玩家选定的行动按**行动者攻速**从高到低排列
- 依次执行每个行动
- 攻速相同时，**先提交行动选择的玩家排在前面**（先决先执行）

> **设计意图**：攻速相同时用"提交顺序"作为 tiebreaker，奖励决策速度。同时回合制下双方虽然同时选择，但网络提交有先后——先做出决定的人获得执行优先权，增加博弈的心理压力。

## 4.3 体力发放

- 玩家**初始拥有2个原粹树脂**
- **每6个回合**，向所有玩家发放**2个原粹树脂**
- 体力是**稀缺珍贵资源**，玩家需要通过发育来获取更多体力
- 某些建筑或角色技能可以**产出体力**（具体待设计）

> **设计意图**：体力限制战斗行动频率，迫使玩家在"发育"与"战斗"之间做选择。前中期以部署/购买/经济为主，积累足够体力储备后发动关键战斗行动。发育投入越多，后期可调动的战斗资源越充裕。

## 4.4 摩拉发放

- 玩家**初始拥有200摩拉**
- **每个回合**，所有玩家自动获取**5摩拉**
