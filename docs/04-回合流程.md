# 四、回合流程

## 4.1 回合阶段

每个回合分为四个阶段，依次执行：

### 准备阶段

- 所有玩家**同时选择1个行动**
- 选择阶段结束后，进入行动阶段

### 行动阶段

- 将所有玩家选定的行动按**行动者攻速**从高到低排列，依次执行
- 攻速取**主动行动的角色**——延奏是主动行动，变奏是延奏触发的被动效果
- 因此变奏的触发时机取决于**发起延奏者的攻速**：延奏者攻速越高，变奏越早执行
- 攻速相同时，**先提交行动选择的玩家排在前面**（先决先执行）

> **设计意图**：攻速相同时用"提交顺序"作为 tiebreaker，奖励决策速度。同时回合制下双方虽然同时选择，但网络提交有先后——先做出决定的人获得执行优先权，增加博弈的心理压力。

### AI 行动阶段

- 1星、2星角色和造物由 AI 控制，依次行动
- 将所有 AI 单位的行动按**攻速**从高到低排列，依次执行

### 结束阶段

- 触发所有**回合结束时**的效果（如燃烧 DoT、寒冰之棱伤害、歌声之环治疗等）
- 按照代码中注册顺序执行（先来后到）

### 流程图

```
准备阶段（玩家选择行动）
  ↓
行动阶段（玩家行动按攻速排序执行）
  ↓
AI行动阶段（1-2星角色/造物按攻速排序执行）
  ↓
结束阶段（回合结束时效果，按注册顺序触发）
  ↓
准备阶段（下一回合）
```

## 4.2 选择时限

| 阶段 | 时限 |
|------|------|
| 第1回合 | 30秒（方便玩家商量战术） |
| 第2回合起 | 20秒 |
| 每发放一次体力后（每6回合） | 缩短4秒 |
| 最低时限 | 8秒 |

## 4.3 体力发放

- 玩家**初始拥有60个原粹树脂**
- **每6个回合**，向所有玩家发放**20个原粹树脂**
- 某些建筑或角色技能可以**产出体力**（具体待设计）

> **设计意图**：初始60体力保证前期有足够的战斗行动空间，玩家可以同时进行探索、部署和交战。中后期体力发放节奏不变，仍需在发育与战斗之间做取舍。

## 4.4 摩拉发放

- 玩家**初始拥有200摩拉**
- **每个回合**，所有玩家自动获取**5摩拉**
