# 五、行动系统

## 5.0 行动规则

- 每回合，玩家从下方所有行动中**选择1个**执行（无论是否消耗体力）
- 选择完毕后进入执行阶段，玩家行动按攻速排序执行（回合流程见 §4.1）
- **消耗体力的行动**与**不消耗体力的行动**的区别仅在于资源消耗，不改变"每回合1个行动"的限制
- 玩家也可以选择**空过**（本回合不执行任何行动）
- 体力耗尽时，玩家只能选择不消耗体力的行动或空过

## 5.1 消耗体力的行动

以下行动消耗10个体力（原粹树脂）：

| 行动 | 说明 |
|------|------|
| **移动** | 施加推力使单位沿直线方向移动（见5.3 移动与推力系统） |
| **战技** | 角色发动战技 |
| **爆发** | 角色发动元素爆发 |

## 5.2 不消耗体力的行动

以下行动不消耗体力。体力耗尽时，玩家只能从以下行动中选择：

| 行动 | 说明 | 消耗 |
|------|------|------|
| **出战角色** | 从牌库中部署一个新角色到场上（卡不消耗，留在手牌） | 摩拉 |
| **提升命座** | 对已出战的**3星及以上**角色重复出战，消耗摩拉提升命座 | 摩拉 |
| **出战建筑** | 从牌库中部署一个建筑到场上（卡不消耗，留在手牌） | 摩拉 |
| **购买卡牌** | 点击场上建筑 → 战技按钮 → 科技面板，花费摩拉购买新卡（角色/建筑），加入局内牌库。**购买费用=出战费用的一半** | 摩拉 |
| **使用物品** | 使用食物/饮料/材料等消耗品 | 物品本身 |
| **装备物品** | 装备武器/配件等 | 物品本身 |
| **势力特殊技能** | 使用势力独有机制 | 视技能而定 |
| **开启核心宝箱** | 开启敌方核心周围的宝箱 | 无 |

### 装备槽位

角色和造物根据星级拥有不同数量的装备槽位：

| 星级 | 武器槽位 | 配件槽位 | 总槽位 |
|------|---------|---------|--------|
| **1星** | 1 | 1 | 2 |
| **2星** | 1 | 1 | 2 |
| **3星** | 1 | 2 | 3 |
| **4星** | 1 | 3 | 4 |
| **5星** | 1 | 4 | 5 |

> **设计意图**：高星级角色不仅属性更强，装备灵活性也更高——5星角色可以同时装备兔兔伯爵+勾玉+圣遗物+其他配件，形成多样化的搭配。武器槽位固定为1，确保武器选择的策略性而非堆叠。

> **设计意图**：体力只限制"移动/战技/爆发"三类高强度战斗行动的频率。资源管理（元能/摩拉/物品）和战术部署（出战角色/建筑）不受体力限制，确保**每回合玩家都有事可做**。

### 星级与操控规则

| 星级 | 代表角色 | 出战摩拉 | 操控方式 | 重复出战 |
|------|----------|----------|----------|----------|
| **1星** | 火斧丘丘暴徒、丘丘人、丘丘射手、仙灵、丘丘打手等 | 10 | AI自主行动 | 可重复出战，不提升命座 |
| **2星** | 愚人众火枪手等 | 20 | AI自主行动 | 可重复出战， 不提升命座 |
| **3星** | 安柏、凯亚、丽莎等 | 50 | 玩家操控 | 提升命座 |
| **4星** | 琴、风魔龙等 | 100 | 玩家操控 | 提升命座 |
| **5星** | 巴巴托斯等 | 300 | 玩家操控 | 提升命座 |

- **1星、2星角色**部署后交由AI控制，每个小回合结束时自主行动，玩家不可操控
- **1星、2星角色**可以重复出战且**不提升命座**（直接在场上增加一个同类单位）
- **3星及以上角色**重复出战则提升命座（见 §九 命座系统）

## 5.3 移动与推力系统

### 核心机制

移动不是路径规划，而是**推力驱动**。玩家选择方向，施加推力（ForceData），单位沿直线移动对应格数。

- 每次移动 = 施加一个 ForceData（方向 + 力度 + 类型）
- 移动类型（ForceType）：步行 / 飞行 / 两栖 / 击退 / 牵引 / 跳跃 / 瞬移
- 力度（Magnitude）= 移动格数
- 月矩力（挪德衍生玩法）也通过 ForceData 施加推力
- **建筑免疫强制位移**：建筑始终占据一个格子，不可被击退、牵引等任何强制位移效果移动（不作为位移目标）

### 格子叠加

- **一个格子可以存在多个单位**，不限制数量
- 不存在"抢格子"的冲突——双方移动到同一格只是叠加（除非有阻挡判定）
- **牵引无视碰撞**：牵引不检查碰撞阻挡，可以把单位拉入已有单位所在的格子（例如把两个敌人吸到同一格）

### 攻击范围按格子结算

- **所有攻击的范围都以格子为单位计算，而非单位**：只要目标所在的格子被攻击覆盖，目标即被命中
- 同一格内叠加的多个单位会被同一次攻击**全部命中**（例：两个敌人被牵引叠加到同一格，安柏朝该方向战技射箭，该格内两名敌人同时受到伤害）
- 技能描述中的"敌人/我方"等措辞仍按阵营过滤目标——**格子决定范围，阵营决定谁被命中**

### 碰撞与阻挡

移动过程中途经的格子可能有其他单位，是否被阻挡取决于碰撞规则（UnitMoveable）：

| 配置项 | 说明 |
|--------|------|
| `blockAllies` | 该单位是否阻挡友方移动 |
| `blockEnemies` | 该单位是否阻挡敌方移动 |
| `blockedByEnemies` | 该单位是否被敌方阻挡 |

- 攻速排序后，排在前面的行动先执行，单位位置更新
- 排在后面的移动行动执行时，如果途经格子上存在具有阻挡属性的单位，则被阻挡（停在阻挡格前）
- 飞行（Fly）和瞬移（Teleport）不受步行地形限制
- 地形通行性由 TileType 标签决定（AllowWalk / AllowFly / WaterTerrain）

### 与死亡判定的关系

- 单位死亡后变为**尸体**（见5.4），尸体仍留在场上、保留碰撞属性
- 排在前面的行动击杀某单位后，该单位变为尸体**仍在原地**，碰撞规则不变
- 排在后面的移动途经尸体位置时，**仍可能被尸体阻挡**（取决于尸体保留的碰撞属性）
- 排在后面的攻击行动可以**鞭尸**（攻击尸体），命中后正常触发"战技命中敌人"效果（如获得元能）

## 5.4 死亡与尸体系统

### 核心规则

单位（角色/建筑）血量降为0时**不消失**，变为**尸体**留在场上。

| 属性 | 活体 | 尸体 |
|------|------|------|
| 血量 | 正常 | **永远0**（不复苏） |
| 属性/攻速/防御等 | 正常 | **完全保留** |
| 碰撞规则 | 正常 | **完全保留**（可堵路） |
| 势力归属 | 正常 | **保留**（势力机制触发条件仍满足） |
| 元能 | 正常 | **保留**（纳塔角色元能仍流逝） |
| 可被攻击 | 是 | **是**（鞭尸） |
| 可被选中为目标 | 是 | **是** |
| 可行动 | 是 | **否** |
| 可发动战技/爆发 | 是 | **否** |
| 可被出战/升命 | — | **否** |
| 再次使用角色卡 | — | **仅提升命座，不复苏，血量仍为0** |

### 设计意图

- **堵路**：尸体保留碰撞属性，可以用尸体卡住通道，形成战术地形
- **鞭尸获元能**：攻击尸体命中后触发"战技命中敌人"效果，蒙德角色可通过鞭尸获取元能
- **势力机制延续**：尸体保留势力归属，场上存在该势力尸体仍可触发势力机制（如蒙德延奏的目标可以是尸体）
- **纳塔夜魂延续**：纳塔角色变为尸体后元能仍会流逝，直到元能归零才真正倒下
- **复苏**：尸体上的命座提升只是命座成长，不会让角色复苏。尸体要"消失"只能靠被【消散】（玩家战败，从游戏中真正删除）或【放逐】（转移到另一个维度，单位仍然存在）

### 与掠夺的关系

- 摧毁敌方协议核心后掠夺的是**手牌**，不是场上的单位
- 尸体是已经部署出去的倒下的单位，掠夺不改变尸体状态

## 5.5 控制与韧性系统

### 控制类型

| 类别 | 控制效果 | 说明 |
|------|----------|------|
| **硬控** | 晕眩 | 完全不能行动 |
| **硬控** | 沉默 | 只能移动，不能使用战技/爆发 |
| **软控** | 减移速 | 降低移动力度 |
| **软控** | 减攻速 | 降低攻速排序优先级 |
| **软控** | 减攻击 | 降低攻击力 |
| **其它控** | 心控 | 控制目标单位行动 |
| **其它控** | 压制 | 限制目标单位行动 |

### 韧性机制

韧性（Tenacity）决定单位受控时的实际持续时间。

- **韧性 > 0 时**：
  - 受到**硬控**：受控时间**减少1回合**，韧性**-10**
  - 受到**软控**：受控时间**减少1回合**，韧性**-5**
- **韧性 < 0 时**：
  - 受到**硬控**：受控时间**增加1回合**，韧性**+10**（向0回归）
  - 受到**软控**：受控时间**增加1回合**，韧性**+5**（向0回归）

### 设计意图

- 韧性相当于"控制抗性"——高韧性单位能抵抗控制，低韧性单位反而更容易被控
- 韧性正负波动：每次受控都会向反方向推动韧性，防止韧性无限累积
- "其它控"（心控/压制）不受韧性影响，由技能本身定义持续时间和解除条件

## 5.6 伤害公式

### 核心公式

最终伤害 = (攻击力 × 攻击百分比 + 额外伤害) × (增伤 - 免伤) × 易伤

### 易伤乘区

- 防御 ≥ 0：易伤 = 100 / (100 + 防御)
- 防御 < 0：易伤 = 1 - 防御 / 100

- 防御为 0 → 易伤 = 1（无变化）
- 防御为正数 → 易伤 < 1（减伤），递减且永不归零
- 防御为负数 → 易伤 > 1（增伤），每 1 点防御 = 1% 增伤，线性

| 防御 | 易伤 | 效果 |
|:----:|:----:|------|
| 100 | 0.50 | 减伤50% |
| 50 | 0.67 | 减伤33% |
| 0 | 1.00 | 无变化 |
| -5 | 1.05 | 增伤5%（凯亚C2） |
| -50 | 1.50 | 增伤50% |
| -100 | 2.00 | 增伤100% |

> **设计意图**：正防御用除法减伤递减（永不归零），负防御用线性增伤（每点1%，可控不爆炸）。当前全角色基础防御为 0，易伤乘区 = 1（无变化）；通过技能/物品降低敌方防御可使其进入易伤状态。元素反应对增伤/易伤/防御的影响见 §六 元素与反应系统。
