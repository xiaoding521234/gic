## 1. 项目概况

- **游戏**："协议核心"——同时回合制卡牌战术战棋（原神 IP，最多 6 人，LAN 联机 via Mirror）
- **引擎**：Tuanjie 1.9.3（Unity 2022.3 分支），URP
- **技术栈**：C# 单一程序集（**无 asmdef**，决策背景见 docs/20 §1.2；用命名空间隔离）、Mirror 联机、Unity Localization（6 语言）、Addressables 大资源、Unity UI（UGUI + TMP）
- **目标**：个人 Demo/作品集，非商业上线（scope 原则：2v1 优先 6 人、2-3 势力优先 7、垂直切片优先广度）

## 2. 目录结构（Assets/_Scripts）

**命名空间约定**：namespace 固定为模块根（GIC.Framework / GIC.Data / GIC.UI / GIC.Battle / GIC.Tool / GIC.Editor），目录仅做模块内物理分组，不映射到 namespace——新文件按此写，不要按目录逐级嵌套 namespace。

| 目录 | 命名空间 | 职责 |
|------|----------|------|
| Framework | GIC.Framework | 核心层：Wargame 组合根、GameScene、DI、EventBus、AssetCache、Audio、Save、Input(InputManager/InputLocks/KeyAction/KeyBindingEntry + Gestures 手势层)、Command（CommandSystem 统一指令系统+GameCommandsCore：help/give/card/time）、Network(Player/RoomManager)、Pool、Collection（卡组/收藏域：CardManager/CardDeck/DeckCodeCodec/UnitManager，2026-09-19 B3 归位自 Framework/Battle 迁入） |
| Data | GIC.Data | 纯数据：Config 类（Battle/ 下 Unit/Item/Position/Skill/Board（BattleMapConfig/TileType）/BattlePalette（战斗配色资产 Configs/BattlePalette.asset）/Buff（BuffType）、Card/、Wish/）、战斗协议（Battle/Protocol/：ActionData/BattleCommand/Segment/BattleSnapshot/BattleMapData/传输消息）、事件类（Event/）、玩家数据（Player/）、枚举 |
| UI | GIC.UI | 界面层：Screen/（各弹层场景脚本）、Popup/、Skill/、Common/ |
| Battle | GIC.Battle | 战棋域（B1 已落地）：Unit/、Card/、Skill/、Tile/、Buff/、Flow/（TurnResolver/执行器/DamagePipeline/ElementReactionResolver/BattleSimState/BattleSession/TurnFlowController/AIDebugBrain/BattleLaunchConfig/ProjectileResolver（B5 连续命中判定）/BattleMetrics（判定常量收口））、View/（BattlePlayer/UnitView/BattleBoard/BattleHud 三 partial=主+TopBar+Build/BattleViewFactory/BattleViewTween；操作规范=gic-battle-hud skill） |
