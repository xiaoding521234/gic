> 2026-08-16 创建。一页式代码地图：新会话（人或 AI）先读本文建立全貌，再按需深入各专项文档/skill。
> 玩法设计见 docs/00-12；输入系统详见 docs/15；技术陷阱详见 docs/14（含 Tuanjie UITK 陷阱）；优化史见 docs/16。

## 1. 项目概况

- **游戏**："协议核心"——同时回合制卡牌战术战棋（原神 IP，最多 6 人，LAN 联机 via Mirror）
- **引擎**：Tuanjie 1.9.3（Unity 2022.3 分支），URP
- **技术栈**：C# 单一程序集（**无 asmdef**，2026-08-01 决策，用命名空间隔离）、Mirror 联机、Unity Localization（6 语言）、Addressables 大资源、Unity UI（UGUI + TMP）
- **目标**：个人 Demo/作品集，非商业上线（scope 原则：2v1 优先 6 人、2-3 势力优先 7、垂直切片优先广度）

## 2. 目录结构（Assets/_Scripts，命名空间即目录）

| 目录 | 命名空间 | 职责 |
|------|----------|------|
| Framework | GIC.Framework | 核心层：Wargame 组合根、GameScene、DI、EventBus、AssetCache、Audio、Save、Input、Network(Player/RoomManager)、Pool |
| Data | GIC.Data | 纯数据：Config 类（Unit/Item/Position/Map/WishPool/ElementFactionIcon）、事件类（Event/）、枚举 |
| UI | GIC.UI | 界面层：Screen/（各弹层场景脚本）、Popup/、Skill/、Common/ |
| Battle | GIC.Battle | 战棋域（组件骨架已有，核心执行未实现）：Unit/、Card/、Skill/、Tile/、Buff/ |
| Tool | GIC.Tool | 通用组件与工具：Component/（TextCombiner/LightPillarEffect/ArcLayout…）、扩展方法 |
| Editor | GIC.Editor | 编辑器工具（全部 UITK，见 gic-editor-tool skill） |

依赖方向（约定）：UI→Framework/Data，Battle→Framework/Data，Editor→全部；禁止反向。

## 3. 核心系统速查

| 系统 | 入口/文件 | 关键约定 | 深入 |
|------|-----------|----------|------|
| DI 容器 | Wargame.Instance.Context | [Component]/[Autowired]/[PostConstruct]；Manager 直达禁止 | gic-di-injection skill |

## 4. 场景清单（Assets/Scenes）

| 场景 | 类型 | 说明 |
|------|------|------|
| Boot | 根 | 组合根：GameScene 挂载，Wargame 初始化 |

## 5. 配置资产

- `Resources/Configs/`：UnitConfig / ItemConfig / PositionConfig / MapConfig / ElementFactionIconConfig / WishPool_*.asset —— 均有自定义 Inspector（列表型走 ConfigInspectorBase，批量工具在 Inspector 底部）
- 角色数据源头：`docs/units/{name}.md`（AI 读取后同步 enum+asset+本地化，见 gic-new-unit skill）
- Addressables（Assets/Art/）：`PositionBack/{Region}/{pos}_{time}` 大厅背景、`WishArt/{unit}` 祈愿 4K 立绘
- Sprite Atlas ×6（Assets/SpriteAtlases/）：小 UI 图入 Atlas，大图不入

## 6. 常用工作流速查

| 任务 | 路径 |
|------|------|
| 新增/修改角色 | 编辑 docs/units/{name}.md → gic-new-unit skill 同步 |
| 新增界面/场景 | gic-new-screen skill（SceneType 注册 + BuildSettings + ScreenBase 骨架） |
| 新增事件 | gic-eventbus skill checklist |
| 新增音效/BGM | AudioManager.PlaySFX/PlayMusic（界面配乐用 ScreenBase Safe） |
| 新增大贴图 | gic-assetcache skill（Addressable 地址约定） |
| 批量本地化 | Tools/Localization/CSV 导出导入（gic-localization skill） |
| 导出测试 APK | Tools/导出 APK/快速导出（自动切 Android 平台） |
| 联机自测 | ParrelSync Clone 双开（Tools/编辑器启动/同步 Clone Play） |
| 提交 | git-commit-helper skill（PowerShell -m 破坏中文，用 -F 文件） |
