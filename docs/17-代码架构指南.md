## 1. 项目概况

- **游戏**："协议核心"——同时回合制卡牌战术战棋（原神 IP，最多 6 人，LAN 联机 via Mirror）
- **引擎**：Tuanjie 1.9.3（Unity 2022.3 分支），URP
- **技术栈**：C# 单一程序集（**无 asmdef**，2026-08-01 决策，用命名空间隔离）、Mirror 联机、Unity Localization（6 语言）、Addressables 大资源、Unity UI（UGUI + TMP）
- **目标**：个人 Demo/作品集，非商业上线（scope 原则：2v1 优先 6 人、2-3 势力优先 7、垂直切片优先广度）

## 2. 目录结构（Assets/_Scripts）

**命名空间约定**：namespace 固定为模块根（GIC.Framework / GIC.Data / GIC.UI / GIC.Battle / GIC.Tool / GIC.Editor），目录仅做模块内物理分组，不映射到 namespace——新文件按此写，不要按目录逐级嵌套 namespace。

| 目录 | 命名空间 | 职责 |
|------|----------|------|
| Framework | GIC.Framework | 核心层：Wargame 组合根、GameScene、DI、EventBus、AssetCache、Audio、Save、Input(InputManager/InputLocks/KeyAction/KeyBindingEntry)、Network(Player/RoomManager)、Pool |
| Data | GIC.Data | 纯数据：Config 类（Battle/ 下 Unit/Item/Position/Skill、Card/、Wish/）、事件类（Event/）、玩家数据（Player/）、枚举 |
| UI | GIC.UI | 界面层：Screen/（各弹层场景脚本）、Popup/、Skill/、Common/ |
| Battle | GIC.Battle | 战棋域（组件骨架已有，核心执行未实现）：Unit/、Card/、Skill/、Tile/、Buff/ |
| Tool | GIC.Tool | 通用组件与工具：Component/（TextCombiner/LightPillarEffect/ArcLayout…）、扩展方法 |
| Pet | GIC.Pet | 桌宠形态（同 exe `--pet-mode` 双形态）：PetMode 开关、PetWindowController 透明置顶窗口（docs/19 §5.8） |
| Editor | GIC.Editor | 编辑器工具（全部 UITK，见 gic-editor-tool skill）；DevTest/ 开发用测试脚本（不入包） |

依赖方向（约定）：UI→Framework/Data，Battle→Framework/Data，Editor→全部；禁止反向。

## 4. 场景清单（Assets/Scenes）

| 场景 | 类型 | 说明 |
|------|------|------|
| Boot | 根 | 组合根：GameScene 挂载，Wargame 初始化 |
| SplashScreen | 根 | 启动动画 → MainHall |
| MainHall | 根 | 大厅（SpriteRenderer 背景 + UGUI 按钮） |

| PaimonPet | 桌宠专用 | 不走 SceneType 跳转：`--pet-mode` 启动时 GameScene 守卫直接 LoadScene 本场景；派蒙模型+色键相机+PetWindowController（docs/19 §5.8）。PaimonPreview 为其调姿用母版（不打包） |
| PaimonRetargetTest | 桌宠专用 | 模型/动作/渲染测试场景：原生 MMD 模型 + 14 动作滚动按钮列 + 无灯（地面 URP/Unlit，PaimonToon 材质不读灯，docs/19 §5.9） |

## 5. 配置资产

- `Resources/Configs/`：UnitConfig / ItemConfig / PositionConfig / MapConfig / ElementFactionIconConfig / WishPool_*.asset —— 均有自定义 Inspector（列表型走 ConfigInspectorBase，批量工具在 Inspector 底部）
- 角色数据源头：`docs/units/{name}.md`（AI 读取后同步 enum+asset+本地化，见 gic-new-unit skill）
- Addressables（Assets/Art/）：`PositionBack/{Region}/{pos}_{time}` 大厅背景、`WishArt/{unit}` 祈愿 4K 立绘
- Sprite Atlas ×6（Assets/SpriteAtlases/）：小 UI 图入 Atlas，大图不入
