# GIC — 协议核心 · 文档总览

> 本文档是 docs 的**入口与导航**。项目背景与立项论证见 [00-概念提案.md](00-概念提案.md)；代码侧入口是 [17-代码架构指南.md](17-代码架构指南.md)，通用规范权威是 [20-项目规范.md](20-项目规范.md)。

## 项目一句话

- **类型**：联机同时回合制卡牌战棋（原神 IP，最多 6 人，LAN 联机 via Mirror）
- **核心体验**：组卡构筑 → 同时博弈 → 攻速执行 → 掠夺结算 → 祈愿成长
- **定位**：个人独立开发的概念验证 Demo，非商业上线；目标全平台互通（PC / 移动 / 主机）

## 核心数值速查

| 数值 | 值 | 权威出处 |
|------|-----|---------|
| 初始摩拉 / 体力 | 200 / 60 | 01 §1.1 |
| 每回合发放 | 摩拉 +5、体力 +5（统一时机） | 04 §4.3 |
| 行动体力消耗 | 移动 / 战技 / 爆发各 10 | 05 §5.1 |
| 攻速延迟 | 每 10 点攻速差 = 延后 1 秒开始执行 | 04 §4.1 |
| 选择时限 | 第1回合 25s → 2-6回合 16s → 每回合 -0.5s，下限 8s | 04 §4.2 |
| 战场规格 | 初始 20×20，上限 50×50 | 03 §3.3 |
| 命座 | 0-3 命（0命=部署即有固有被动） | 09 |
| 祈愿单抽 | 160 原石 | 12 §3 |
