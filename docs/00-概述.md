## 项目一句话

- **类型**：即时制卡牌战棋（原神 IP，最多 6 人；实时联机=后置批次——决策九十五拍板 2：tick 命令流+desync hash 天然可移植）
- **核心体验**：组卡构筑 → 即时对抗（任意角技能/真圆范围/摇杆走位）→ 掠夺结算 → 祈愿成长
- **定位**：个人独立开发的概念验证 Demo，非商业上线；目标全平台互通（PC / 移动 / 主机）

## 文档地图

> **三区原则**（2026-09-14 拍板）：docs 分三区——**现状文档**（根目录，本表第一/二/三层）只记"现在是什么+为什么"；**active/**=进行中的实施设计（B 批次施工蓝图，收官后现状化迁回根区）；**archive/**=已收官的过程记录（仅追溯用，细节查 git 历史）。收录规则见 docs/20 §3。
