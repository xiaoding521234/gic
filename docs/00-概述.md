# GIC — 协议核心 · 文档总览

> 本文档是 docs 的**入口与导航**。项目背景与立项论证见 [概念提案-立项书.md](概念提案-立项书.md)；代码侧入口是 [17-代码架构指南.md](17-代码架构指南.md)，通用规范权威是 [20-项目规范.md](20-项目规范.md)。

## 项目一句话

- **类型**：联机同时回合制卡牌战棋（原神 IP，最多 6 人，LAN 联机 via Mirror）
- **核心体验**：组卡构筑 → 同时博弈 → 攻速执行 → 掠夺结算 → 祈愿成长
- **定位**：个人独立开发的概念验证 Demo，非商业上线；目标全平台互通（PC / 移动 / 主机）

## 文档地图

> **三区原则**（2026-09-14 拍板）：docs 分三区——**现状文档**（根目录，本表第一/二/三层）只记"现在是什么+为什么"；**active/**=进行中的实施设计（B 批次施工蓝图，收官后现状化迁回根区）；**archive/**=已收官的过程记录（仅追溯用，细节查 git 历史）。收录规则见 docs/20 §3。
