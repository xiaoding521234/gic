## 结论：带原神 IP 形态的商业化可行性为零

侵权面盘点：角色名 / 术语 / 七元素十八反应命名 / GI 解包字体（zh-cn SDF）+ RigMesh + MMD 模型 + OST——全链侵权，不存在"安全商业化"路径。

去 IP 后机制本体（同时回合 + 攻速错峰 + 契约谈判 + 命座）为**原创设计，可独立成立**。fork 换皮留作核心循环验证完成后的选项，**现在不做**。

## 发布三条纪律

1. **全渠道不收费**（打赏与项目解绑）
2. 启动页加"非官方同人，与 miHoYo 无关"免责声明
