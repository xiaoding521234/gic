# UI 架构重构技术设计

> 2026-09-12 起草。UI 层大重构（P1-P4）的技术实施蓝图，**P1 按本文直接开工**。
> 拍板结论（2026-09-12 本轮）：载体=**混合制**（纯 UI 弹层 prefab 化 + Map 3D 弹层保留场景制、统一入栈）；术语保留 Screen；自研 UI Kit 对齐业界框架组件划分（TEngine UIModule / QFramework UIKit / GameFramework UIForm），**不引入第三方全家桶**（它们各自的 UI 模块长在自家资源/事件底座上，引入=换地基）。
> 现状盘点与债务实证见本文 §1；重构前对话记录：2026-09-12 会话（"UI 架构是否混乱 + 成熟框架调研"）。

## 1. 现状与债务（2026-09-12 代码实证）

**现状架构**：Screen=Additive 场景（5 个弹层）+ 根场景（Splash/MainHall/Battle）；GameScene 持场景历史栈与 GoBack；ScreenBase 收敛注入/IClosable/输入锁/音乐/标准关闭；PopupManager 管 modal+toast；纯命令式刷新。

**三处结构性债务 + 一笔性能账**：

| # | 债务 | 实证 |
|---|---|---|
| 1 | Screen 全是 god-class：View 装配/状态/刷新/动画/业务逻辑混在一类，partial 按文件切不按职责切 | WishDrawController 1592 行/7 partial、SettingsScreen 811/8、BackpackScreen 755/6、MainHallScreen 581/3、CoopScreen 538/4 |
| 2 | 纯命令式刷新，无数据流约定：状态变更靠手动调对 RefreshXxx（BackpackScreen.Deck 单文件 10 处），漏调即静默不同步 | EventBus→Handler→刺进 Screen 的回调遍地 |
| 3 | 弹窗双轨：PopupManager 一套，DeckSwitchPanel/BattleExitConfirmDialog/各屏内嵌面板手搓一套；无统一层级/优先级/栈模型，z-order 靠场景加载顺序+Canvas sorting 分散维持 | rg 实证 |
| 4 | 性能账：每次 GoBack 全走 `UnloadUnusedAssets + GC.Collect`；每次开关界面=完整 scene load/unload | GameScene.GoBackCoroutine |

**保留项（本就是底座优势，不动）**：Wargame DI、EventBus（owner 登记）、InputLocks、AssetCache/Addressables、Unity Localization + TextCombiner、SaveManager、Mirror、AudioManager。

## 2. 目标架构总览

**业界框架 ↔ GIC 组件映射**：

| TEngine/UIKit/GameFramework 概念 | GIC 落地物 | 位置 |
|---|---|---|
| UIModule（UI 栈管理器） | **UIManager** | `GIC.UI`，Boot 常驻（挂 GameScene 子物体） |
| UIWindow/UIPanel/UIForm | **ScreenBase**（保留名，扩充生命周期） | `GIC.UI` |
| 分层 Layer（Hidden/Bg/Normal/Popup/Top…） | **UILayer**（Fullscreen/Popup/Toast/Top） | `GIC.UI` |
| Window 打开参数 payload | `UIManager.Open(ScreenId.X, args)` | — |
| 弹窗/Toast 栈 | UIManager 内置弹窗层（现 PopupManager 并入，留门面） | — |
| 资源加载 | 面板 prefab→Resources（与 Unit/Card.prefab 同路线）；3D 弹层→场景 | — |
| 事件/注入/输入锁 | EventBus / DI / InputLocks 原样 | — |

**分层结构**：

```
Boot（常驻）GameScene [DontDestroyOnLoad]
├─ UICamera（cullingMask=UI，depth 高于一切场景相机）
└─ UIRoot（编辑器手搭，禁止代码搭 UI——docs/20 铁律）
   ├─ Canvas_Fullscreen  (sortingOrder 100, ScreenSpace-Camera→UICamera)
   ├─ Canvas_Popup       (sortingOrder 200)
   ├─ Canvas_Toast       (sortingOrder 300)
   └─ Canvas_Top         (sortingOrder 400，预留给转场遮罩/强制弹窗)

根场景体制不变：Splash / MainHall / Battle 仍是 Single 根场景（背景/战斗内容=场景级）
弹层两制同栈：纯 UI 弹层→PrefabHost（实例化 prefab 入层级根）；Map→SceneHost（Additive 场景，栈语义统一）
```

## 3. 核心抽象

### 3.1 ScreenId 注册表（对齐 SceneType 模式）

```csharp
public sealed class ScreenId
{
    public string Name { get; }
    public UILayer Layer { get; }          // Fullscreen / Popup / Toast / Top
    public ScreenHostKind Host { get; }    // Prefab | Scene | RootScene
    public string PrefabPath { get; }      // Prefab: "Prefabs/UIPanels/Xxx"（Resources 下）
    public SceneType SceneType { get; }    // Scene/RootScene: 关联场景
}

public static class Screens   // 注册表（P1 全场景制，P3 逐屏翻成 PrefabHost）
{
    public static readonly ScreenId MainHall    = ScreenId.Root("MainHall", SceneType.MainHall);
    public static readonly ScreenId Battle      = ScreenId.Root("Battle",   SceneType.BattleScreen);
    public static readonly ScreenId Splash      = ScreenId.Root("Splash",   SceneType.SplashScreen);
    public static readonly ScreenId Map         = ScreenId.Overlay("Map",       SceneType.MapScreen);
    public static readonly ScreenId Wish        = ScreenId.Overlay("Wish",      SceneType.WishScreen);      // P3→Prefab
    public static readonly ScreenId Backpack    = ScreenId.Overlay("Backpack",  SceneType.BackpackScreen);  // P3→Prefab
    public static readonly ScreenId Settings    = ScreenId.Overlay("Settings",  SceneType.SettingsScreen);  // P2→Prefab
    public static readonly ScreenId Coop        = ScreenId.Overlay("Coop",      SceneType.CoopScreen);      // P3→Prefab
}
```

调用面统一为 `UIManager.Open(Screens.Xxx, args)`；**P3 翻 Host 时调用点零改动**（迁移=改注册表一行+建 prefab+删场景）。

### 3.2 UILayer 分层与遮挡策略

| 层 | 语义 | 遮挡策略 |
|---|---|---|
| Fullscreen | 一级全屏界面（含 Map 场景制） | 新开时**下方 Fullscreen 收 OnPause**（仅钩子，不自动变暗/停用——重内容屏可在 OnPause 自行降载）；关闭后下方收 OnResume |
| Popup | 模态弹窗（确认框/输入框/管理面板） | 自带全屏阻断底图（prefab 内做），不触发下方 OnPause；栈式堆叠，ESC 先关最顶 |
| Toast | 轻提示（不阻断、自动消散、可堆叠） | 无阻断 |
| Top | 转场遮罩/强制提示（预留） | — |

### 3.3 生命周期（UIManager 调度，ScreenBase 虚方法）

| 阶段 | 虚方法 | 时机 | 配对/约定 |
|---|---|---|---|
| 初始化 | `OnInit()` | Prefab 实例化后一次性；场景制=Awake 后由 ScreenBase 自行调用等价逻辑 | 幂等守卫 |
| 打开 | `OnShow(object args)` | 每次入栈后 | 音乐 push（Safe 系列保留在此）；入场动画自管（Entering 锁不变） |
| 遮挡 | `OnPause()` | 被更高 Fullscreen 盖住 | 不动音乐；仅钩子 |
| 恢复 | `OnResume()` | 上方 Fullscreen 关闭 | 与 OnPause 配对 |
| 关闭 | `OnClose()` | UIManager 发起（ESC/关闭按钮/GoBack） | 防重入 isClosing + Closing 锁 + 退场动画 + 音乐 pop（ScreenBase 模板保留，仅收尾从 GameScene.GoBack 换成 UIManager） |

场景制 Screen（SceneHost）：OnPause/OnResume 同语义（场景保持加载，仅收钩子）；Show/Close 对应场景加载/卸载。

### 3.4 UIManager 职责与 API

| API | 语义 |
|---|---|
| `Open(ScreenId, args)` | 层级判定→Host 分发（Prefab 实例化/场景加载/根场景切换清栈）；UITransition 锁防抖；同屏重复 Open=幂等 no-op+Warn |
| `GoBack()` | **关闭栈顶 Fullscreen**（Popup/Toast 不入返回历史——弹窗不留面包屑） |
| `Close(unit)` / `CloseTop()` | 关指定/栈顶单元（供 ESC 收口与外部调用） |
| `ShowModal(message\|LocalizedString)` / `ShowToast(...)` | 弹窗层/Toast 层（吸收 PopupManager） |
| `Clear()` | 根场景切换（进 Battle/Splash）时清栈 |

ESC 链路（P1 保持现状职责划分，P3 收口）：InputManager.CloseTopUI 不变 → 各 Screen 仍自注册 IClosable（栈序即遮挡序，Boot 注册的 UIManager 恒在栈底）；P3 屏幕面板化后改为 **UIManager 单注册**，InputManager 只关 UIManager，内部按"Toast 顶→Popup 顶→Fullscreen 顶"分发。

### 3.5 三种 Host

| Host | Show | Close | 适配对象 |
|---|---|---|---|
| PrefabHost | Resources.Load 实例化→层级根下（Fullscreen 层） | 退场动画→Destroy | Wish/Backpack/Settings/Coop（P2-P3 后） |
| SceneHost | GameScene 场景原语（Load/Preload/Activate，SceneTransition 锁） | 退场动画→卸载场景+恢复激活上级 | MapScreen（3D 内容弹层） |
| RootHost | 清栈+Single 加载根场景 | 无（根场景间无 GoBack 语义，如 Battle→MainHall 直 Open） | Splash/MainHall/Battle |

GameScene 瘦身为**纯场景原语**（Load/Preload/Activate/Unload/SetActive/过渡锁），历史栈、GoBack、OnGoBackEvent 发送全部移交 UIManager（事件类本体在 Data/Event 不动，MainHall 的 GoBackHandler 监听不变）。

**性能决策**：场景制关闭保留 `UnloadUnusedAssets`（Map 瓦片内存重），**去掉每 GoBack 的 `GC.Collect`**（主线程卡顿尖峰，托管内存交运行时 GC）；面板制关闭=Destroy，零额外清理。

### 3.6 迁移兼容策略（P1 精确边界，2026-09-12 实施时勘定）

**模型勘定：root 场景 = context，不是栈单元**。栈只收**弹层**（Fullscreen overlay）；根场景切换（Splash→MainHall、Coop→Battle、Battle→MainHall）**保留 `SceneType.Load()` 直载**（6 个调用点零改动），栈内残留弹层随 Single 加载触发 `ScreenBase.OnDisable/OnDestroy` 自清。MainHall/Battle/Splash 在注册表中标记 RootScene，`ScreenBase.OnEnable` 注册时自动跳过。

**注册制**：场景制 Screen 由 ScreenBase 的 `OnEnable/OnDisable` 钩子自动入栈/出栈（无需各屏手写）；场景名未注册时**匿名入栈 + Warn**（保零回归，P4 清查）。P3 面板化后注册点不变（prefab 实例化同样触发 OnEnable）。

**返回语义两分（防递归，实测 CoopScreen.Close→OnLeaveRoomClick→GoBack 链）**：
- `UIManager.GoBack()` —— 返回**意图**（未来 pet 聊天/UX 返回键入口）：调栈顶的 `Close()`，各屏可按领域语义响应（Coop 房主状态 = 离房回发现页，不弹层）
- `UIManager.PopToPrevious(unit)` —— **弹出原语**（原 GameScene.GoBack 职责）：移栈项+卸载场景+恢复上级激活+资源清理+发 OnGoBackEvent。CloseScreen 模板收尾、Coop 房客离房、PetGameBridge 兜底三处直连本原语，不再经 Close 二跳

- `PopupManager` **P1 完全不动**（10 处 ShowToast 调用面零风险）；P4 折叠进 UIManager 弹窗层后删门面。
- `GameScene.Instance.GoBack()` 3 个调用点（ScreenBase 模板 / CoopScreen.RoomFlow / PetGameBridge）改连 `UIManager.PopToPrevious`。
- ScreenBase 的 `RegisterClosableSelf/PushMusicSafe` 等对子类 API 不变（迁移期零回归）。
- UIRoot 层级 Canvas（编辑器手搭）挪到 **P2** 随首个 prefab 面板一起落地（P1 无面板，无宿主）。

## 4. 导航语义汇总

| 操作 | 语义 |
|---|---|
| Open | 见 §3.4；Fullscreen 新开→下方 OnPause；根场景 Open→Clear+Single Load |
| GoBack | 关栈顶 Fullscreen；栈空=no-op（现状语义保持） |
| ESC/右键 | 关最顶可关闭单元：Popup 顶 > Fullscreen 顶；Toast 永不接 ESC |
| 历史 | 层栈即历史（不另设 back 栈）；Popup/Toast 不入历史 |
| 动画 | 入/退场动画仍由各 Screen 自管（UIManager 只发生命周期+收尾）；MainHall 的"退场→预载→激活"三段式改由 Open 编排并行化 |

## 5. God-class 拆分映射（P2/P3 迁移时一并执行）

**纪律（同步进 docs/20）**：Screen 类只留 Inspector 装配+生命周期+子 Controller 创建销毁；子 Controller 持 View 引用做刷新、EventBus 订阅 owner 登记进 Controller；**状态变更只经 Controller 公共方法→内部调 View.RefreshX，EventBus 事件→Controller 订阅→走同一条刷新路径**；不引入数据绑定框架（命令式但收口）。

| 现状 | 拆分后 |
|---|---|---|
| BackpackScreen 755/6 | View + CategoryTabsController + CardGridController + DeckEditController（DeckSwitchPanel 已是雏形） |
| SettingsScreen 811/8 | View + 6 个 TabController（partial 边界恰好即此） |
| WishDrawController 1592/7 | View + Display/Effects/Encounter/Starglitter/Track/Video 六职责类 |
| CoopScreen 538/4 | View + RoomFlowController + PlayerListController + DiscoveryController |
| MainHallScreen 581/3 | View + BackgroundController + 入场动画 Controller |
