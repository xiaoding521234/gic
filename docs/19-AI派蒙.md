## 1. 定位

AI派蒙 = **常驻桌宠 + 对话式游戏助手**：

- **表现层**：派蒙 3D 模型桌面常驻置顶悬浮，游戏失焦/最小化时仍在
- **生命周期**：**拉起不绑命**——启动游戏自动唤出（Mutex 单例防重）；游戏退出/崩溃后派蒙独立存活；关闭方式=双击她
- **交互层**：拖拽（物理手感未做，现为窗口直移）、待机动作轮换、视线跟随、屏幕边缘探头（未做，§6.3）
- **功能层**：LLM 对话指令入口——**已拍板接 LLM，一期不做**（§7）

非目标：战斗/联机中表现策略不考虑；不做逐小窗口交互（只认屏幕边缘）；移动端不做独立进程（仅游戏内悬浮挂件）。

## 3. 窗口与渲染（现状）

### 3.1 窗口体制【实证+目检，2026-08-26 夜三次重构终案】

**固定画布**（VPet/eSheep 源码逐行核验后重写，用户目检通过）：

- **窗口**：750×825 逻辑（宽 2026-08-26 550→750：高度被工作区 95% 钳制顶格，横向是唯一可扩轴，两侧余量各+230px）×DPI×缩放上限固定尺寸；DWM 逐像素 alpha 透明（前提关 `useFlipModelSwapchain`）
- **核心原则【源码实证】**：一切动画期间**相机/模型根/窗口完全静止**——动画只在固定画布内演，窗口位置绝无"播动画的副作用"。VPet：全部动画渲染进固定 500px 画布（PNGAnimation img.Width=500），仅走路图（GraphType.Move）按显式速度向量移窗，其余动画一律 MoveTimer.Stop()，出界只打日志"当前动画移动设计错误"；eSheep：唯一权威状态 PositionX/Y 只由动画 XML 显式编写的步进累加（待机步进=0）。主流桌宠的位置精确是结构性的——位置只经显式移动（走路/拖拽/飞行）变更
- **窗口唯一移动源**：①启动停靠/pet.json 恢复 ②拖拽物理绝对定位（骨盆客户区投影钉物理目标，docs §6.1）③松手防丢拉回+防隐形守卫（完全出虚拟屏才干预）
- **缩放**：滚轮只改模型 localScale（固定窗口防 resize 闪烁）；pet.json 独立存档（缩放+窗口原点，防抖落盘）
- **帧节奏=DWM 帧对齐（2026-08-27 v4 终案）**：分层窗口 blt present 不阻塞→vSyncCount 实际无效（canvas 矩阵 min=6.05ms 实证 ~130fps 自由跑=匀速动画全程 judder）；`DwmFlush` 每帧阻塞到下一次桌面合成=唯一有效节拍器，165Hz 实测 99% 帧严格 6.06ms/163fps。开时强制 vsync=0+不限帧。演化史：vsync0+限帧30→vsync2→vsync1→自适应分频→**DwmFlush**（前四代均建立在"vsync 有效"的错误假设上）
- 画布性能矩阵【2026-08-26 实测，--pet-canvas-px 测试钩子留库】：2.40MP avg7.53ms/CPU80% → 3.38MP 7.61/84% → 4.81MP 7.85/81% → 全屏 6.40MP 7.8/98%。稳态帧时间几乎不随画布像素涨（+2.7×仅+4%）；真实成本=CPU 单核，全屏逼近满载。当前 3.28MP 落在免费区间

> 演化史 ❌已废弃：①"相机+窗口双跟随"增量体制（2026-08-25 首版）——三处结构性 bug：相机累积位移=角度变化、多状态链累积=漂移、双环反馈=拖拽恒半速。②**根绝对补偿+窗口跟随编排位移**（2026-08-26 二版，曾标记"定案"）——归零依赖"混合回待机恰好回到锚点捕获相位"，但待机是带骨盆微动的循环相位永不对齐；拖拽打断动作时基准根=中途补偿值；落地反应混合中途重锚——每次偏差成永久残差烤进下一锚点=随机游走漂出窗（用户报"动作越多越漂，最终不可见"+待机时窗口跟微摆），同日废弃。③全屏覆盖体制——"帧率 165→75 腰斩"结论经重测**不成立**（vsync=1 时代产物，vsync=2 预算下全屏稳态 avg 仅 7.8ms）；真实废弃理由=单核 CPU 98% 逼近满载+全屏遮蔽交互。
>
> 业界机制参考【源码核验 2026-08-26】：VPet=固定 500×500 画布+走路才移窗+出界仅打日志；eSheep=窗恒等帧尺寸+窗位即宠位+离场逐帧裁窗；Desktop Mate=大余量跟随+随缩放 resize（其 resize 抖动/贴边 disjoint 病灶恰被本项目固定窗/虚拟屏钳制设计根治）。**先网检拿一手信源再设计**（源码>失效泄漏证据>GDC>社区逆向），本节即该方法论的第一次全胜实证。

### 3.2 渲染风格 v8【目检，2026-08-26 定妆】

**纯官方贴图 × 原神式基色暗化描边**：

- 光照全关：`_ShadowStrength=0`/`_RimStrength=0`/SDF 关（桌宠小窗无环境光，官方贴图自带烘焙渐变即"原神味"；ramp 调子在小窗读作脏色/发绿，是负资产——勿再主动重开）。参数全留接线，Inspector 可调回
- 描边：宽 0.2/0.18/0.15（身体/头发/披风，脸恒 0——脸轮廓由头发承担，眉毛/眼球浮层几何无法与外轮廓区分）+ 距离/缩放补偿（近大远小屏宽恒定+滚轮缩放等比）
- **描边色=基色暗化**【原神逆向实证】：`_OutlineColorMode=1` 时描边=该处主贴图像素×`_OutlineTint(0.5,0.45,0.4)` 逐通道（白衣→冷灰、肤色→暖棕、深发→深发色，随固有色变化）；mode=0 回退固定色。原神本尊即此做法（"outline is everywhere a different color depending on the base color"），非纯黑非固定色
- 未接：原神 ilm/Lightmap **A 通道逐区域描边宽度**（主轮廓粗关节细——本项目网格无 UV1 lightmap，每材质统一宽度）；ILM 其余通道/边缘光/发影
- GI 贴图考古铁律：**Diffuse UV 与光照 UV（UV1）是两套空间**，Lightmap/ILM 类贴图不能按像素直接叠加到 Diffuse（披风星点即此坑，现为合成贴图方案）

### 3.3 桌面阴影【目检】

剪影→高斯模糊（17-tap×2 轮）→偏移合成 Quad 三步管线（CSS drop-shadow / DWM 窗口阴影同款）：影子壳共享骨骼姿势逐帧同步、专属层独立相机渲 RT、合成 Pass `Blend SrcAlpha OneMinusSrcAlpha, One Zero`（alpha 直写防平方）。内部 shader 必须序列化 Material 引用（Shader.Find 构建期被裁）。参数 Inspector 中文可调。

## 4. 行为层（现状）

- **待机循环** + 事件动作（`PetBehaviorController`）：光标停留 1.2s（包围盒屏幕矩形扩 90px，冷却 45s）→ Greet；久待机随机小动作（Nod/ShakeHead/Sneer/Clap/Show_1-4，间隔 25-55s）
- **出场/退场**：进程启动播 Appear；双击=播 Disappear 后才 Quit（`请求退场(Action)` API）；仪式期间视线+眨眼静默
- **视线跟随**（`PetLookAtController`）：颈(35%)→頭→眼球分层叠加，每帧基线重建（防复利累积自转——曾"只剩眼白"根因）【实证】。进入静默（抓起/仪式）=权重混合淡出：输出 `Slerp(动画姿态, 平滑值, w)`，停写时输出恒等于动画姿态（结构性无跳变，2026-08-27 v2）
- **动作切换（2026-08-27，GoW4 惯性化）**：硬切新 clip + PetInertializer 后处理（五次多项式 C2 衰减，速度承接任意切点无缝），替代 CrossFade 线性混合。**幅度自适应**：偏移<10° 全额拉引+0.6s 慢混（防起步平台期）；≥60° 拉引×0.3+0.3s 快切（防大姿态差"悬一下"/瞬移）；诊断日志留库（打印诊断）。切换手感整体状态见 §8 遗留
- **动作切换统一入口**（`PetAnimSwapper.Play/PlayOnce`）+ 启动全 clip 预热（legacy 首播冷初始化 150ms 掉帧串→挪到启动帧）
- **命中网格=一次性补烘（2026-08-27）**：周期性重烘全删（重 cook 15-22ms 尖峰=切换停顿主凶，219 条掉帧中 214 条与烘焙同帧实证）；只在交互结束 2s 后补烘一次，连续交互顺延；cookingOptions=UseFastMidphase

## 6. 未实现设计（落地前必读）

### 6.1 拖拽与拎起（已实现，2026-08-27 更新：刚体跟随+四肢摆动+轻微挣扎+放下反应）

**现状【目检】**：拖拽=**身体刚体 1:1 直跟光标**（eSheep 直移语义：骨盆目标=抓取时骨盆位+光标位移，零摆动零滞后）+**四肢跟拍摆动**+**轻微挣扎（2026-08-27 用户要求，推翻 2026-08-26"只有四肢摆动"旧拍板）**+**松手即停**（骨盆冻结原地、四肢弹簧 ~0.5s 归零，无飞行/弹跳/落地反应）+**放下反应（2026-08-27 目检通过，commit 8e2a74e）**。窗口按"骨盆客户区投影钉物理目标位"定位（根平移不动，仅根旋转=拎起姿势基准）。

**放下反应（按时长三档，2026-08-27）**：物理收尾（松手 0.5s 归位）结束后按本次拖拽时长分档——**<3s 无反应**直接回待机（快速挪位置不打扰）；**≥3s 害羞**（Shy01AS+害羞表情）；**≥7.5s 生气**（Anger+生气表情，用户拍板"拖太久就生气"+阈值砍半）。PetDragPhysicsController 记录拖拽时长（拖拽期实时/松手冻结），PetBehaviorController 物理结束边沿分档播单次（播完自然回待机）。阈值/动作名 Inspector 中文可调（清空动作名=跳过该档）。

**四肢摆动（PetDragPhysicsController）**：4 条欠阻尼二阶角弹簧（左右臂/左右腿），目标角∝光标速度低通值（τ=50ms）——水平分量=惯性滞后（往右拖四肢向左甩）+竖直分量=外展（下拖张开/上提收拢，张开上限 10°、收拢再×0.35 防穿模）；臂腿增益/频率微差防同步机械感。应用层=PetWindowController.LateUpdate 以**世界 Z 轴**（屏幕平面法线）旋转叠加到 `Bip001 L/R UpperArm`+`L/R Thigh`（Animation 每帧重写姿势后叠加，不累积）。手感参数全在组件 Inspector 中文自调（摆动增益/外展增益/摆动频率/摆动阻尼比/外展上限）。

**挣扎（2026-08-27）**：全身轻微摆动=侧摆±2.5°（绕骨盆钟摆，头/四肢随反侧摆）+扭动±4°（绕竖直轴肩部拧，第三频率×1.37 与主次级错开）+四肢反相扑腾±6°（左右肢镜像开合，叠加进取四肢摆动输出）；两频叠加（次级占比 0.53）防机械摆锤感；包络渐入 0.4s/收尾随剩余时间线性衰减/相位全程连续（收尾中被再抓无跳变）；应用层=应用物理帧把挣扎摆/扭叠加进根旋转（绕骨盆枢轴补偿已有，骨盆恒钉物理目标位窗口稳定）。参数 Inspector 中文可调（挣扎摆幅/挣扎扭幅/挣扎频率/挣扎次级频率占比/挣扎渐入秒/四肢挣扎摆幅，单项 0=关闭）。

**标定教训【实证】**：①`Transform.rotation` 本就是**世界旋转**（localRotation 才是父系量）——直接前置乘 `AngleAxis(角, 世界轴)` 即正确；曾误当局部量做"父系共轭换算"（pw⁻¹·R·pw），反而把每肢旋转轴劫持到各自父骨局部 Z（左右镜像骨互反→"左右手反向摆"根因），已回退。②世界 Z 轴负角实测=四肢向屏幕**右**甩（与直觉相反）——方向符号按目检标定写死在物理组件（滞后=+vx），调方向只动那两处符号。③四肢摆幅的"美观度"参数（外展上限 10°）与"活感"参数（摆动增益/阻尼比）分离调。

**拎起动画 v4+v6（Drag01 专用 clip）**：`Ani_NPC_Kanban_Paimon_Drag01.anim`（GI/Animations，从 Standby 派生）：躯干 4 骨 C 型塌陷（Spine25°/Spine1 50°/Neck45°/Head55° 链式前屈=含胸低头脸朝观众）+四肢 12 骨贴身垂落共 16 条常量曲线；披风/头发/发饰/手指保留 Standby 微动。姿势基准=拎起转身角 45°（3/4 偏左）×横躺角 0（均 Inspector 可调，收尾平滑归零）。表情=Confuse 直发情绪层。生成链=PetDragPoseMeasure（Tilt 常量）→ generate_drag_clip.cjs → ImportAsset+同步工具。**Q 版骨架实证：Spine/Spine1 前倾 25/50 起步才出塌陷；Neck/Head≤55°，超过变"头转朝地面"俯卧式。**

**沿革**：v1 程序化垂落叠加层（PetDanglePoseController，弃用留库）→ v2 仓鼠式横躺 → v3 直立垂落 → v4 瘫软塌陷+松手飞行弹跳 → v5/v6 转身角演化 → **终案（2026-08-26 深夜）**：用户反馈"太像果冻"→删挣扎/飞行/落地反应；"没抓住斗篷"→抓点钉斗篷（一版）；"不要任何摆动，只摆四肢"→刚体直跟+四肢跟拍弹簧（斗篷锚点随钟摆一并移除）。业界共通式（VPet/eSheep/Shimeji 源码核验：垂挂瘫软姿势+低频次要动画+硬切过渡）中我们保留垂落 clip+微动，摆动改由四肢弹簧承担。

### 6.2 边缘坐（坐窗口顶边/任务栏横框）（已实现，2026-08-27 目检通过）

**机制（`PetEdgeSitController`，挂 PetWindow 物体）**：拖拽松手（无放下反应档）时磁吸探测附近"横框"——**窗口顶边**（DWM 可见帧 `DWMWA_EXTENDED_FRAME_BOUNDS`，非 GetWindowRect——后者含 Win10/11 不可见阴影边 ~7px 会悬空）与**任务栏顶**（工作区底）→ 磁吸贴合播直坐姿 SitUpright。

- **磁吸窗**：上 120px/下 60px（≈标题栏高度）/水平容差 160px（物理像素，场景序列化值可调）。采用 VPet 式磁吸而非 Shimeji 全局掉落——不推翻既有"松手即停"拍板，其余位置松手行为零变化
- **判定/贴合基准=骨盆（屁股）**（`Bip001 Pelvis` 投影，非包围盒底脚线——目检纠正：脚线判定整条腿沉入窗下）。落座后 `坐定贴正秒=1.2s` 逐帧钉骨盆（站→坐姿势过渡平滑"坐进去"）
- **窗口跟随**（eSheep FollowWindow 同款）：垂直恒贴顶边，水平按锚定比例随窗口宽度缩放；窗口最小化/关闭/隐藏/DWM cloaked → **重力掉落**（2800px/s²，途中更低窗口顶边可接住，任务栏顶兜底），落到哪坐哪
- **坐定中纯坐**（用户拍板）：打招呼/随机小动作全压制；情绪映射无匹配=默认脸（SitLoop→Sleepy 已清空——"生病坐姿"的困困脸不再随坐姿出现）
- **缩放露馅修正**（用户拍板方案）：坐姿下滚轮缩放=模型绕脚底长高而窗口不动→屁股浮离窗沿；处理=切回站立待机→缩放稳定 0.3s 后按锚点重新落座（锚定窗口消失则磁吸探测兜底）
- **窗口枚举过滤**=eSheep FallDetect 标准（可见+标题非空+非自身）+现代补充（最小化/WS_EX_TOOLWINDOW/cloaked/最小尺寸 240×160）；0.15s 重枚举节流，坐定期失效检测 0.5s 节流
- 一手源码参照：eSheep FormPet.cs（Adrianotiger/desktopPet，FallDetect/FollowWindow 语义），源码快照 .codely-cli/tmp/esheep_formpet.cs

**坐姿动画 SitUpright（合成）**：SitLoop（原版）是"生病坐姿"——骨盆前倾 ~65°+头耷拉 ~38°+手臂前抱（含胸驼背读感）。SitUpright=Standby 直立上身（抬头+中性脸+idle 微动，重采样压缩 2.68→2.02s）+SitLoop 腿（前伸下垂）与手势（上臂世界取向 Δ 补偿：父链换成直立躯干后保扶膝手势观感，补偿链=根⊗骨盆⊗脊⊗脊1⊗锁骨——漏锁骨差 7°）+骨盆高度不变（0.214）。**合成数学：换某骨父链后保该骨世界取向 = q' = newChain⁻¹ ⊗ oldChain ⊗ q，链必须逐骨完整（非交换，省略中间骨必留残差）**。

### 6.4 游戏画面内版派蒙（2026-08-27 立项）

**定位**：派蒙渲染在主游戏进程内（游戏画面角落悬浮），替代桌面版进程——目标安卓（Win32 不适用）与想省内存/单进程的 Windows 玩家。桌面版与游戏内版二选一，主游戏设置新增"派蒙"栏目切换（存档字段）。形态切换一期=重启生效。
