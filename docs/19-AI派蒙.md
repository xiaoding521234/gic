> 2026-08-21 立项。**本文 = 现状定案 + 设计意图 + 决策记录**。原则：只记"现在是什么、为什么"；过程流水与已废弃路线的排查细节在 git 历史与 docs/14，不再重复。操作工作流见 `gic-pet` skill；重定向管线操作见 `gic-paimon-retarget` skill。

## 1. 定位

AI派蒙 = **常驻桌宠 + 对话式游戏助手**：

- **表现层**：派蒙 3D 模型桌面常驻置顶悬浮，游戏失焦/最小化时仍在
- **生命周期**：**拉起不绑命**——启动游戏自动唤出（Mutex 单例防重）；游戏退出/崩溃后派蒙独立存活；关闭方式=双击她
- **交互层**：拖拽（物理手感未做，现为窗口直移）、待机动作轮换、视线跟随、屏幕边缘探头（未做，§6.3）
- **功能层**：LLM 对话指令入口——**已拍板接 LLM，一期不做**（§7）

非目标：战斗/联机中表现策略不考虑；不做逐小窗口交互（只认屏幕边缘）；移动端不做独立进程（仅游戏内悬浮挂件）。

### 2.2 动画（现状）

**当前生效：199 条 GI 原始 .anim 零重定向直读**（Bip001 路径与 FBX 骨架同源）。Animation 组件挂在 NPC_Kanban_Paimon_Model 骨节点。

GI 直读路线三个数据修复**必须在重新导出/新增 clip 后重跑**（详见 gic-pet skill）：
1. 菜单 `Tools/桌宠/GI原始动画: 哈希路径修复`——AssetStudio 导出时辅助骨（王冠/头发/披风链/手指）path 是哈希字面量 `path_<CRC32>`，逐字绑定必死（王冠不动/头发披风手指僵直的根因）【实证：109 文件 8262 处替换】
2. Node 批处理 `gi_tangent_batch.cjs`——AssetStudio 导出全零切线（60Hz 速度脉冲=丝滑度差主因），FD C1 切线+四元数符号连续化
3. Node 批处理 `gi_pos_center.cjs`——Bip001 编排位移均值归位（往返型峰值减半）；**ref 必须外置固定常量**（自引用基准=非幂等跑飞，曾两轮全体漂 -8cm）

**方案 B 重定向管线（MMD 路线，现为兜底）**：97 条已转换产物在 `Animations/MMD/`，管线/配置/审计工具全在（gic-paimon-retarget skill）。切回 MMD 模型时用它。

> 历史注记 ❌已推翻：§2.2 早期记录"30 哈希路径经引擎 binding hash 正常匹配"**只对主链骨成立**，辅助骨哈希实际全是死绑定（2026-08-25 哈希修复工具实证）。

### 2.3 表情层（运行时驱动，零烘焙）【目检】

三层架构（行业通行 body/face 分层——GI 动画本就不含表情曲线，源数据如此）：
- **身体层** = Animation clip
- **情绪层** = `PetEmotionController`：情绪=多 Morph 组合（嘴+眉+眼联动，10 情绪 25 morph）；PetAnimSwapper 按动作名映射下发（13 条：Greet→Happy、Show_→得意、Sleep/SitLoop→Sleepy 等）
- **微动作层** = `PetBlinkController`：随机眨眼 2.5~5.5s
- morph 独占约定：组件管理的 morph 不得出现在任何 clip 曲线中

## 3. 窗口与渲染（现状）

### 3.1 窗口体制【实证，2026-08-26 定案】

**小窗+固定相机+根绝对补偿+窗口唯一移动者**（严格对齐 VPet/eSheep 源码核验架构）：

- **窗口**：恒 550×825 逻辑×DPI×缩放上限固定尺寸（550×825 含影子边距；DWM 逐像素 alpha 透明，前提关 `useFlipModelSwapchain`）
- **相机永不移动**【实证】：移动相机=模型被斜着看（累积位移@2.5m→斜视角 ~15°），是旧体制"角度变化"bug 根因；VPet/eSheep 源码均无移动相机操作
- **单次动作期**：模型根**绝对补偿**——假想位移=骨盆世界位换算回锚点根坐标系（每帧从动画值重导出=结构性零累积漂移），根=锚点根-位移XY（骨盆钉窗内构图恒定不被裁；Z 不补=窗内近大远小），窗口=锚点窗+位移屏幕像素（绝对定位）
- **收尾**：行为层清标志后跟随宽限 0.6s（覆盖 CrossFade 尾段混合），根/窗口随混合自然归零——无归位 lerp
- **拖拽**：窗口直接绝对定位到 光标-抓取偏移（1:1 零反馈），根全程不动【eSheep 源码原样】；拖出虚拟屏松手才拉回防丢
- **待机**：相机+根+窗口全静止，模型窗内自由微动（VPet 画布余量哲学）
- **缩放**：滚轮只改模型 localScale（固定窗口防 resize 闪烁）；pet.json 独立存档（缩放+窗口原点，防抖落盘）
- 帧节奏 vSyncCount=1（满刷）；CPU≈115% 是满刷既有成本非回归

> 演化史 ❌已废弃：①"相机+窗口双跟随"增量体制（2026-08-25 首版）——三处结构性 bug：相机累积位移=角度变化、多状态链累积=漂移、双环反馈（光标→世界映射依赖窗口原点，窗口位移吃掉光标映射）=拖拽恒半速，2026-08-26 全部根治。②全屏覆盖体制（同日）——3200×2000@200%DPI 帧率 165→75 腰斩+dwm 全屏合成吃系统，一日游废弃。
>
> 业界机制参考【源码核验 2026-08-26】：VPet=固定 500×500 画布+走路才移窗+出界仅打日志；eSheep=窗恒等帧尺寸+窗位即宠位+离场逐帧裁窗；Desktop Mate=大余量跟随+随缩放 resize（其 resize 抖动/贴边 disjoint 病灶恰被本项目固定窗/虚拟屏钳制设计根治）。**先网检拿一手信源再设计**（源码>失效泄漏证据>GDC>社区逆向），本节即该方法论的第一次全胜实证。

### 3.2 渲染风格 v8【目检，2026-08-26 定妆】

**纯官方贴图 × 原神式基色暗化描边**：

- 光照全关：`_ShadowStrength=0`/`_RimStrength=0`/SDF 关（桌宠小窗无环境光，官方贴图自带烘焙渐变即"原神味"；ramp 调子在小窗读作脏色/发绿，是负资产——勿再主动重开）。参数全留接线，Inspector 可调回
- 描边：宽 0.2/0.18/0.15（身体/头发/披风，脸恒 0——脸轮廓由头发承担，眉毛/眼球浮层几何无法与外轮廓区分）+ 距离/缩放补偿（近大远小屏宽恒定+滚轮缩放等比）
- **描边色=基色暗化**【原神逆向实证】：`_OutlineColorMode=1` 时描边=该处主贴图像素×`_OutlineTint(0.5,0.45,0.4)` 逐通道（白衣→冷灰、肤色→暖棕、深发→深发色，随固有色变化）；mode=0 回退固定色。原神本尊即此做法（"outline is everywhere a different color depending on the base color"），非纯黑非固定色
- 未接：原神 ilm/Lightmap **A 通道逐区域描边宽度**（主轮廓粗关节细——本项目网格无 UV1 lightmap，每材质统一宽度）；ILM 其余通道/边缘光/发影
- GI 贴图考古铁律：**Diffuse UV 与光照 UV（UV1）是两套空间**，Lightmap/ILM 类贴图不能按像素直接叠加到 Diffuse（披风星点即此坑，现为合成贴图方案）

### 3.3 桌面阴影【目检】

剪影→高斯模糊（17-tap×2 轮）→偏移合成 Quad 三步管线（CSS drop-shadow / DWM 窗口阴影同款）：影子壳共享骨骼姿势逐帧同步、专属层独立相机渲 RT、合成 Pass `Blend SrcAlpha OneMinusSrcAlpha, One Zero`（alpha 直写防平方）。内部 shader 必须序列化 Material 引用（Shader.Find 构建期被裁）。参数 Inspector 中文可调。

## 4. 行为层（现状）

- **待机循环** + 事件动作（`PetBehaviorController`）：光标停留 1.2s（包围盒屏幕矩形扩 90px，冷却 45s）→ Greet；久待机随机小动作（Nod/ShakeHead/Sneer/Clap/Show_1-4，间隔 25-55s）
- **出场/退场**：进程启动播 Appear；双击=播 Disappear 后才 Quit（`请求退场(Action)` API）；仪式期间视线+眨眼静默
- **视线跟随**（`PetLookAtController`）：颈(35%)→頭→眼球分层叠加，每帧基线重建（防复利累积自转——曾"只剩眼白"根因）【实证】
- **动作过渡**：CrossFade 0.3s + 尾段提前过渡（剩余≈过渡秒×0.9 即切，消除"播完定格→再淡入"）
- **动作切换统一入口**（`PetAnimSwapper.Play/PlayOnce`）+ 启动全 clip 预热（legacy 首播冷初始化 150ms 掉帧串→挪到启动帧）

## 5. 进程架构（现状）

- 同 exe 双形态：`gic.exe`（主游戏）+ `gic.exe --pet-mode`（桌宠）；`PetMode` 静态开关，编辑器恒 false
- Boot 的 GameScene.Awake 与 Mirror 网络组件 Awake 均有 PetMode 守卫
- 主进程拉起桌宠（PetProcessLauncher，`UNITY_STANDALONE_WIN` 守卫）；Mutex 单例
- **同 exe 双进程约束（新功能必读）**：①共享 Screenmanager 注册表——主进程必须显式 SetResolution（SettingsApplier.ApplyDefaultFullscreen），桌宠永不碰主存档（独立 pet.json）、永不触发存档写盘
- 构建走 `Tools/桌宠/构建 Windows 桌宠测试包`（构建判据与竞态守卫见 gic-pet skill——**只信 Editor.log RESULT 行**）
- 编辑器联调：`Tools/桌宠/Play 时自动拉起派蒙`（编辑器 Play 自动拉起上次构建产物）

## 6. 未实现设计（落地前必读）

### 6.1 拖拽与拎起（已实现，2026-08-26 终案）

**现状**：拖拽=抓点（光标）钉住斗篷、骨盆做不可伸长绳单摆质量点（PetDragPhysicsController 纯模拟：重力+空气阻尼+周期挣扎爆发力+倾角欠阻尼弹簧；松手速度二分——≥700px/s 飞行弹跳+虚拟屏侧墙反弹，低速原地收尾）。窗口按"骨盆客户区投影钉物理目标位"定位（根平移不动，仅根旋转）。

**拎起动画 v4（2026-08-26 参考图定案，瘫软低头含胸式）**：专用 `Ani_NPC_Kanban_Paimon_Drag01.anim`（GI/Animations，从 Standby 全套曲线派生）：**躯干 4 骨塌陷**（Spine 25°→Spine1 50°→Neck 45°→Head 55° 链式前屈=C 型含胸、头低臀高；头为**纯低头**——脸朝观众、视线垂向地面、下巴贴胸口，非"头朝前探出"俯卧式；实测骨盆→头前偏 28-37°、头骨降 2.9cm）+**四肢 12 骨贴身垂落**（上臂贴身微后摆、肘微屈左右不对称、手猫爪微内、大腿内收内八、膝微屈 150°、脚尖下垂）共 16 条旋转常量曲线；披风/头发/发饰/手指/锁骨/骨盆保留 Standby 微动（布娃娃微晃感）。生成链=PetDragPoseMeasure（编辑器程序化摆姿势出 JSON，Tilt 常量在此调）→ generate_drag_clip.cjs（YAML 手术）→ ImportAsset+同步工具注册。拎起横躺角 0 直立。表情=Confuse 直发情绪层；落地冲击≥900px/s 播反应（Anger/Confuse/Shy 随机）。**Q 版骨架实证：短脊柱+大头，Spine/Spine1 前倾 15/30 只降头 1.7cm，25/50 才出含胸塌陷；Neck/Head 别超 55°——85°/95° 是"头转朝地面"（下巴顶朝观众），参考图是"脸朝观众纯低头"。**

**业界一手核验（2026-08-26 网检，VPet/eSheep/Shimeji 源码+官方精灵帧）**：主流共通式=「垂挂瘫软姿势+低频次要动画（眨眼/微晃/间歇踢腿，无激烈循环）+（可选，仅 Shimeji）移动倾斜+松手必有下文（掉落/落地/爬起）+硬切过渡」。我们的对应：垂落 clip ✓、待机微动+钟摆倾角（Shimeji 弹簧滞后的 3D 连续版）✓、飞行+落地反应 ✓、CrossFade 0.3s（比主流硬切更平滑）✓。

**沿革**：v1 程序化四肢垂落叠加层（PetDanglePoseController，已弃用留库、场景组件已移除——与 clip 每帧叠加易顿挫、调参面大）→ v2 Sleep01 躺姿+根旋转 90° 横躺（仓鼠式，语义错位：团姿传达"放松蜷缩"，主流是"重力拉垂"）→ v3 专用垂落动画（直立悬挂，VPet 式）→ v4 瘫软塌陷（用户参考图式：C 型前屈+贴身四肢，终案）。拖拽物理手感参数全在 PetDragPhysicsController Inspector 中文自调。

### 6.2 屏幕边缘探头（扒边框）

停靠/甩到屏幕边缘→身体出屏只露头和扒框双手→张望变体；拖回恢复。只认屏幕边缘不做逐窗口；多显示器策略待定。

### 6.3 对话功能（LLM）

已拍板接 LLM 一期不做。分层=对话层（LLM Intent）→指令层（Intent→Action）→既有系统调用（不新写业务）。选型结论【2026-08 调研】：文字期=云 API function calling + 自研薄 Intent 层（推荐豆包/DeepSeek/GLM，C# HttpClient 直连）；LLMUnity 本地推理作离线备选；重量级 Agent 框架（LangGraph 等 Python 生态）不采用。语音期 TTS 可用项目内 AudioManager.PlayVoice（可 voice_clone）。注：团结提供的 GLM 是编辑器侧工具不提供运行时 API，运行时要接用智谱 BigModel 开放平台。首批指令：设置游戏内时间/打开背包/帮我抽卡（均已有现成系统）。
