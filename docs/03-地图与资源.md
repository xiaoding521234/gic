# 三、战场与资源

## 3.1 核心宝箱

- 开局时，每个玩家的协议核心周围**随机刷出3个核心宝箱**
- **只有敌人可以开启**（己方无法开自己的箱子）
- 敌人开启宝箱获得：
  - **升变**：提升1个命座
  - **传送**：传送回自己的协议核心
  - **资源**：摩拉、物品

## 3.2 局内资源

| 资源 | 用途 | 来源 |
|------|------|------|
| **原粹树脂（体力）** | 移动、战技、爆发的消耗 | 初始60个 + 每回合发放5个（与摩拉统一时机） + 建筑/角色技能产出 |
| **摩拉** | 出战角色 / 提升命座 / 出战建筑 / 璃月契约 / 须弥传输 / 建筑购买卡牌 | 初始200 + 每回合自动获取5 + 核心宝箱 |
| **元能** | 角色元素爆发 / 蒙德延奏 | 移动、战技命中敌人 |
| **原石** | 局外祈愿抽卡 | 造成伤害、摧毁核心 |

## 3.3 战场基本规格

- 战场为**平铺网格**，无高低差概念
- 初始尺寸：**20×20**
- 上限尺寸：**50×50**
- 没有地形的格子用**虚空**填充（不可通行、不可放置）

## 3.4 地形类型

- 每个格子有**地形属性**，类型包括但不限于：
  - **草地**
  - **水**
  - **岩浆**
  - **泥土**
  - **石路**
  - 其他地形（待设计）

### 出生点

- 每个玩家的出生点固定为**3×3的石路地形**
- 出生点位置在战场上对所有人可见（通过迷雾也能看到地形）

## 3.5 战场动态变化

- 战场**不是固定的**，玩家可以通过技能改变地形：
  - **扩大战场**：将虚空格子变为有地形格子
    - 例：北斗可以把周围虚空变为**水**，使该格变为可通行的水域
  - **摧毁格子**：将有地形的格子变为虚空
    - 例：雷神的元素爆发可以**摧毁格子为虚空**
- 这意味着战场会随着对局推进**不断变化**——前期小战场空间紧张，后期战场扩大但关键格子可能被摧毁

## 3.6 战争迷雾

- 采用类似红色警戒2的**战争迷雾**机制
- 未探索区域被**半透明迷雾**覆盖，可以看见地形但**看不见单位、建筑、宝箱**
- 一旦探索过该区域，**永久可见**（不再有迷雾）
- 由于出生点为固定3×3石路地形，玩家可以通过迷雾中的地形特征推断对手的大致方位

## 3.7 设计意图

- 地形本身提供策略深度（不同地形影响移动/战斗）
- 战场扩展=领土争夺（谁先把虚空变成自己的地形，谁就获得更多空间）
- 格子摧毁=战术断路（摧毁关键通道可以切断敌方进攻路线或保护己方核心）
- 角色的地形相关技能（如北斗造水、雷神毁格）让地形变化成为角色特色的一部分
- 战争迷雾=前期侦察博弈（探索敌方核心位置/宝箱位置/建筑布局）
- 半透明迷雾让玩家能通过地形特征（如3×3石路出生点）推断对手方位，减少纯随机摸索，保留信息博弈深度
